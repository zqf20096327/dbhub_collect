# PFN — Private Finance Tracker

Локальный трекер личных финансов: денежный поток, капитал, бюджеты, подписки,
цели, активы и криптопортфель в одном приложении. Работает **на вашем
компьютере**, данные лежат в одном файле и никуда не отправляются.

- один процесс, без Docker, без Postgres, без nginx;
- запуск двойным кликом, интерфейс открывается отдельным окном;
- данные — файл `pfn.db` в вашем пользовательском каталоге;
- светлая, тёмная и системная тема + шесть акцентных цветов;
- русский и английский интерфейс.

**Сайт:** https://0x-dorothy.github.io/PFN/ · **Скачать:** [Releases](https://github.com/0x-dorothy/PFN/releases)

## Установка

Скачивать нужно ровно один файл — в зависимости от системы:

| Файл | Кому | Что делать |
| --- | --- | --- |
| `PFN-1.2.0-Setup.exe` | Windows, обычный пользователь | двойной клик → «Далее» → ярлык на рабочем столе |
| `PFN-1.2.0-win64.zip` | Windows, без установки | распаковать куда угодно → запустить `PFN.exe` |
| `PFN-1.2.0.dmg` | macOS | открыть, перетащить PFN в «Программы» |
| исходники | только разработчику | нужен Python 3.10+, см. [«Разработка»](#разработка) |

**Python, Node.js, Docker и Postgres для первых трёх не нужны.** Интерпретатор
Python и собранный интерфейс лежат внутри установщика — дополнительно ставить
ничего не надо. Python понадобится только если запускать из исходников.

### Windows

1. Запустить `PFN-Setup.exe`, нажимать «Далее». Права администратора не нужны —
   программа ставится в профиль пользователя.
2. Запустить **PFN** из меню «Пуск» или с рабочего стола.

SmartScreen может показать «Windows защитила ваш компьютер»: сборка не подписана
сертификатом (он стоит денег). «Подробнее» → «Выполнить в любом случае» — это
ожидаемое поведение для бесплатных сборок.

### macOS

Открыть `.dmg`, перетащить PFN в «Программы». Первый запуск: правый клик по
иконке → «Открыть» (Gatekeeper не любит неподписанные приложения; одного
подтверждения достаточно).

### Где хранятся данные

| ОС | Путь |
| --- | --- |
| Windows | `%APPDATA%\PFN\pfn.db` |
| macOS | `~/Library/Application Support/PFN/pfn.db` |
| Linux | `~/.local/share/PFN/pfn.db` |

Каталог можно перенести переменной `PFN_DATA_DIR`. Программу при этом можно
переустанавливать как угодно — база лежит отдельно.

Резервная копия: **Настройки → Бэкап → Экспортировать** (один JSON со всеми
данными), восстановление тем же файлом. Это же способ перенести данные на
другой компьютер.

### Если что-то не запустилось

- Подробный лог: `launcher.log` в каталоге данных (таблица выше).
- Порт занят? `PFN.exe --port 8800`.
- Нужен доступ с телефона по домашней сети? `PFN.exe --host 0.0.0.0`, затем
  открыть `http://<IP-компьютера>:8765`. Пароля в приложении нет — только своя сеть.
- Остановить: «Остановить PFN» в меню «Пуск» или `PFN.exe --stop`.

### Как эти файлы получаются

```powershell
powershell -ExecutionPolicy Bypass -File tools\build_windows.ps1
# → dist\PFN\PFN.exe, release\PFN-1.2.0-win64.zip,
#   release\PFN-1.2.0-Setup.exe, release\SHA256SUMS.txt

python tools\make_icon.py   # пересобрать иконку из той же геометрии, что и логотип
```

Скрипт сам находит Inno Setup и нормальный Python (если у системного нет
PyInstaller — берёт переносимый из `build\pytool`). Рядом с файлами лежит
`SHA256SUMS.txt`: проверить можно через `certutil -hashfile <файл> SHA256`.

Windows-артефакты собираются локально, macOS `.app`/`.dmg` — только на Mac.
Обе сборки автоматизированы в
[`.github/workflows/build.yml`](.github/workflows/build.yml): пуш тега `v*`
публикует готовые файлы в Releases. Пошаговый чек-лист — в
[docs/RELEASE.md](docs/RELEASE.md), история версий — в [CHANGELOG.md](CHANGELOG.md).

## Возможности

- **Счета и транзакции** — доходы, расходы, переводы; категории с
  подкатегориями, теги, поиск, разделение одной покупки на несколько категорий.
- **Импорт из банка** — CSV из Т-Банка, Альфа-Банка или своя схема
  колонок.
- **Капитал** — общий график чистого капитала и разбивка по классам активов,
  риску и роли капитала.
- **Криптовалюта** — портфели, история покупок, средняя цена, P/L, изменение за
  1ч/24ч/7д (нужен бесплатный ключ CoinGecko, см. `.env.example`).
- **Бюджеты, цели, регулярные платежи** — лимиты по категориям, взносы в цели,
  проведение регулярных операций одной кнопкой.
- **Отчёты и советы** — рейтинг категорий за период, правила-подсказки
  (растущие расходы, перерасход, динамика нормы сбережений).
- **Калькулятор доходности** — окупаемость и сложный процент с графиком.
- **Оповещения** — серия месяцев с отрицательным потоком, падение капитала,
  перерасход, слишком большая доля рисковых активов, простаивающие деньги.

## Оформление

**Настройки → Язык / Тема / Акцентный цвет.**

![Настройки: тема и акцентный цвет](docs/screenshot-settings.png)

- Тема: светлая, тёмная, системная (следует за ОС и переключается на лету).
- Акцент: синий, фиолетовый, зелёный, янтарный, розовый, графит. Меняет
  кнопки, активный пункт меню, переключатели, фокус полей и ссылки.
  Палитра графиков при этом не меняется — она подобрана под цветовую слепоту.
- Выбор запоминается в браузере и применяется до первой отрисовки, без вспышки.


Бизнес-логика (сервисы, схемы, роуты, палитра графиков, миграции) не менялась.

## Разработка

```
backend/            FastAPI + SQLAlchemy (async) + SQLite/Postgres
  app/api/routes/   эндпоинты по доменам
  app/services/     бизнес-логика и агрегаты
  app/models/       ORM
  alembic/          миграции (только для Postgres)
frontend/           React 19 + TypeScript + Vite + Tailwind 4
  src/lib/          тема, брендинг, i18n, форматирование
launcher.py         запуск приложения для конечного пользователя
pfn.spec            сборка PyInstaller (Windows .exe / macOS .app)
installer/          Inno Setup: установщик для Windows
tools/              иконка и сборочные скрипты
docs/               анализ проекта и справка по API
```

Запуск из исходников, без сборки:

```bash
# Windows
double-click start.bat

# macOS / Linux
./start.sh
```

Скрипт сам создаст окружение, поставит зависимости и откроет окно приложения.

```bash
# бэкенд (API + собранный UI на http://127.0.0.1:8000)
cd backend
python -m venv .venv && .venv\Scripts\activate      # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload

# фронтенд (dev-сервер с проксированием /api на :8000)
cd frontend
npm install
npm run dev

# сборка интерфейса для поставки
npm run build        # tsc -b && vite build → frontend/dist

# проверки
cd frontend && npx tsc -b && npx vitest run
cd backend && pytest     # требует Postgres (см. tests/README.md)
```

## Ограничения

- **Вкладка «Криптовалюта»** без `PFN_COINGECKO_API_KEY` показывает ошибку —
  остальное приложение работает полностью офлайн.
- **Тесты бэкенда** идут на SQLite (как и рабочая сборка): 142 теста,
  эфемерная база в памяти на каждый тест.
- **macOS-сборка не проверялась**: `.app`/`.dmg` собираются только на Mac.
  Windows-артефакт собран и проверен на этой машине.
- **Android** пока не собран: нужен Android SDK, см. `docs/Анализ-и-план.md` §11.2.
- **Пароля нет.** Приложение рассчитано на один компьютер и одного
  пользователя; не выставляйте его в интернет.
