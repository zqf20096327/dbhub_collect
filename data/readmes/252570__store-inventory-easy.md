STORE INVENTORY MANAGEMENT - EASY OFFLINE VERSION

This version uses only Python's built-in Tkinter and SQLite.
NO PySide6, NO pip install, and NO internet are required.

HOW TO START:
1. Keep this whole folder together.
2. Double-click START_STORE_INVENTORY.bat.
3. The application opens automatically.

The database is created in:
data\inventory.db

Attached documents are copied into:
data\documents

Backups can be saved in:
data\backups

FEATURES:
- Add / edit / delete items
- Stock IN and Stock OUT
- Automatic quantity calculation
- Person/department, purpose, reference and notes
- Attach invoices/receipts/documents
- Search inventory
- Transaction history
- Export inventory to CSV
- Database backup
- Fully offline
