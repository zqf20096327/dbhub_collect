# Develop Dream Fiction Skill

一个用于梦女、乙女与真人梦角创作研究的 Codex Skill。

它将公开资料研究、人物 Character Bible、OC 主体性、关系逻辑、文学母题与跨学科概念转译整合为持续创作工作流。核心问题不是“怎样让理想人物爱上主角”，而是：**为什么偏偏是她，以及为什么这段关系不可替代。**

## 能做什么

- 研究真实人物的公开形象与可核验 TMI，并区分事实、观察、推断和虚构转化
- 构建梦角、OC、关系逻辑与 Story Bible
- 开发人物弧光、冲突、文学母题和意象系统
- 把粗糙情感转译为更准确、有感染力的文学表达
- 结合文学、神话、宗教、哲学、心理学、人文社会科学和自然科学概念
- 辅助扩写、续写、重写、润色和文本诊断

## 安装

将仓库中的 `develop-dream-fiction` 文件夹复制到你的 Codex Skills 目录：

```text
~/.codex/skills/develop-dream-fiction/
```

然后可以直接提出相关创作任务，或显式调用：

```text
$develop-dream-fiction
```

## 使用边界

真人资料只使用公开、可核验且具有叙事功能的信息；避免隐私越界、把推断包装成事实，或把文学角色等同于真人私生活。创作者保留最终设定与表达决定权。
