## 技术栈

- 后端：PHP 8.0+、ThinkPHP 8.0.2、ThinkORM 3
- 数据：MySQL 5.7/8.0、Redis 6+
- 前端：Vue、Element 系列组件、移动端 H5
- 媒体：FFmpeg / FFprobe、阿里云 ICE（按业务启用）
- 存储：本地、阿里云 OSS、七牛云、腾讯云 COS
- 部署：Nginx、宝塔 Linux 面板、Composer 2
- 第三方：微信生态、短信、支付、AI 模型、平台开放接口（按需配置）

## 宝塔快速部署

1. 安装 Nginx、MySQL、PHP 8.2、Redis，并启用所需 PHP 扩展。
2. 创建新站点与全新 `utf8mb4` 数据库，将站点运行目录设为 `/public`。
3. 上传源码交付包并解压到站点根目录。
4. 填写 `.env` 数据库参数，导入交付包中的数据库安装文件。
5. 执行 `composer install --no-dev --optimize-autoloader`。
6. 配置 ThinkPHP 伪静态：`try_files $uri $uri/ /index.php?$query_string;`。
7. 为 `runtime`、上传目录配置 Web 用户写入权限。
8. 配置守护进程：`php think timer start`，用于异步文案与视频任务。
9. 绑定域名、申请 HTTPS，随后填写对象存储、AI 与平台接口参数。
