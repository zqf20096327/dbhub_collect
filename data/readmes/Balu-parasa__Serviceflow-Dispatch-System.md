# 🚀 ServiceFlow – Real-Time Dispatch System

A modern full-stack service management platform designed to streamline service requests, technician allocation, and real-time tracking. ServiceFlow enables organizations to efficiently manage field operations through live technician updates, secure authentication, and an intuitive user interface.

> 💡 Built as a scalable full-stack application using **Next.js**, **Laravel**, **TypeScript**, **TiDB**, and **Pusher WebSockets**.

---

## 📌 Overview

ServiceFlow simplifies the complete service lifecycle by allowing users to create service requests, enabling administrators to assign technicians, and providing real-time status tracking throughout the process.

The platform focuses on improving operational efficiency through secure APIs, live communication, and a responsive user experience.

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/Balu-parasa/Serviceflow-Dispatch-System.git
```

### Navigate

```bash
cd Serviceflow-Dispatch-System
```

### Install Dependencies

Frontend

```bash
npm install
```

Backend

```bash
composer install
```

### Start Development

Frontend

```bash
npm run dev
```

Backend

```bash
php artisan serve
```
