# AI Resume Analyzer

An AI-powered Resume Analyzer built using Python, Flask, Groq AI, and TiDB Cloud.

##  Features

- 🔐 User Authentication (Login & Signup)
- 📄 Upload Resume (PDF/DOCX)
- 🤖 AI Resume Analysis
- 📊 Skill Gap Analysis
- 🛣️ Personalized Learning Roadmap
- 💡 AI Interview Questions
- 📜 Resume History
- 🔑 Forgot Password
- Responsive UI

##  Tech Stack

- Python
- Flask
- HTML5
- CSS3
- SQLAlchemy
- TiDB Cloud
- Groq API
- Flask-Mail
- Gunicorn
- Render

## ▶️ Installation

```bash
git clone https://github.com/Dipmandole/Resume_Analyzer.git
cd Resume_Analyzer
pip install -r requirements.txt
python app.py
```
