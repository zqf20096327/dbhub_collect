## 为什么会有这套东西

做工厂外贸，一票货从询盘、问工况、定牌号、报价或 PI、寄样、测试、合同、
收款、排产、报关、订舱出运到尾款归档，中间要出的单证是分散的。
客户改一次数量或贸易术语，报价单、形式发票、合同、发票、装箱单要跟着改一遍，
漏改一处，到了银行或报关环节就得重来。

这几年把美国、法国、意大利的订单从头到尾走过一遍之后，
我把自己每天实际要填的字段、要核对的口径、要打印的版式，
收成了这一套本机离线的工作台。**它不是一个通用 ERP，就是一张单证桌。**

设计上守几条笨规矩：

- **不联网**：只监听 `127.0.0.1`，没有远程接口，数据全在本机 SQLite。
- **不编数据**：重量、体积、HS 编码、账号、认证，没有实测或已确认的依据就不填；
  缺实测装箱数据，Packing List 会直接拦住，不让你出一份带空值的单证。
- **空字段不外泄**：没填的条款、备注、重量不会打印成空白占位或 0。
- **各是各的文件**：五类单证独立生成、独立预览、独立打印／下载，不拼成一个大 PDF。

## 能做什么

| 能力 | 说明 |
| --- | --- |
| 五类单证 | Quotation / Proforma Invoice / Sales Contract / Commercial Invoice / Packing List |
| 多贸易术语 | 一份订单可设 FOB / DAP / DDP 等多套价格，逐产品 × 逐术语单价矩阵，按术语分别出报价单 |
| 双币种参考 | 主币种计价，可带参考币种合计行 |
| 版式 | A4 零页边距、11 种输出语言、9 款配色，表头／标题线／强调色联动 |
| 卡片墙 | 单证中心逐张卡片预览，想打哪张打哪张 |
| 装箱与唛头 | 逐型号数量校验、箱唛卡片、实测重体积录入 |
| 档案与设置 | 客户、产品、出单主体、收款账户、汇率、利润分析、历史记录 |
| 上手辅助 | 一键载入／清除 DEMO 虚构数据、首启三步引导、Logo 可上传、帮助与支持页 |

## 不做什么（边界写清楚，免得误会）

- 不生成货代订舱委托（Booking）、ISF / AMS、报关单、原产地证、COA、
  提单、电放、进仓单——这些由货代、海关或第三方出具，不该由单证软件代劳。
- 不联网查汇率、不自动抓客户资信、不发邮件。
- 不替你推断 HS 编码、重量、体积或箱数：这些须由工厂实测或报关行确认后录入。
- 不提供多人协同、云端同步、数据库加密，也不做在线激活或授权校验。
- 不对海关、银行、货代、客户的接受结果作任何担保。正式出单前请人工逐项复核。

## 快速开始

### 方式 A：直接能跑（推荐给不写代码的人）

下载 Release 里的 **`TradeDocsPro_开源分享版_v1.0_免安装.zip`**，完整解压到任意文件夹，
双击 `启动TradeDocsPro.bat`。随包 `runtime/python/` 已带 Python，无需另装。
浏览器自动打开 `http://127.0.0.1:8965/`（端口占用会在 8965–8995 内顺延，以窗口显示为准）。

> 关掉那个黑色命令行窗口就等于关掉服务；换电脑直接复制整个文件夹。
> 打印／另存 PDF 时记得勾选「背景图形」，否则配色会丢失。

### 方式 B：从源码跑（推荐给想改代码的人）

```bash
# 需要 Python 3.8+，只用标准库，不需要 pip install
git clone https://github.com/DowneyQiu/tradedocs-pro.git
cd TradeDocsPro
python server.py
```

首次使用：①【出单主体】填贵公司英文法定名称与地址 → ②【收款账户】按币种建档 →
③ 客户与产品建档 → ④ 新建订单五步填写 → ⑤ 单证中心逐张预览打印。
想先看效果，可在设置里一键载入 DEMO 数据（全部为虚构示例，带明确标注）。

**出厂是空库**，不含任何真实公司、客户、账户、订单资料，请放心。

## 技术栈与目录

Python 3.8+ 标准库 `http.server`（`ThreadingHTTPServer`）+ SQLite，
前端原生 JavaScript、无框架、无 CDN、无构建步骤。
数据真实源是 `tradedocs.sqlite3`（文档式 JSON 集合 `records(collection,id,body)`），
浏览器 `localStorage` 只是写穿缓存，每次启动由 SQLite 覆盖。

```
TradeDocsPro/
├─ server.py                 # 本机 HTTP 服务与 /api/* 接口
├─ core.js documents.js      # 状态与单证引擎
├─ studio.js workspace.js    # 卡片墙与各视图
├─ order-form.js             # 五步订单向导
├─ i18n.js app.css           # 语言、配色、版式
├─ brand.js                  # Logo 上传 / DEMO 数据 / 首启引导
├─ seller-config.json        # 出厂空白配置模板
├─ tradedocs.sqlite3         # 出厂空库
├─ LICENSE                   # 源码可见 · 非商业化分发许可（中文正文）
├─ LICENSE-EN.md             # 英文摘要（不具效力）
├─ THIRD-PARTY-NOTICES.md    # 第三方组件许可
└─ runtime/python/           # 随包运行时（仅免安装 ZIP 含，仓库忽略）
```

## 数据与隐私

只监听 `127.0.0.1`，`Cache-Control: no-store`，不含任何远程接口。
业务数据全在 `tradedocs.sqlite3`，自动快照在 `backups/`，产品图片在 `product-images/`。
清浏览器缓存、换浏览器都不会丢数据；定期复制整个文件夹另存即可。
