<section>
<h2>Build With 🖱️</h2>
  <p>This app is created using Tauri, a Rust framework for building desktop applications with web technologies. It uses Shadcn and React for the frontend layer, Monaco Editor to edit the snippets, and SQLite to save them locally.</p>
</section>

<section>
<h2>Install ⬇️</h2>
  Download from <a href="https://github.com/EnzoDev10/Estela/releases/tag/firstRelease">releases</a> page. Currently only supports Windows x64.
