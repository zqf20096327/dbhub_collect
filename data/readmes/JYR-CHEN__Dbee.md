# Dbee

Dbee 是一款桌面数据库管理工具。覆盖关系型、国产、时序、文件 / 嵌入式、文档 / 缓存、搜索、分布式协调与消息队列八类数据源，共 16 种。

- **免装驱动**：Oracle、SQL Server、Redis（RESP2）等都不依赖本机客户端 —— 不用装 Oracle Client，不用配 ODBC。
- **一个客户端管全部**：从 MySQL 到 Kafka 都在同一套界面里，不必为每种库开一个工具。
- **跨库数据传输**：表 → 表迁移时自动做列类型映射，两端可以是完全不同类型的数据库。

> ⚠️ **Dbee 定位是个人 / 开发调试工具，不建议直接接入生产库。** 连接密码明文保存、写操作真实落库且部分方言无法回滚、无审计与权限收敛。请务必先读 [使用前必读](#使用前必读)。

## 使用前必读

**Dbee 目前没有经过大规模生产验证，请在接入真实数据前读完这一节。**

1. **连接密码以明文存在本地。** 勾选「记住密码」后，口令原样写入应用数据目录下的 `session_profiles.json` —— 任何能读到你本机用户目录的人或程序都能拿到它。生产口令请勿保存，每次手输。
2. **连接导出文件的「加密密码」只是混淆。** 导出的连接包用的是内置固定密钥，拿到文件即可还原 —— 等同于明文，不要把它当凭据载体发给别人。
3. **写操作会真实落库，且部分方言无法回滚。** MySQL / MariaDB / Oracle / 达梦的 DDL 会隐式提交，事务里 `ROLLBACK` 撤不掉已经执行的 `DROP` / `CREATE`。数据传输、导入向导、单元格编辑都是直写目标库 —— 执行前请确认目标、先备份、先在测试库上跑一遍。

## 支持的数据源

16 种类型全部已实现驱动。

| 分类 | 数据源 |
| --- | --- |
| 关系型 | MySQL、MariaDB、PostgreSQL、SQL Server、Oracle |
| 国产关系型 | Kingbase 金仓、Dameng 达梦 |
| 时序 | TDengine |
| 文件 / 嵌入式 | SQLite |
| 文档 / 缓存 | MongoDB、Redis |
| 搜索 / 分析 | Elasticsearch、OpenSearch |
| 分布式键值 / 协调 | ZooKeeper、etcd |
| 消息队列 / 流 | Kafka |

除 SQLite 外，全部支持 SSL / TLS，其中 PostgreSQL 系、Oracle、Redis、MongoDB、ZooKeeper、etcd、Kafka、Elasticsearch / OpenSearch、TDengine 还能指定 CA 证书与客户端证书（mTLS）。

> 阿里云 RDS / PolarDB / OceanBase 等托管变体不作为独立类型出现，用对应内核类型连接、自行填写连接参数即可；早期版本存下的 `aliyun-*` 连接仍可正常读取。

## 功能

### 连接管理
- 分组树管理，支持嵌套分组、拖拽排序、重命名
- 连接向导按类型给默认值（端口 / 用户名），带「测试连接」
- 连接配置导入 / 导出（可连同分组结构，可选是否带密码）
- 未保存密码的连接在打开时弹窗询问，空密码与「没存过」分开处理

### 浏览与对象树
- 库 / 模式 / 表 / 视图 / 物化视图 / 函数 / 存储过程 / 索引 / 触发器 / 序列 / 角色 分层展开，惰性加载
- 系统对象是否显示可开关
- 对象右键：查看结构、查看 DDL、数据浏览、转储、新建 / 设计 / 删除 / 重命名 / 清空

### SQL 工作台
- 多标签编辑器，SQL 语法高亮（`re_editor` + `re_highlight`）
- 关键字 / 表名 / 列名自动补全，补全条目数可配置
- SQL 美化（缩进档位 2 / 4 / 8）、多语句拆分执行
- 执行计划：按方言自动拼 `EXPLAIN`（MySQL / MariaDB / PostgreSQL / SQLite / TDengine）
- 结果网格：分页、行数上限可配（默认 1000，可设不限）、列宽自适应、单元格查看与复制
- 查询结果直接导出为文件
- 查询历史归档

### 表数据浏览 / 编辑
- 服务端分页（`COUNT(*)` + `LIMIT/OFFSET`），页大小 10 ~ 500 可调
- 排序 / 筛选下推到 SQL：点击表头排序（Ctrl / Shift 追加多列），「筛选与排序」向导支持等于、不等于、大于 / 小于、包含、开头是、为 NULL、在列表中、介于等条件，条件间可选并且 / 或者
- 单元格双击就地编辑，批量生成 `UPDATE` / `DELETE` / `INSERT` 后提交
- 行头勾选框支持多行选中，右键「复制为」制表符 / CSV / 含栏位名 / SQL 语句，或「导出所选」
- 视图 / 物化视图自动进入只读模式，编辑入口不显示

### 表结构设计
- 新建表 / 修改表：列类型下拉随方言变化，主键、非空、默认值、注释、自增
- 索引、外键、触发器、约束管理
- ALTER 语句按方言生成并预览，支持一次提交多条变更

### 导入 / 导出 / 传输
- **导出**：CSV、TSV、JSON、SQL（INSERT）、XML、HTML 表格、Markdown 表格 —— 流式写出，内存占用与表大小无关
- **导入**：CSV、TSV、JSON、XML、HTML、Markdown —— 带字段映射、跳行、修剪、批量提交、可选先清空表，预览即所导
- **转储**：库 / 模式 / 表导出为 SQL 文件，可选是否带数据、是否带索引与外键
- **数据传输**：跨库「表 → 表」迁移，自动做列类型映射，两端可以是完全不同类型的数据库

### 各类存储的专属视图
- **Redis**：键列表（前缀分层树，分隔符可配）、键值查看（多种格式化）、命令行控制台、发布 / 订阅、服务器信息
- **MongoDB**：集合 / 文档浏览与编辑、索引管理、用户管理、控制台、服务器信息
- **Elasticsearch / OpenSearch**：文档检索、mapping、索引信息、别名、集群信息、索引模板、快照、ILM、SQL 查询、分词分析、REST 控制台
- **Kafka**：主题、分区消息、消费组、Broker 列表、服务器信息
- **ZooKeeper / etcd**：节点树、节点详情、watch、控制台、服务器信息

### 快速命令
顶部工具栏的「快速命令」打开一页命令行，按当前连接类型分派到对应驱动：关系库执行 SQL、Redis 执行 RESP 命令、MongoDB 执行库语句、ZooKeeper / etcd 执行元命令（如 `ls`、`get`）。

它不是 shell —— 不拉起本机客户端、没有 PTY，输出以等宽文本流呈现。Kafka 与 Elasticsearch / OpenSearch 不支持该入口（分别走「主题」页与 REST 控制台），工具栏上不会显示该按钮。

### ER 图
- 新建、设计、导出数据库模型图

### 其他
- 活动日志：所有执行的语句与结果统一记录
- 6 套主题：暗色「夜航 / 墨松 / 炉火」，亮色「晴雪 / 宣纸 / 湖光」，配套 SQL 语法配色
- 首选项：结果行数上限、分页大小、缩进、补全条数、键扫描条数等集中管理
- 「无显卡模式」：关掉阴影模糊、毛玻璃与鼠标跟随高亮，供软件光栅化环境使用

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl/Cmd + W` | 关闭当前标签（光标在输入框内时让给编辑控件的「删除前一个词」） |
| `Ctrl/Cmd + Shift + W` | 关闭全部标签 |

数据网格中点表头排序时，`Ctrl` / `Shift` 用于追加排序列。

## 本地数据存放

| `model_vault.json` | 已保存的 ER 模型 |
