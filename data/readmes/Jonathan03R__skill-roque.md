# Skills Roque

Guías de trabajo de Jonathan Roque para desarrollar backends Node.js, APIs, proyectos Go con DLL C-shared y esquemas SQL/Supabase.

## Backend Node.js

Cuando se cree un backend Node.js nuevo, revisa y usa [Roque-stack](https://github.com/Jonathan03R/Roque-stack) como referencia de estructura y generación. Es un CLI en TypeScript que crea proyectos Express y módulos por feature. Antes de aplicarlo, consulta su código y contratos actuales. Para endpoints y contratos HTTP, lee también `skills/apis-roque/SKILL.md`.
