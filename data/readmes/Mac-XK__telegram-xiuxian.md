# 修仙 · Telegram 修仙游戏

一个跑在 Telegram 上的修仙文字游戏：玩家私聊机器人，点开 Mini App 修炼、历练、斗法、炼丹、逛坊市；游戏群里有天降机缘、论道问答、渡劫围观、门派小比、世界妖王等群活动。附带一个网页后台，用来管理玩家、开关活动、发补偿。

- 后端：纯 PHP（不用框架、不用 Composer），数据库 MySQL / MariaDB。
- 前端：Telegram Mini App（`xiuxian/index.html`，单文件）。
- 独立 iOS App（可选）：Cocos Creator 3.8.8 工程在 `xiuxian-client/`，怎么打开、打包见 [xiuxian-client/README.md](xiuxian-client/README.md)；接口文档在 `docs/xiuxian-app-api.md`。

## 一、需要准备什么

| 东西 | 要求 |
|---|---|
| 服务器 | Linux，能装宝塔就行（作者线上用的是 2 核 2G） |
| 域名 | 一个解析到服务器的域名，**必须能开 HTTPS**（Telegram 只认 HTTPS） |
| PHP | **8.1 或更高**，需要扩展 `pdo_mysql`、`curl`、`openssl`、`mbstring`（宝塔装的 PHP 默认都有） |
| 数据库 | MySQL 或 MariaDB，宝塔默认装的版本就可以 |
| Telegram 账号 | 用来创建机器人 |

不需要 Composer、Node.js，也不需要给任何目录写权限。

## 第 1 步：创建 Telegram 机器人

1. 在 Telegram 里搜索 **@BotFather**，发送 `/newbot`。
2. 按提示起名字，再起一个以 `bot` 结尾的用户名（例如 `my_xiuxian_bot`）。
3. BotFather 会回一串 **Token**，形如 `1234567890:AAH...`。**先复制保存好，不要发给别人**，后面第 6 步要用。
4. 继续给 BotFather 发 `/setprivacy`，选择你的机器人，再选 **Disable**。

   > 关掉隐私模式，机器人才能看到群里的普通聊天，例如有人说「修仙」、抢机缘口令、问答的答案。不关的话，群活动基本都不会响应。

---

## 第 2 步：准备网站

1. 宝塔 →「网站」→「添加站点」：
   - 域名：填你的域名，例如 `xiuxian.example.com`
   - PHP 版本：选 **8.1** 或更高
   - 数据库：这里可以不建，第 3 步单独建
2. 站点建好后 → 点「设置」→「SSL」→ 选 Let's Encrypt 申请证书 → 打开「强制 HTTPS」。
3. 浏览器打开 `https://你的域名`，能看到宝塔默认页、地址栏有小锁，就说明 HTTPS 好了。

> **不用宝塔**：用 Nginx 或 Apache + PHP-FPM 建一个站点，站点根目录就是本项目的根目录，再用 certbot 等工具配好 HTTPS。

---

## 第 3 步：创建数据库

1. 宝塔 →「数据库」→「添加数据库」：
   - 数据库名、用户名：自己起，例如都叫 `xiuxian`
   - 密码：用它生成的随机密码就行
   - 编码选 **utf8mb4**
   - **记下数据库名、用户名、密码**，第 4 步要填。
2. 在数据库列表里找到刚建的库 →「导入」→ 上传本项目里的 **`install.sql`** → 导入。

   导入后库里会多一张 `system_settings` 表，是存设置用的。游戏自己的 50 张表不用手动建，第一次访问时会自动建好。

> **不用宝塔**：
> ```bash
> mysql -u root -p -e "CREATE DATABASE xiuxian CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
> mysql -u root -p xiuxian < install.sql
> ```

## 第 4 步：上传代码、填写配置

### 4.1 上传

把本仓库的文件上传到站点根目录（宝塔 →「文件」→ 进入 `/www/wwwroot/你的域名/` → 上传 ZIP 后解压）。`xiuxian-client/` 是 App 客户端的源码，**不用上传**。宝塔自动生成的 `index.html`、`404.html` 可以删掉，`.user.ini` **不要删**。

上传完，站点根目录应该是这样：

```
/www/wwwroot/你的域名/
├── admin/
├── api/
├── Class/
├── config/
├── docs/
├── static/
├── xiuxian/
├── install.sql
└── README.md
```

注意：`admin`、`api` 这些文件夹要直接在站点根目录下，不要多套一层文件夹。

### 4.2 生成两个密钥

宝塔 →「终端」（或 SSH 登录服务器），执行下面两条命令。`/www/server/php/81/bin/php` 是宝塔 PHP 8.1 的路径，装的是别的版本就把 `81` 换掉。

```bash
# ① APP_KEY：加密用的随机串，复制输出的 64 位字符
/www/server/php/81/bin/php -r 'echo bin2hex(random_bytes(32)), PHP_EOL;'

# ② 后台密码的 hash：把最后的「你的后台密码」换成你想用的密码，复制输出的 $2y$ 开头那一串
/www/server/php/81/bin/php -r 'echo password_hash($argv[1], PASSWORD_DEFAULT), PHP_EOL;' '你的后台密码'
```

> 配置里存的是 hash，不是密码本身。登录后台时输入的是你上面设的那个密码。

### 4.3 填写配置

把 `config/config.local.example.php` **复制一份**，改名为 `config/config.local.php`，然后打开编辑：

```php
return [
    'database' => [
        'dsn' => 'mysql:host=127.0.0.1;dbname=xiuxian;charset=utf8mb4',  // 把 xiuxian 换成你的数据库名
        'username' => 'xiuxian',          // 数据库用户名
        'password' => '数据库密码',
    ],
    'app_key' => '第 4.2 步 ① 生成的 64 位字符',
    'admin_password_hash' => '第 4.2 步 ② 生成的 $2y$ 开头那串',
    'base_url' => 'https://你的域名',     // 末尾不要带 /
];
```

- `app_key` 设好以后**不要再改**：后台保存的机器人 Token 是用它加密的，改了就要重新填一次 Token。
- `config.local.php` 已经写在 `.gitignore` 里，不会被提交到 Git。**千万不要把它传到公开的地方。**

### 4.4 检查

浏览器打开 `https://你的域名/api/xiuxian-webhook.php`，看到下面这行就说明 PHP 正常运行：

```json
{"ok":true,"service":"Xiuxian Webhook"}
```

## 第 5 步：禁止外人访问配置目录

`config/` 里有数据库密码，必须禁止从网页访问。

- **宝塔 / Nginx**：网站 →「设置」→「配置文件」，在 `server { ... }` 的大括号里面加三行（放在哪一行都可以），保存：

  ```nginx
  location ^~ /config/ { deny all; }
  location ^~ /Class/  { deny all; }
  location ^~ /docs/   { deny all; }
  ```

- **Apache**：`config/` 和 `Class/` 里已经带了 `.htaccess`，不用另外配置。

检查：打开 `https://你的域名/config/config.local.php`，应该显示 **403 Forbidden**。

## 第 6 步：登录后台，连接机器人

1. 打开 `https://你的域名/admin/`，输入第 4.2 步设的后台密码登录。

   > 第一次打开会自动建游戏表，可能要等几秒。连续输错 5 次密码会锁 15 分钟。

2. 进入「**概览设置**」标签，在「基础设置」里：
   - **游戏机器人 Token**：粘贴第 1 步拿到的 Token
   - **游戏群 Chat ID**：先留空（留空 = 所有群都能玩），第 7 步再说
   - 其他保持默认
   - 点「**保存设置**」

3. 在下面的「部署」区域点「**设置 Webhook**」。

   成功后页面顶部会提示「Webhook 已设置：@你的机器人…」，标题旁也会显示 `@你的机器人`。这一步做了三件事：
   - 让 Telegram 把消息推到你的服务器
   - 注册机器人菜单命令
   - 在私聊输入框左边加一个「修仙」按钮，点它就能打开 Mini App

> 以后换了域名，先改 `config.local.php` 里的 `base_url`，再回来点一次「设置 Webhook」。

---

## 第 7 步：把机器人拉进游戏群

1. 把机器人加进你的 Telegram 群，**设为管理员**，至少勾上「删除消息」权限（机器人要定时清理群里的游戏消息，免得刷屏）。
2. 如果第 1 步关隐私模式之前机器人就已经在群里了，**把它踢出去再重新拉进来**，新的隐私设置才会生效。
3. （可选）只允许指定的群玩：
   1. 拿到群的 Chat ID，两种办法任选：
      - 电脑浏览器打开 <https://web.telegram.org/a/> 并进入这个群，地址栏 `#` 后面那串 `-100` 开头的数字就是。
      - 把 **@RawDataBot** 拉进群，它会回一段 JSON，`"chat"` 里的 `"id"` 就是；拿到后把它踢出去。
   2. 填到后台「游戏群 Chat ID」里，多个群用英文逗号隔开，保存。
   3. 不填就是所有群都能玩。私聊不受这个限制，永远能玩。

**群消息自动删除秒数**默认 60：玩家在群里发的 `#` / `/` 游戏命令，60 秒后自动删掉，免得刷屏；填 0 就不删。

## 第 8 步：添加计划任务

门派小比、拍卖会、世界妖王、天降机缘、论道问答这些活动要**准时开始**，需要每分钟跑一次计划任务。

宝塔 →「计划任务」→ 添加，两种方式选一种：

**方式一（推荐）：Shell 脚本**

- 执行周期：**每 1 分钟**
- 脚本内容：
  ```bash
  /www/server/php/81/bin/php /www/wwwroot/你的域名/api/xiuxian-cron.php > /dev/null
  ```

**方式二：访问 URL**

- 执行周期：**每 1 分钟**
- 地址：到后台「**活动管理**」标签复制那条带 `?key=` 的地址（key 是计划任务专用的密钥，可以在那里重新生成）

检查：过一两分钟刷新「活动管理」，「最近一次计划任务」应该显示刚才的时间。

> 没配计划任务游戏也能玩，只是活动不会准时开场：机器人收到消息时会顺手检查一次，最多 30 秒一次。

---

## 第 9 步：开放游戏，自己先玩一下

1. 后台「概览设置」→ 勾选「**开放游戏**」→ 保存。

   > 没勾的时候，机器人收到任何消息都**不会回复**。

2. 打开 Telegram，私聊你的机器人，发 `/start`。
3. 机器人回一条带「**进入修仙**」按钮的消息，点开就是 Mini App。按提示测灵根、选门派，入道成功就说明全部搭好了。
4. 去游戏群里说一句「修仙」，机器人会回一个「进入修仙」按钮，说明群也通了。

**到这里就搭建完成了。** 🎉

## 玩家怎么玩

- **主要玩法都在 Mini App 里**：私聊机器人，点输入框左边的「修仙」按钮，或者发 `/start` 后点「进入修仙」。里面有修炼、闭关、突破、历练、任务、坊市、背包、法器、灵兽、药园、炼丹、制符、斗法、结伴秘境、寄售行、排行榜等。
- **聊天里的命令**：以 `#` 或 `/` 开头，例如 `#闭关`、`#坊市`、`#斗法`。命令本身不执行操作，只回一个按钮，点开直接进 Mini App 里的对应页面。私聊里随便发什么，机器人都会回入口按钮。
- **游戏群里**：
  - 天降机缘：群里会不定时掉机缘，点按钮、说出口诀或发 `/jiyuan` 来抢
  - 有人说话里带「修仙」：机器人回一个入口按钮，同一个人 10 分钟内只回一次
  - 渡劫围观：有人大境界突破时，群里会挂劫云，群友可以点「助劫」或「落井下石」
  - 论道问答：定时出题，直接在群里回答
  - 小比、大比、拍卖会、世界妖王的开场和结果，都会在群里公告
- 活动时间都按**北京时间**算。

## 后台怎么用

后台地址：`https://你的域名/admin/`，一共五个标签：

| 标签 | 能做什么 |
|---|---|
| 概览设置 | 玩家数、境界和门派分布；开放 / 维护开关、Token、群 ID、修炼 / 灵石 / 掉落倍率、血色禁地开放方式；设置 Webhook；给所有游戏群推公告；**清档**（会先自动备份，可以从备份恢复） |
| 玩家管理 | 搜索、筛选（封禁、测试账号、闭关中等）；改灵石 / 贡献 / 修为、发物品、设境界、调单人突破率和修为倍率、改灵根、封禁、设为测试账号、删除角色 |
| 活动管理 | 计划任务状态和地址；各活动开关和参数（小比、大比、拍卖、妖王、黑市、赌坊、宗门战、机缘、问答、天道、渡劫）；测试用的「立即举行」 |
| 全服补偿 | 给某个境界范围内的玩家发灵石、贡献、物品，玩家下次操作时自动到账 |
| 坊市 / 寄售 | 改坊市商品的价格和限量；查看寄售行，强制下架违规物品 |

几点说明：

- **维护模式**：玩家的所有操作只会收到维护提示。更新代码时可以先打开。
- **测试账号**：能正常玩，但不上排行榜、不出现在江湖列表里、交易和斗法不留记录，适合管理员自己试玩。
- **游戏管理员 TG ID**：选填，目前只用于玩家管理里的「游戏管理员」筛选。想查自己的 TG ID，私聊 **@userinfobot**。
- 清档、恢复备份、删除角色这几个不可撤销的操作，都要再输一次后台密码。

## 更新代码

1. 建议先备份数据库（宝塔「数据库」→「备份」）。
2. 后台打开「维护模式」（可选）。
3. 用新代码覆盖站点目录里的文件，**不要覆盖 `config/config.local.php`**。
4. 打开一次后台或游戏，数据库会自动升级到新版本。
5. 关掉维护模式。

## 常见问题

**后台提示「加载失败」，并且带 `system_settings` doesn't exist**
没导入 `install.sql`，回到第 3 步导入。

**后台提示数据库连接失败（`SQLSTATE[HY000] [1045]` 之类）**
`config.local.php` 里的数据库名、用户名、密码填错了。

**私聊机器人没有任何回复**
按顺序检查：
1. 后台是否勾了「开放游戏」。
2. 有没有点过「设置 Webhook」。
3. 浏览器打开 `https://api.telegram.org/bot<你的Token>/getWebhookInfo`，看 `url` 是不是你的域名；如果有 `last_error_message`，按它的提示排查（多数是证书或 HTTPS 的问题）。

**私聊有反应，群里没反应**
- 机器人的隐私模式没关，或者关了之后没重新拉进群（第 1、7 步）。
- 后台填了「游戏群 Chat ID」，但没包含这个群。
- 机器人不是管理员，或者没有删除消息权限。

**点「进入修仙」提示需要 HTTPS**
`base_url` 没填，或者填的不是 `https://` 开头。改好后再点一次「设置 Webhook」。

**活动没有准时开始**
计划任务没配好。看后台「活动管理」里「最近一次计划任务」的时间，第 8 步再检查一遍。

**点「设置 Webhook」时提示「解密失败」**
`app_key` 被改过，旧 Token 解不开了。在后台重新填一次机器人 Token，保存后再点「设置 Webhook」。

**后台登录提示「密码错误次数过多」**
15 分钟内输错 5 次会锁定，等 15 分钟再试。忘了密码就按第 4.2 步重新生成 hash，替换掉 `config.local.php` 里的旧值。

## 项目结构

| 路径 | 作用 |
|---|---|
| `install.sql` | 全新安装时导入一次（建 `system_settings` 表） |
| `config/bootstrap.php` | 公共函数：数据库连接、读写设置、缓存、加解密、CSRF |
| `config/config.local.example.php` | 配置模板，复制成 `config.local.php` 再填 |
| `Class/Xiuxian*.php` | 游戏逻辑。入口是 `XiuxianBot.php`（机器人）和 `XiuxianWebApp.php`（Mini App）；建表和升级在 `XiuxianCore.php` 的 `ensure_xiuxian_schema()` |
| `api/xiuxian-webhook.php` | 接收 Telegram 推送 |
| `api/xiuxian-app.php` | Mini App 和独立 App 调用的接口 |
| `api/xiuxian-cron.php` | 计划任务，每分钟一次 |
| `admin/index.php` | 后台登录和页面框架 |
| `admin/xiuxian.php` | 后台各标签的具体页面 |
| `xiuxian/index.html` | Mini App 前端（单文件） |
| `static/js/lucide.min.js` | 后台图标库 |
| `docs/xiuxian-design.md` | 玩法和数值设计文档 |
| `docs/xiuxian-app-api.md` | 独立 App 的登录和接口文档 |
| `xiuxian-client/` | 独立 iOS App 客户端（Cocos Creator 3.8.8），只在本机打包，不上传服务器。打包前把 `assets/scripts/Config.ts` 里的 `API_BASE` 改成你的域名 |

数据说明：

- 游戏表都以 `xx_` 开头，共 50 张，代码里的 `XX_SCHEMA_VERSION` 一变就自动升级。
- 设置存在 `system_settings` 表，键名是 `xiuxian.*`；缓存是 `cache.xx_*`、`cache.xiuxian_rank.*`。
- 时区固定为北京时间（`Asia/Shanghai`）。

开发时注意：**服务器是 PHP 8.1，不要用 8.2 以后才有的语法。**
