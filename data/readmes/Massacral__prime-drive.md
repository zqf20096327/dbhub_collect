# 🚗 Prime Drive — Plataforma de Mobilidade Urbana

### Projeto Full Stack | React • Node.js • TiDB

O **Prime Drive** é uma plataforma de mobilidade urbana desenvolvida de forma independente para conectar passageiros e motoristas. O projeto reúne interfaces responsivas, gerenciamento de corridas e funcionalidades de acompanhamento e gestão para os dois perfis.

## 🎯 Objetivo

Desenvolver uma solução de transporte por aplicativo com experiências próprias para passageiros e motoristas, regras de negócio e estrutura para integração de pagamentos digitais.

## 🚀 Funcionalidades demonstradas

- Cadastro e autenticação com perfis de passageiro e motorista
- Mapa e localização nas interfaces de corrida
- Solicitação e estimativa de viagem
- Disponibilidade do motorista para receber corridas
- Carteira, histórico e acompanhamento de ganhos
- Interface responsiva com opção de instalação PWA

**Em desenvolvimento:** integração de pagamentos Pix/cartão e automação de repasses. As funcionalidades apresentadas podem estar em fase de testes.

## 🛠️ Tecnologias

- **Frontend:** React, JavaScript, HTML5, CSS3
- **Backend:** Node.js, API REST
- **Banco de dados:** TiDB (compatível com MySQL)
- **Infraestrutura:** Render
- **Versionamento:** Git e GitHub
