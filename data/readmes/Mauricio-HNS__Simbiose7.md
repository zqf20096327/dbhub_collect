# Simbiose7

## Destiny7 Software Solutions

Simbiose7 is a database development and management platform focused on connecting to multiple database engines through a unified desktop experience.

### Product

- Product: Simbiose7
- Company: Destiny7 Software Solutions
- Repository: Mauricio-HNS/Simbiose7
- License: Apache-2.0

### Capabilities

- Multi-database connectivity
- SQL editor and query tooling
- Schema and data exploration
- Redis and MongoDB tooling
- AI-assisted database workflows
- MCP integration
- Desktop, CLI and web components
- Database drivers and plugin extensibility

### Technology

- Tauri 2
- Vue 3
- TypeScript
- Rust
- CodeMirror
- SQLx and database-specific drivers

### Development

Requirements:

- Node.js 22+
- pnpm 10+
- Rust toolchain

Install dependencies:

```bash
pnpm install
```

Run development:

```bash
pnpm dev:tauri
```

Run checks:

```bash
pnpm check
```

Build:

```bash
pnpm build:checked
```
