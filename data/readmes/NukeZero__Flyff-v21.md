# 📜 FlyFF v21 Source (Archived)

🛡️ This repository serves as a **finalized, archived release of the FlyFF v21 source project**. 

🔍 This project was established by the NukeZero development collective to provide a collaborative, high-quality development foundation. It represents the culmination of efforts from the team that evolved the original Lodelight project, bringing that collective experience into an open-source framework.

---

### 📂 Project Overview
This project was designed as an open-source initiative, focusing on community-driven development and quality improvements. It integrates various public and private fixes to provide a more stable and functional base for developers.

> **Note:** This repository is now **read-only/archived**. It is provided as-is, and no further updates, bug fixes, or maintenance will be provided by the development team.


### 🛠️ Technical Specifications
To maintain compatibility with this source, developers should use the following environments:

* 💻 **Compiler:** Visual Studio 2026 Community
* 💾 **Database:** Microsoft SQL Server 2019
* ⚙️ **Scripting:** Lua

### ⚠️ Security & Usage Notice
This source is provided for educational and archival purposes only. Users are responsible for performing their own security audits, as this code includes a variety of community-sourced fixes and modifications.
