## Hi, I'm Ruilin 👋

I'm a software engineer at Alibaba Cloud, working on the PolarDB-X control plane. Outside work, I learn modern LLM and agent systems by reading source code, reproducing training pipelines, and building small systems from scratch.

### What I'm exploring

- 🧠 **End-to-end LLM training** — tokenization, pretraining, SFT, evaluation, and inference through hands-on study of `NanoChat` and `MiniMind`.
- 🔬 **LLM post-training** — `PPO`, `GRPO / RLVR`, `DPO`, and on-policy distillation (`GKD / OPD`), with an emphasis on connecting the algorithm to the rollout, reward, and update data flow.
- 🤖 **Agent systems** — building a Claude Code-style agent harness to understand agent loops, tool use, context engineering, memory, subagents, and recovery mechanisms.
- 🔎 **Agentic RL** — experimenting with search agents and long-horizon training loops through `Search-R1`-style projects.
- 🧩 **Applied AI** — turning the underlying ideas into reproducible RAG and task-oriented agent applications.
