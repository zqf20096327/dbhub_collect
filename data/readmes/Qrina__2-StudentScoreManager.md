##此项目为本人课设，用 SQL + JavaWeb 搭建的高校成绩管理系统，没改过直接po上来了：  
##技术栈  
数据库：openGauss 3.1.1  
后端：JavaWeb + DAO + Druid 连接池，IDEA 开发  
安全：SM3 密码哈希 + 角色权限拦截  
前端：Bootstrap + JSP  

##已实现功能  
三级登录：学生、教师、管理员，账号自动生成，密码加盐哈希。  
成绩流：教师录入 → 触发器同步更新“已修学分”→ 视图实时算绩点 / 排名 / 平均分。  
统计页：  
按学年/课程/班级 一键查平均成绩、最高最低、柱状图。  
学生个人页自动显示已修学分、各学年 GPA、专业排名。  
批量导入：下载模板 Excel → 上传 → 秒级写入数据库，重复学号自动跳过并提示。  
安全兜底：  
删除学生级联删除成绩；删除教师级联删除授课；外键 + 触发器双保险。  
所有查询用 PreparedStatement，无 SQL 注入缝隙
