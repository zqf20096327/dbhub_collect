# dsh-life-planner

DSH Desktop 的**任务计划 + 学习模式**插件：任务树、日历、看板、学习工作区、错题与习惯都在同一个本地应用里，资料和记录保存在本机 SQLite。今日建议可通过 DSH 调用 DeepSeek。

当前版本 **0.9.40**，要求 **DSH ≥ 0.2.1-rc.4**。运行时 Node 22 系列需 **22.16.0** 或更新版本，其他版本需 **23.8.0** 或更新版本。
Windows 与 macOS 使用同一份发行包。macOS 通知、PDF 取文、书架去重、无边框窗口拖动、日历折叠均已内置。

界面自带一张随包分发的默认背景图（`plugin/assets/default-background.webp`，1920×1080 webp），装好即有背景。

---

## ⚠️ 安装前必读：两个 bundle 都要装

| 目录 | 包名 | 提供什么 | 只装它会出现什么 |
|---|---|---|---|
| `plugin/` | `@local/dsh-life-planner` | 宿主逻辑、规划页、学习页、43 个工具 | 能打开页面，但**新建会话里没有「学习模式」预设** |
| `study-preset/` | `@local/dsh-study-preset` | **「学习模式」会话预设（`study-teach`）** | 能看到「学习模式」，但没有页面与工具，对话会报工具不存在 |

> 安装完成后必须**重启 DSH**。只刷新页面不会注册预设。

## 安装

### 方式 A：插件管理器（推荐）

1. 打开 DSH → 设置 → 插件 → 「从本地安装」。
2. 安装 `plugin` 目录，**再安装 `study-preset` 目录**。
3. **重启 DSH**。

### 方式 B：手动安装

1. 两个目录放进 profile 的 `node_modules/@local/`（复制或软链接）。
2. 在 profile 的 `package.json` 中，把**两个包名**都写进 `dsh.profile.bundles` 与 `dependencies`
   （`link:` 指向两个目录）。
3. 在 profile 目录执行 `pnpm install`；若插件目录缺依赖，再在 `plugin/` 执行一次 `pnpm install --prod`。
4. **重启 DSH**。

### macOS

安装步骤相同，不需要额外补丁：

- 系统通知走 `osascript`（Electron 在 Host 进程不可用时的回退）；
- PDF 取文优先 `pdftotext`，没有时用系统 PDFKit；
- 书架去重用 `realpath` + NFC，适配 APFS；
- 无边框窗口可拖动插件页头（页签之间的空隙与整条页头）；
- 日历折叠后可用右侧「展开日历」按钮或向上滚动展开；
- 详细检查表见[安装与排查](docs/安装与排查.md)。

## 安装后自检（5 步）

1. **设置 → 插件**：同时看到 `@local/dsh-life-planner` 与 `@local/dsh-study-preset`。
2. 已**重启** DSH。
3. **新建会话**：预设下拉里有「学习模式」。
4. 选中「学习模式」发一句话：工具里出现 `study_task_list` / `study_next_questions`。
5. 设置弹窗标题版本为 **v0.9.40**。

## 功能

### 任务计划

- **单一节点类型**：所有节点都是任务；分类由创建时的最顶层祖先决定，移动或改名不变，也可手动改。
- **四种视图**：任务树、日历、看板、已归档。
- **标签与分类库**：可增删；删除只影响候选列表，不改已有任务的数据。
- **提醒**：按工作日/周末时段、最小间隔、每日上限、顺延上限扫描；宿主在面板关闭时也会尝试发送系统通知。
- **批量操作**：多选归档/完成、拖拽改期、键盘操作。

### 学习模式

- **学习对话**：选用「学习模式」预设的会话自动登记学习任务，按工作区知识库出题、批改、记进度。
- **三种知识库**：
  - **列表库 `list`**（原 `word-bank`）：单词/术语卡片，选择题带干扰项；
  - **知识树 `tree`**（原 `outline`）：章节 → 知识点；
  - **题库 `bank`**（原 `outline-bank`）：知识树 + 题目库，题目按覆盖的知识点分类，答题同时推进知识点。
  - 另有 `custom`；旧模板 id 自动归一。
- **新学 / 复习分离**：每日目标分两段，两段都达标才算完成；新内容取未学过的条目，复习按熟练度从弱到强。
- **熟练度 0–10**：答对 +1、答错 −1；满 10 视为掌握并移出错题；到 0 仍每天出题，但 3 天内答对不加分。
- **书架**：文件、递归目录、网址；目录递归列出（上限 800 项，超出有「已截断」标记）；可挂到学习任务。
- **错题集**：默认随机排序，筛选后按时间倒序，可编辑与删除；掌握后自动清理。
- **学习规划与习惯**：学习任务可定时开始并发通知，可关联到科目；习惯页汇总近 14 天的学习对话时长和任务完成情况。

### 外观

- 内置默认背景图；可切换纯色/无背景，调整不透明度与蒙版。
- 8 档字号、行高与标签高度联动；面板透明度；皮肤命名保存、导入导出。
- **弹窗（设置、新建/编辑、确认卡）使用独立不透明度（约 97%）与更深的遮罩**，不受面板透明度影响。
- 外观与皮肤存宿主 `ui_state`，重启不丢。

## 使用

- **规划页**：任务树新建/拖拽/多选；日历改期（向下滚动折叠日历、向上滚动或点「展开日历」恢复）；看板看状态；归档页恢复或清理。
- **学习页**：今日学习、学习规划、书架、错题集、习惯五个页签。
- **窗口拖动**（macOS 无边框）：拖动插件页头空白处或页签间隙即可移动窗口；页签仍可正常点击。
- **数据位置**：`~/.dsh/life-planner/`；每个学习对话的知识库在工作区 `learning/knowledge.db`。
- **备份/迁移**：设置 → 导出/导入。

## 隐私

- 规划、书架、错题和皮肤保存在本机。自动学习建议会把任务摘要、学习目标和习惯统计交给 DSH 的 DeepSeek 模型，地区自动识别、天气和节假日分别使用外部查询。
- 「规划 → 日历」标题栏的天气按钮可查看公历、农历、天气和生活建议。日历默认在当地时间中午 12 点更新。可在「设置 → 通用设置」手填或锁定地区、切换日历刷新方式，以及关闭 DeepSeek 学习建议。
- 系统通知默认开启，可在设置里关闭。

## 配置

| 配置 | 说明 |
|---|---|
| `studyMode` | 学习工具总体开关（关闭后隐藏全部 `study_*` 工具） |
| `studyPanel` | 学习页面开关（关闭后学习写操作返回 403，读取返回空结构） |

插件级配置修改后需要重启 DSH；会话级开关即时生效。

## 开发

```bash
# 在 plugin/ 下
node build-client.mjs      # 生成 client.js（唯一产物，禁止手改）
node --check index.js
node --check client.js
node test/smoke.mjs        # 43 工具、路由、学习/计划/树完整性
node test/smoke-client.mjs # 插槽、构建顺序、组件结构
```

真实运行时探测（可选，需要 DSH 的 Electron 以 Node 模式运行）：

```bash
ELECTRON_RUN_AS_NODE=1 "<DSH 可执行文件>" plugin/test/tools/runtime-probe.mjs
```

更多细节见 [docs/README.md](docs/README.md)。

## 已知限制

- 学习日按**凌晨 04:00** 切分；日历与提醒按自然日。
- 书架目录列表上限 800 项（复制到学习工作区时仍全量）。
- 工具权限：会话开关或学习模式预设 = 全部 43 个工具。
- **桌面通知**：DSH 运行时，宿主会通过系统通知发送。Windows 使用通知区域，macOS 使用 `osascript`，Linux 可用 `notify-send`。显示仍受系统通知设置影响。
- **PDF**：扫描件需 OCR；Windows/Linux 需要 `pdftotext`。
- macOS 27 的安装、系统通知和 PDFKit 回退仍待 Apple Silicon 实机验证。
