# 药店管理系统

基于OpenGauss数据库的连锁药店管理系统，实现药店管理员和销售员用户的管理，药品信息管理以及销售功能。

## 功能特性

系统用户角色和功能：

1. **系统管理员**：
   - 管理药店管理员和销售员用户（增、删、改）
   - 数据分析功能：
     - 库存预警监控（可设置处方药和非处方药的预警阈值）
     - 销售趋势分析和可视化
     - 药品库存状态实时监控
     - 销售业绩统计和图表展示
2. **药店管理员**：管理药品信息（增、删、改）
3. **销售员**：查询药品（包括精确和模糊搜索）并销售药品

## 技术架构

- 后端：Python + Flask
- 数据库：华为OpenGauss
- 前端：Bootstrap 5 + HTML/CSS/JavaScript

## 安装步骤

### 前提条件

- Python 3.6或更高版本
- Docker（用于运行OpenGauss数据库）
- psycopg2库（PostgreSQL数据库适配器）

### 安装流程

1. 克隆代码仓库：

```bash
git clone https://github.com/RoschildRui/OpenGauss_practice.git
cd OpenGauss_practice
```

2. 安装所需Python库：

```bash
pip install flask psycopg2-binary
```

3. 启动OpenGauss数据库：

```bash
# 使用脚本运行OpenGauss Docker容器
sh gauss_run.sh
```

4. 初始化数据库：

```bash
# 运行初始化脚本创建数据库表结构
python init_table.py
```

## 运行系统

启动应用服务器：

```bash
python app.py
```

在浏览器中访问：`http://localhost:5000`

## 系统用法

### 系统管理员

1. 使用系统管理员账号登录
2. 添加、编辑和删除药店管理员
3. 添加、编辑和删除销售员
4. 数据分析功能：
   - 在仪表板查看实时库存预警信息
   - 设置处方药和非处方药的库存预警阈值
   - 查看销售趋势图表
   - 分析药品销售情况
   - 监控各药店库存状态

### 药店管理员

1. 使用药店管理员账号登录
2. 添加、编辑和删除药品信息
3. 管理药品库存
4. 添加药店并关联药品

### 销售员

1. 使用销售员账号登录
2. 选择药店查看药品库存
3. 搜索药品（支持药品名称、拼音码或生产厂家搜索）
4. 将药品添加到购物车
5. 完成销售交易
6. 查看销售历史记录和详情

## 数据库结构

系统主要数据表：

- admin：系统管理员表
- pharmacy_manager：药店管理员表
- salesperson：销售员表
- pharmacy：药店表
- medicine_category：药品分类表
- medicine：药品信息表
- sales_record：销售记录表
- sales_detail：销售详情表

## 常见问题解决

### 连接数据库错误

如果出现数据库连接错误，请检查：

1. OpenGauss容器是否正在运行
2. 连接参数（主机、端口、用户名、密码）是否正确
3. 是否已执行初始化脚本创建必要的数据库结构

### 销售药品问题

如果销售药品时遇到问题：

1. 确保已选择正确的药店
2. 检查药品库存是否充足
3. 验证购物车中的药品是否都属于同一个药店
4. 确保销售员账号有效且已正确登录

### 登录问题

如果无法使用默认账户登录，请尝试：

1. 确认初始化脚本执行成功且没有报错
2. 检查数据库中admin表是否已包含默认用户
3. 重新执行初始化脚本

### SQL语法和占位符

系统使用psycopg2连接OpenGauss数据库，需要注意：

1. SQL参数占位符使用 `%s`而不是 `?`（与JDBC不同）
2. OpenGauss不支持某些PostgreSQL特有的语法，如 `ON CONFLICT`
3. 如遇到SQL语法错误，检查是否使用了不兼容的语法
