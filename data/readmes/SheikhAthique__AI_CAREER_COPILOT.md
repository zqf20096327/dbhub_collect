# 🚀 AI Career Copilot

AI Career Copilot is a full-stack Flask application designed to help job seekers optimize their career paths using AI. By analyzing candidate resumes against target job titles, the application identifies technical skill gaps, creates personalized learning roadmaps, and generates custom technical interview preparation questions.

---

## ✨ Features

- **🔐 User Authentication:** Secure sign-up, login, and session handling using Flask sessions and hashed passwords.
- **📄 Dual Resume Inputs:** Supports both raw text input and file uploads (`.pdf` / `.docx`).
- **🔍 Intelligent Gap Analysis:** Automatically compares candidate profiles against desired target roles (e.g., *Machine Learning Engineer*, *Backend Developer*).
- **🗺️ Actionable Roadmaps:** Generates step-by-step guidance to help users bridge identified technical skill gaps.
- **💡 Interview Preparation:** Custom AI-generated technical questions tailored to the candidate's target position.
- **📜 History Tracking:** Saves past feedback and analysis reports per user into a cloud database.

---

## 🛠️ Tech Stack

- **Backend:** Python, Flask, SQLAlchemy, PyMySQL
- **Database:** TiDB Cloud MySQL
- **AI Integration:** OpenAI API
- **Frontend:** HTML5, CSS3 (Modern Dark Theme)
