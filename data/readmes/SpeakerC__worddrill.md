# 单词练习 WordDrill

Android 单词练习 App：**英译汉 / 汉译英 / 单词默写 / 听音拼写**四种模式，内置高中 3500 词，也可以导入自己的词汇表。
无广告、无账号，词库与进度全部保存在本机；只有「检查更新」和「AI 智能解析 / AI 例句」会联网。

**当前版本 1.4.4**（versionCode 18） · 隐私说明见 [PRIVACY.md](PRIVACY.md)

目前1.0版本已经部署到web： [1.0](https://wordrill.zzlltt.xyz/) ，1.2移植工作紧张进行中。

Kotlin · 原生 View · SQLite · Material 3 · minSdk 24 / targetSdk 36

## 功能

### 练习

- **七种题型**：英译汉、汉译英、单词默写、听音拼写、听音选义、例句填词（给中文句意 + 挖空例句）、词形变化（过去式 / 常见不规则复数）。
- **混合题型**：一轮里混着出，同一轮里每道题的题型按单词 id 固定分配；关掉发音时不会出听力题，没有例句或词形的词会自动退出对应题型。
- **每日学习包**：把「到期复习 + 错题 + 新词」合成一轮，三类各自配额（默认 30 / 10 / 20），点一下直接开练。
- **三档自评**：答完题可选「认识 / 模糊 / 忘了」，直接决定下次复习时间；默认关闭，在「我的」里打开。
- **拼写诊断**：拼错时指出差几个字母、少了哪一段，以及有没有把 ie/ei、-tion/-sion、双写字母记混。
- **手势**：练习页左滑等于「我不会」，长按加星；3 秒内答对会标「⚡ 秒答」。

### 词典与发音

- **音标**：内置美式 / 英式两套 IPA，练习反馈卡、词表、词典详情都会显示；口音在「我的」里切换。
- **双语例句**：内置例句覆盖率约 92%，没有例句的词仍可手动生成（见「AI 例句生成」）。
- **固定搭配**：每个词带一条高频搭配，答题反馈里顺手看一眼。
- **易混词**：词典详情里列出拼写相近的词（adapt / adopt / adept），点进详情就能对比。
- **发音**：系统 TTS，全离线；可切美式 / 英式口音与三档语速。

### 复习与统计

- **间隔重复 + SM-2**：在 1 → 2 → 4 → 7 → 15 → 30 → 60 天的基础上引入难度系数 `ease`，认识拉长、模糊和忘了缩短；默认 ease 下曲线与旧版完全一致，升级后到期时间不会乱跳。
- **掌握度**：除了进度条，还有一条横置的四段堆叠条（新词 / 学习中 / 较熟 / 已掌握）。
- **到期量折线**：未来 7 天的复习任务用折线画出来，比柱状更容易看出堆积。
- **一年打卡热力图**：按天着色，5 档强度。
- **分题型正确率**：报告页显示最近 30 天各题型的正确率与平均用时。
- **成就徽章**：8 枚里程碑（首个词、100/500 词、连续 3/7/30 天、掌握 50 词、秒答 20 次），答完题静默判定，只解锁一次。
- **词汇量自测**：按词库前 / 中 / 后三段各抽 10 个词自评，按认识率外推词汇量。
- **考试倒计时**：填考试名和日期，练习页会按剩余未练词数反推每天该练多少。
- **打卡分享图**：报告页可生成 1080×1080 的打卡图，直接走系统分享。
- **每日一词组**：桌面小组件按日期取词，一天之内不换，跨天自动换，附带音标和一条搭配。

### 其他

- **每日复习提醒**：到点提醒你复习今天到期的单词，点通知直接开练；时间可自定。
- **已学过**：单独一页看当前词库练过的词，可按「还没掌握 / 已掌握 / 易忘」筛选，行内显示练过几次和下次复习时间。
- **生词本筛选**：可按首字母区间、词性、熟练度再筛一遍。
- **深色模式**：跟随系统深浅色。
- **快捷方式**：长按桌面图标可直接进「今日复习」「词典」「学习报告」。
- **词典**：中英文双向模糊搜索，可一键发音或直接练这个词。
- **底部导航**：界面分成「练习 / 复习 / 词库 / 我的」四个页签，切页签保留各自的滚动位置和输入。
- **抽题设置**：每轮 1–200 题，可按词库索引区间抽题，可开关「允许重复抽到已练过的词」。
- **内置词库**：高中 3500 词（3793 条）+ 大学英语四级（4543 条），含词性、释义、音标、例句与搭配；默认使用高中 3500 词。
- **自组词库**：直接选择 Markdown 文件导入（自动识别 UTF-8 / GBK），也可粘贴表格；导入时可从系统分享或「用其他应用打开」直接把文本送到导入页，导入后还能继续追加。
- **AI 智能解析**：导入页可把随便一段文字（单词列表、CSV、OCR 结果、带音标的词汇表）交给自建 AI 服务
  整理成标准表格再导入。服务端是 `netlify/functions/smart-parse.js`，背后接商汤日日新，
  部署方式见 [docs/netlify-smart-parse.md](docs/netlify-smart-parse.md)。
- **屏蔽单词**：长按词表中的单词即可屏蔽，被屏蔽的词不参与抽题，剩余单词索引自动重排，可随时恢复。
- **星标与错题**：练习页、词表都能加星标；答错自动进错题本，**连续答对 2 次**才移出；错题本支持搜索、按「最近错 / 错得最多 / 最该复习」排序、长按手动移出、一键清空。
- **练习进度**：练习页顶部显示当前词库的已练 / 总数与进度条。
- **备份与恢复**：导出 JSON（自组词库、错题、星标、打卡、练习进度、复习排期、音标与搭配），导入时与本机数据合并，不覆盖已有内容。
- **应用内更新**：启动时自动检查，有新版可在应用内下载并安装（Android 8+ 会引导授权）。

## 构建

需要 JDK 17+ 与 Android SDK（platform 36）。

```bash
git clone https://github.com/SpeakerC/worddrill.git
cd worddrill
./gradlew assembleDebug        # Windows 用 gradlew.bat assembleDebug

adb install -r app/build/outputs/apk/debug/app-debug.apk
```

APK 也可以直接从 [Releases](https://github.com/SpeakerC/worddrill/releases) 下载。

## 测试

```bash
./gradlew testDebugUnitTest
```

单元测试覆盖：出题逻辑、SQLite 数据层（Robolectric 实际运行）、Markdown 词表解析与编码识别、
间隔重复曲线、复习队列、词典搜索、每日统计、备份合并、更新清单解析、智能解析返回值清洗、界面渲染。

## 隐私

- 不注册、不收集个人信息；词库、错题、打卡、进度只存在本机，卸载即删除
- 联网只有三处：检查更新、下载更新包、你主动使用「AI 智能解析」
- AI 解析只在你点击并确认后发送当次文本，服务端不保存；不用它时 App 完全离线可用
- 权限只有 `INTERNET` 和 `REQUEST_INSTALL_PACKAGES`，没有存储、位置、相机、通讯录、通知权限

完整说明（含第三方服务、代码审计入口）见 **[PRIVACY.md](PRIVACY.md)**。
