# E-Commerce Platform for Branded Footwear

A full-featured, responsive e-commerce web application for selling branded sneakers, developed from scratch using a custom CMS and the MVC architectural pattern to ensure flexible management and a seamless user experience.

### Key Features
* **Custom CMS & MVC Architecture:** Developed following the Model-View-Controller design pattern and supplemented with a proprietary content management system for complete control over business logic and data flow.

* **Advanced Catalog & Filtering:** Multi-level product categorization with dynamic parameter-based filtering. Detailed product pages featuring real-time cart integration.

* **Interactive Cart:** Management of added items with the ability to modify quantities, remove products, and proceed to checkout.

* **Role-Based Access Control (RBAC):** Multi-tier authorization system with distinct privilege levels for Administrator, Manager, and Customer roles, including route protection.

* **Comprehensive Admin Dashboard:** A full CRUD interface for managing the product catalog, news blog, and user accounts.

* **Secure Authentication:** Robust session-based PHP authentication featuring secure password hashing and automated email-based password recovery.

* **Blog & News Module:** An editorial section with content management capabilities through the administrative panel.

* **Internal Search Engine:** Fast and efficient product lookup across the catalog.

* **User Personal Account:** A dedicated customer portal for managing profile data and tracking order history.

* **Order Lifecycle Management:** Automated email notifications sent upon order placement, alongside persistent order tracking in the user dashboard.

* **SEO Optimization:** Semantic URL routing (SEO-friendly slugs), dynamic generation of unique title and description meta tags for every page, as well as configured robots.txt and sitemap.xml files.

* **Responsive UI/UX:** A fully adaptable interface across all screen resolutions featuring interactive carousels powered by Slick Slider.

### Tech Stack
* **Backend:** PHP (Custom MVC architecture, native sessions)

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)

* **Database:** MySQL

* **UI Components:** Slick Slider

* **Architecture:** Custom CMS and MVC Pattern
