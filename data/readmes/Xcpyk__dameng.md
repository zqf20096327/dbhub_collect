# 大梦

> 纵火的青年，迫近的时间

**通过一次有结构的长问答，蒸馏出一个和你一致的数字人。**

不是性格测试，不是问卷，也不是「AI 扮演你」的提示词模板。它是一套完整的流程：

```
140 道题的人生调研  →  原始档案  →  蒸馏任务书  →  persona  →  盲测  →  校准
```

- 题库 14 章、140 题（主线 64 题），覆盖性格、时间线、家庭、爱、工作、欲望、语言习惯。
- 本地网页答题，自动保存，随时续写；答案只存在这台电脑。
- 一键导出《人生档案》《蒸馏指令》《覆盖报告》，交给任意强模型生成 persona。
- 自带数字人运行规则、25 题校验考试、校准日志——**数字人是校准出来的，不是一次生成的。**
- 也可以在对话里让 agent 按协议访谈你，回答直接进同一个库。
- 界面支持 **中文 / English / 日本語 / 한국어**，右上角地球按钮切换，题库同步翻译。

## 30 秒开始

在项目目录里执行：

```bash
./run.sh
```

浏览器会打开 `http://127.0.0.1:8765`。从第一章开始写，或者点「只看主线」先答 64 题；右上角地球按钮可以切换语言。

没有依赖，只需要 Python 3.10+。停止用 `Ctrl+C`。

## 三条使用路径

### 1. 自己写（推荐第一次）

打开网页，按章节写。每道题 700ms 自动保存；写不下去就跳过；下次打开会回到上次的章节。

- 「只看主线」：64 题，约 3 小时，足够做第一版。
- 「看全部」：140 题，约 8–10 小时，档案会厚一倍。
- 搜索框可以按关键词跳到任意题。

### 2. 让 agent 访谈你

在 DeepSeek Harness 里直接说：

> 按 `interview/agent_protocol.md` 开始第 1 场访谈。

agent 会读协议和进度，一次问一题，按你的回答追问，并逐字记录到同一个数据库。适合不想对着屏幕写字、或者希望被追问出细节的人。

记录工具也可以单独用：

```bash
python3 tools/record.py M03.Q02 "她从来不道歉，只会给我削苹果。"
python3 tools/record.py --missing core
python3 tools/record.py --coverage
```

### 3. 导入已有材料

已经有日记、聊天记录、旧访谈？整理成 JSON 导入：

```bash
python3 tools/record.py --import-json my_answers.json
```

格式：`{"name": "我", "answers": {"M01.Q01": "……"}}`。

## 一次完整流程

### 第 1 步：答题

网页或 agent 访谈，目标：主线 ≥ 80%，M13 语言样本至少 3 题。

### 第 2 步：导出

在网页点「导出档案」，或者：

```bash
python3 distill.py --name 我
```

生成到 `exports/<时间>_<名字>/`：

| 文件 | 用途 |
| --- | --- |
| `人生档案.md` | 原始证据，按 14 章编排；未答的题单列成「尚未采集」 |
| `蒸馏指令.md` | 完整的蒸馏任务书 + 档案；整份交给强模型 |
| `覆盖报告.md` | 进度、分章厚度、下一轮补什么 |
| `回答备份.json` | 换电脑/重装时导入；默认省略私密题答案 |

默认生成的是**公开版**：标注「私密」的题目只保留题面和标签，回答替换为「（私密层，未导出）」，备份也会省略这些答案。确实需要完整材料时才加 `--include-private`（文件会带警告，不要分享），或在网页导出弹窗里勾选「包含私密层」。

### 第 3 步：蒸馏

把 `蒸馏指令.md` 全文贴给一个强模型（Claude / GPT / DeepSeek 等）。它会按六步产出：

1. 证据抽取（每条带题号）
2. 性格/价值/依恋推断（每条 ≥2 条证据 + 反例）
3. 语言画像（10 句原话 + 禁语 + 改写规则）
4. 矛盾与空白（至少 5 组矛盾、8 个空白）
5. 合成 persona（十层结构）
6. 自检（10 个档案里没有的问题，标出哪些只能答「不知道」）

存成 `twin/persona.md`，或者放进 `examples/`。

### 第 4 步：跑起来

把 `twin/system_prompt.md` 里的 `{{NAME}}` 和 `{{PERSONA}}` 替换掉，交给任意对话模型。

### 第 5 步：考试与校准

按 `twin/exam.md` 做 25 题测试，最好再找一位朋友做 10 轮盲测。把「不像」写进 `twin/calibration.md`，一次只改一处，复测 5 题。

**通过线**：事实/语气/判断/情绪/边界平均 ≥ 4.0，诚实测试 5/5，盲测 ≥ 8/10。

## 它不是什么

- **不是心理测量**：没有常模、没有诊断、没有分数。依恋类型只写「假设」。
- **不是 100% 复制**：没有意识、身体和连续体验，不可能完全一致。目标是高保真 + 知道自己不知道什么。
- **不是替身**：不用于冒充你签约、转账、承诺或操纵他人。被问「你是真人吗」时，它必须说实话。
- **不是一次性生成**：第一版一定不够像。真正的质量来自考试、盲测和校准日志。

## DSH 插件

同一套题库也打包成了 DSH Host 插件 `dsh-dameng`，已安装到当前 profile。插件源码、安装说明和市场条目都在独立仓库：

**https://github.com/Xcpyk/dsh-dameng**

- 在对话里说「开始大梦访谈」，agent 会调用 `dameng_guide`，再按 `dameng_questions` 一次问一题。
- `dameng_answer` 逐字记录回答，`skip: true` 标记跳过。
- `dameng_status` 看进度，`dameng_export` 生成中文/英文/日文/韩文档案。
- `dameng_import` 导入网页或插件导出的《回答备份.json》，只补未答，不覆盖已有答案。
- 导出默认隐去私密层原文；确实需要完整材料时才加 `includePrivate: true`，导出文件会带警告。
- 回答默认存 `~/.dsh/dameng/answers.json`，导出到 `~/.dsh/dameng/exports/`，不进入工作区或 Git。

这是 **agent 插件**：没有独立的网页界面，访谈在对话里完成。原来的本地网页仍然保留，两边数据独立，可用备份 JSON 互相导入。

网页端也支持同样的隐私开关：导出弹窗里勾选「包含私密层」才会写入私密题原文，默认不勾。

## 语言

右上角地球按钮可以在**中文 / English / 日本語 / 한국어**之间切换。选择会记在浏览器里，刷新后保持；也可以直接用链接指定，例如 `http://127.0.0.1:8765/?lang=ja`。

- 界面文案和 140 道题一起翻译，不是只换按钮。
- **导出也跟随当前语言**：《人生档案》《蒸馏指令》《覆盖报告》《下一步》的标题、表头、说明和文件名都用当前语言；你写的回答原文保持原样，不会被机器翻译。
- 英/日/韩是初版翻译，欢迎直接改 `content/i18n/parts/`、`meta/`、`ui.json`、`scales.json`；改完运行 `python3 tools/i18n_build.py`，刷新即生效。合并后的 `en.json` 等不要手改，重建会覆盖。
- 导出模板在 `content/i18n/export/<lang>/`（prompt.md、next.md、strings.json），单独维护，不经过题库构建脚本。
- 想加一种新语言：按 `docs/TRANSLATION.md` 添加两半题库和 meta，再在 `languages.json` 与 `ui.json` 里登记。

## 隐私

- 服务只绑定 `127.0.0.1`，页面不联网。
- 回答存 `data/dream.db`；导出是明文 Markdown/JSON，自己保管。
- 私密题（创伤、羞耻、秘密）在档案里标为「私密」；默认导出会隐去回答原文，只保留题面和标签。只有显式 `--include-private` / 勾选「包含私密层」才会把原文写入导出，文件会带警告。
- 如果让 agent 访谈，对话内容也会留在会话记录里；介意的话用网页自己写。
- 想清空：删除 `data/dream.db` 即可；导出目录同理。
- 不要把 `data/` 或 `exports/` 提交到公开仓库（`.gitignore` 已忽略）。

| M06 爱与亲密 | 你怎么靠近、怎么退开、怎么冲突、怎么和好 |

## 常见问题

**答不完怎么办？**
先答主线 64 题。主线答完就能蒸第一版；剩下的靠校准补，不需要一次答完。

**一定要用大模型吗？**
生成 persona 需要；答题、统计、导出不需要。你也可以自己按 `docs/PERSONA_SCHEMA.md` 写。

**数字人会不会胡说？**
会，如果 prompt 不严。`twin/system_prompt.md` 的核心规则就是「没有记录就说不知道」；`twin/exam.md` 有 5 道诚实测试专门抓这个。

**可以给家人/伴侣做吗？**
技术上可以，伦理上需要本人知情同意。未经同意采集和模拟他人，不建议做。

**数据会被上传吗？**
本地服务不联网。只有你主动把导出文件贴给模型时，内容才会离开这台电脑。

## 发布与隐私

这个仓库默认**不包含任何真实回答**：

- `data/` 被 `.gitignore` 忽略，`dream.db` 不会进入 Git。
- `exports/` 除 `.gitkeep` 外全部忽略。
- `examples/` 里的沈知微是虚构人物；README 截图使用空档案或示例数据。
- 发布前仍建议跑一次 `git ls-files | grep -E '^(data|exports)/'`，确认只有 `exports/.gitkeep`。
