# AI-skills-config-and-tidbits

My discovered skills, workflow, agent config settings, and other bits relating to using AI in development workflows and projects.

## Layout

| Folder | Contents |
| --- | --- |
| [`skills/`](skills/) | Agent skills, one folder per skill with a `SKILL.md` |
| [`plugins/`](plugins/) | Third-party plugins I use, with credit |
| [`mcp/`](mcp/) | Third-party MCP servers I use, with credit |
| [`agents-md/`](agents-md/) | Reusable chunks for `AGENTS.md` / `CLAUDE.md` files |
| [`notes/`](notes/) | General notes and opinions on models, tools, and workflows |

Each folder has its own README.
