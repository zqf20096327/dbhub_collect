# buptLab-database

这个仓库包含了北京邮电大学 2024-2025 秋季学期《数据库系统原理》课程实验的相关代码和报告。

## 实验内容

1. 建表及数据导入；
2. 数据查询与修改；
3. 完整性约束；
4. 数据库接口；
5. 数据库物理设计；
6. 查询优化；
7. 事务管理。

## 目录结构

```
.
├── LICENSE
├── README.md
├── login.sh             # 用于快速连接数据库的脚本
└── lab<id>-<name>       # 实验文件夹
    ├── sql              # 涉及的 SQL 文件
    ├── src              # 涉及的高级语言源代码
    └── run.sh           # 实验脚本
```
