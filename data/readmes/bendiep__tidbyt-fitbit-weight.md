# tidbyt-fitbit-weight
> Display your weight from Fitbit on the Tidbyt

![FitbitWeight for Tidbyt](fitbitweight.png)

### Setup
1. Create Fitbit developer account at https://dev.fitbit.com
2. Create a new `REGISTERED APP` to receive a `CLIENT_ID` and `CLIENT_SECRET` key pair value.  
3. Generate a Refresh Token and insert it on `Line 2` in `fitbit.csv`.
4. Run your automation script `fitbitweight-script-main.sh`
