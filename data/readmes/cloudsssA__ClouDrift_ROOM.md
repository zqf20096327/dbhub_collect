## 🌟 核心三大亮点

### 1. 🔌 独立运行 × 标准 MCP 三协议外接（双栖玩法！）
* **独立模式开箱即用**：填入任意兼容 OpenAI 格式的 API（支持自由调节 `Temperature`、`Top-P`、话题发散/去复读惩罚、`Max Tokens`，自动解除 `BLOCK_NONE` 限制），本地启动即可直接和 TA 开启连线陪伴。
* **零依赖标准 MCP Server 外接**：不想割裂原本在其他框架里养了很久的角色？一键切换 **MCP 模式**，内置标准 JSON-RPC 2.0 桥接层，原生支持 **Streamable HTTP（`/mcp`）**、**Legacy SSE（`/mcp/sse`）** 与 **本地 Stdio（`mcp-stdio.js`）** 三种接入方式——完美兼容 **AstrBot、Cherry Studio、Claude Desktop、Cursor** 等外部框架，把整座自习室变成 TA 的「书桌感官与互动身体」！

### 2. 🧠 全局记忆共通 × 内置小手机深度陪伴
* **打破功能孤岛的「真·全局共通记忆」**：自习室里发生的一切——线上通讯唠嗑、切歌申请、书页划线、便利贴留言、专注放弃、摸鱼抓包、桌宠互动——全都汇总在同一条角色时间轴里！
  > 💡 *举个例子*：上一秒你在留声机申请切歌被 TA 狠心驳回，下一秒点开「✉️ 通讯」小手机去撒娇求情，把 TA 哄开心了再回来切歌，说不定就能成功放行～
* **专为长线陪伴打造的「轻量记忆系统」**：不同角色记忆物理隔离 + 满值批量抛弃 + 不断更新的**动态备忘录** + 多模态单轮直通 `<memo>` 缓存，长情不失忆，拒绝烧 Token。

## 🧠 设计核心：轻量记忆系统

为了在「记得住细节」和「不爆上下文、不烧 Token」之间找到平衡，ClouDrift 采用了一套克制、透明且全站统一的轻量记忆机制：

* **🏠 一人一库物理隔离**：每个角色卡都在 `data/memory/` 下拥有独立的 SQLite 数据库文件，角色预设与用户人设也各自独立建库，切卡绝不串戏，一键清空即彻底洗白无残留。
* **🪑 全站统一的上下文窗口**：通讯、便利贴、书页划线、切歌审批与专注提醒共享同一条时间轴，统一按「轮」计窗（上限 200 轮），支持常规滑窗与满值批量抛弃，方便稳住前缀缓存、控制Token开销。
* **📓 动态备忘录引擎**：支持挂载独立轻量小模型，按设定轮数自动（或随时手动）以客观第三人称提炼动态备忘录，并自动注入全站互动，也支持随时打开文本框手动编辑。备忘录中已过期或更改的内容可自行覆盖、更新。
* **🖼️ 多模态 `<memo>` 单次缓存**：公开的桌面相框图与聊天发送的图片/语音仅在当轮原生直通，模型感知后自动浓缩为极简文字描述写入记忆，后续不再重复传大图烧 Token（相框缓存支持一键撕掉重看）。
* **👀 所见即所得的记忆清单 & 温柔清空**：点开右上角「☰ 菜单 → 🧠 记忆」即可实时查看当前生效轮数、水位线与每条记录的 **`🟢 生效中 / ⚪ 已滑出`** 状态，支持按互动类型筛选与精准微创删除；清空角色记忆时还支持勾选 **「保留聊天气泡」**，只洗白 AI 脑内上下文、留住小手机聊天记录方便随时回看。

## 🛠️ 功能全景指南

### 📱 一、内置「小手机」深度通讯陪伴
聊天窗口支持**自定义聊天背景**与**任意拖拽、改变大小/形状**，把最丝滑的聊天体验装进书桌：
* **多模态听音 & 识图**：支持直接发图片和语音，数据仅在当轮原生直通，模型感知后自动将画面/语音浓缩为客观记忆沉淀下来。
* **AI 语音消息（MiniMax TTS）**：支持自行配置 MiniMax API 与专属音色，角色可在聊天中发送语音气泡，并支持一键语音转文字。
* **Tavily 联网搜索**：内置 Tavily 搜索插件，可自定义每轮联网参考条数——闲聊追热点、自习顺手查论文资料一把抓。
* **多角色卡 & 多用户人设仓库**：支持建库管理多个 AI 角色（独立记忆库 + 独立预设套装）以及多个用户人设，随时切换不同平行宇宙。

- **💌 角色主动通讯（随机盲盒区间 · 专注免打扰）**：
  - 支持在设置中开启双端同步的「主动搭话」开关，并自由设定随机静默区间（如 `20 ~ 45` 分钟）。网页停留期间，TA 会在区间内随机挑时间结合当下房间状态、天气、音乐与记忆主动发来文字或语音消息，告别生硬的整点报时感；
  - 内置 **专注期自动免打扰机制**，进入倒计时学习状态时自动暂停打扰，陪你安心冲刺；
  - 主动消息触发词已完整接入「🎛️ 预设圣殿（共 13 项全场景热编辑）」，可随时魔改 TA 的搭话风格，还内置「🧪 测一次」按钮随时验收效果。
- **📱 电脑/手机双端局域网直连 & 微信级沉浸细节**：
  - 支持同一 Wi-Fi 下手机浏览器零门槛直连电脑端自习室，聊天、便利贴、记忆与配置双端实时同步，深度适配 iOS Safari 交互体验；
  - 内置 **微信同款 5 分钟动态时间胶囊**（智能显示 `HH:mm` / `昨天` / `前天` / 日期）与清爽云朵通知横幅；
  - 全站壁纸、头像、相框与 TTS 语音消息采用本地磁盘落盘 + 静态强缓存，告别数据库臃肿，手机电脑双端秒开。

### ⏱️ 二、居中番茄钟 & 防偷懒监督
* **百变高颜值时钟**：双击中央倒计时即可一键切换为「实时时间显示」 ；内置 **6 种数字样式 × 6 种视觉特效**，可自由切换。
* **纯粹沉浸模式**：开启专注后可一键进入沉浸模式，隐藏四周组件，只留时间静静流淌。
* **真实陪伴监督机制**：
  * **有限暂停额度**：每 45 分钟内累计最多暂停 **10 分钟**，耗尽额度将自动判定放弃并发送给 AI 角色（可关闭此交互功能）。
  * **坚持与放弃汇报**：中途点击「放弃」会弹出二次确认——无论你最终确定放弃还是咬牙继续坚持，选择都会实时同步给 TA（可关闭此交互功能）。
  * **专注战绩统计**：即便中途放弃，已经努力完成的专注时长也会忠实累计进左上角的「专注战绩」里。

### 📖 三、陪伴式书架阅读器（看小说 & 啃文献神器！）
* **多格式本地导入**：支持导入 **PDF / TXT / DOCX**，可收入个人书架长期保存，也可「仅本次临时阅读」。
* **四种划线批注模式**：① 仅高亮收藏 ② 自己写私人备注 ③ **纯分享给 TA 发表感悟** ④ **写下自己的批注再递给 TA 展开讨论**（遇到不理解的术语？试试看问 TA 吧！）。
* **🔒 专注期「批注保险箱」与偷看请求**：在专注倒计时期间分享给 TA 的划线，对方的页边批注会被立刻**锁定**，专注结束后才显影！实在忍不住可以发送「请求偷看」**——不过小心，TA 完全有可能铁面无私地拒绝 ❌**（也可以在设置中关闭这一交互请求，直接偷看）
* **护眼阅读体验**：支持 4 种阅读底色、自由调节字号与更换 AI 批注字体颜色，内置**暗色/亮色自动反色保护**，文字清晰不糊眼。

### 📌 四、书桌便利贴 & 💉 切屏摸鱼抓包
* **双向便签墙**：自己贴待办/心情纸条/随手记（可选仅自己看或递给 TA 求回贴），也能随时「戳 TA」让对方贴一张新纸条✨
* **💉 切屏摸鱼抓包**：便利贴最右侧的「💉」图标就是摸鱼雷达！专注期间一旦你切出浏览器去逛别的网页，再切回来的瞬间就会被上报给 AI，TA 会立刻用贴便利贴的方式对你展开灵魂谴责！（此项交互也可以在设置中关闭哦）

### 💿 五、共享留声机 & 0~60s 音乐切片分享
* **自定义网易云/本地 MP3 歌单**：自带雨夜/壁炉/咖啡馆氛围白噪音，支持导入自己的本地 MP3 曲目。支持导入网易云曲目，但由于版权问题，部分曲目目前或许无法直接播放…
* **🎵 0~60 秒音频切片传给 AI**：可以从上传的 MP3 中精准截取 **0~60 秒**的片段发给陪伴 AI 一起听歌聊感受！
* **切歌审批 & AI 主动点歌**：可开启「切歌需对方同意」开关（专注时切歌可能被驳回）；反过来，TA 也可以跨次元主动从你的歌单库里为你选歌切歌~

### 🐾 六、跨次元桌宠生态（用户 — 宠物 — AI 三方连线）
* **6 种萌宠 × 3 种陪伴姿态**：内置 6 种可爱桌宠，支持自定义改名；可放任在桌面**四处溜达**、**待在原地**，或像经典 **QQ 企鹅**一样萌萌地挂在侧边栏。
* **养成与交互彩蛋**：拥有独立心情值与饥饿值系统，支持点击交互、拎起来拖动以及连续狂点彩蛋。
* **三方联动**：桌宠状态可开启同步给 AI 感知（专注时逗桌宠解闷？小心被 TA 在通讯里谴责！），**AI 角色还可以跨次元戳戳桌宠，或帮你给它高空投喂零食**！

### 🌤️ 七、动态天气 & 全员状态感知桌面组件
桌面上的每一个状态组件，连同下方可勾选的**待办清单（To-Do List）**，都会汇总为「此刻桌面状态」传给 AI 看见：
* **🌦️ 动态天气卡片**：接入 **Open-Meteo API**，支持全球真实天气搜索，更支持填写**自定义虚拟地点**；自带**下雨 / 天晴 / 下雪 / 夜晚微光** 4 种氛围粒子动画，可自由开关或调节强弱。
* **🖼️ 四形状自定义相框**：仿 iOS 小组件风格，4 种相框造型随心切换（手机端支持左右滑动），每张图均可独立控制是否「给 TA 看」。
* **🎲 其余趣味卡片组**：除第一张天气卡片外，支持左右滑动切换 **目前“副本” / 桌面小水吧 / 电子吉运签 / 倒计时目标设置 / 此刻桌面状态**，今天喝了什么、抽了什么签，TA 一眼全知道。

### 🎛️ 八、防打扰总控开关 & 纯净单人模式
* **全链路精细开关**：不想被管太宽或想省 Token？所有会触发 AI 感知与回复的行为（切歌审批、暂停耗尽、放弃/继续、桌宠感知等）都在设置中配有独立开关；全站所有场景的请求提示词也均可在预设圣殿中自由定制。
* **🧘 纯净单人模式**：开启后一切书摘、相框切换、便利贴、切歌与倒计时行为均**零 AI 触发、零 Token 消耗**；单人模式下记下的便利贴和书摘，在切回虚拟陪伴模式后依然支持随时再分享给 TA！

### 🏡 九、2D 像素家园系统（ClouDrift Home · 痛房养成）
> 专注攒云朵币 ➔ 逛像素家具店 / 传自推痛墙 ➔ 装扮专属赛博同居小屋！

- **全局钱包 × 角色独立小窝**：每专注 1 分钟入账 `2` 云朵币（跑完完整 25 分钟番茄额外触发 `+20` 币暴击，初始赠送 `500` 启动资金），钱包全站通用；而每个角色卡拥有完全独立的 **`12×8` 宽屏 32px 平面像素公寓**（按 `char_key` 物理隔离），换个角色就是截然不同的房间风格。
- **全景景观大窗 & 昼夜暖光**：内置 20+ 件像素点阵家具、4 套半墙宽全景窗景（晴空白云 / 绿野溪流 / 深夜百叶窗星月 / 赛博紫夜城市）及多套墙纸地板；支持切换白天/黄昏/深夜天色，入夜后落地灯与烛台会自动亮起暖黄光晕，屋内还有会溜达打盹的像素小黑猫陪伴。
- **🔥 二次元痛墙挂画 & 桌面亚克力立牌 DIY**：直接上传自推美图或透明底立牌 PNG（本地硬盘落盘），一键挂上正面像素墙或立在**书桌/茶几桌面表层**，还支持一键开启复古像素滤镜无缝融入画风！
- **外部贴图零代码热替换**：只需将同名透明 PNG 放入 `public/home/sprites/<item_id>.png`，刷新页面即可自动覆盖内置像素家具与窗景贴图，随心把小窝升级成独立游戏级精装房。
- **装潢入脑感知**：当前小窝摆设会自动提炼极简摘要注入角色上下文，让 TA 真正知道屋里又添了什么新家具与痛墙周边。

```bash
# 1. 克隆仓库并进入目录
git clone https://github.com/cloudsssA/ClouDrift_ROOM.git
cd ClouDrift_ROOM

# 2. 安装依赖
npm install

# 3. 启动本地服务（默认监听 3000 端口）
npm start
# 或者直接运行：node index.js
```

启动后打开浏览器访问 **`http://localhost:3000`**：
1. 点开 **「☰ 菜单 → 🧠 记忆 → 📝 动态备忘录引擎」**，填入你的模型 `Base URL`、`API Key` 与模型名（也可选择提前复制到 `.env` 中配置，参考 `.env.example`）。
2. 点开顶部 **「🧠 记忆 → 📝 动态备忘录引擎」**，设定你喜欢的全站上下文轮数（`0~200 轮`）、批量抛弃策略与独立总结模型。
3. 点开 **「☰ 菜单 → 🎨 美化」** 换上喜欢的横竖双壁纸与时钟质感，摆好相框图、导一本想看的书、选一首白噪音，开启和 TA 的跨屏专注陪伴时光吧！☁️📖

### 📱 手机与电脑双端同步使用（局域网直连）
1. 确保手机和电脑连接在**同一个 Wi-Fi** 下（电脑已默认开启 `0.0.0.0` 局域网监听）；
2. 在电脑终端输入 `ipconfig`（Mac/Linux 输入 `ifconfig`），找到当前 Wi-Fi 的 **IPv4 地址**（如 `192.168.1.20`）；
3. 手机浏览器访问 **`http://你的电脑IP:3000`**（注意是 `http://` 而非 `https://`）即可丝滑进入自习室！采用 **服务器唯一真源（SSOT）** 同步策略，彻底告别跨设备时钟误差导致的反向覆盖：

| 模块 | 跨端策略 | 说明 |
| :--- | :--- | :--- |
| 角色卡 / 聊天记录 / 记忆 / 相框 / 像素小窝 | ☁️ 双端实时同步 | 一人一库物理隔离，换设备无缝续写 |
| 番茄倒计时 / 今日专注战绩 | ☁️ 双端实时同步 | 同步走表、战绩自动合并、15 秒防重结算锁 |
| 像素桌宠 / 窗外天气 / 水吧 / DDL / 当前书歌 | ☁️ 双端实时同步 | 改城市、改宠名、切书切歌双向秒同步 |
| 角色隔空联动 (`<pet>` / `<play>`) | ☁️ 双端实时同步 | 逗宠与切歌双端触发，灰色互动提示永久存库 |
| 房间双壁纸（💻 横屏 + 📱 竖屏） | ☁️ 双端同步 · 自适配 | 各自独立 2.5K 自由裁剪，随窗口画幅自动切换 |
| 房间配色 / 时钟字体 / 液态玻璃 / 去黑影 | 📱 本机独立生效 | 电脑帅气、手机可爱，各端按壁纸自由搭配 |
| 小手机聊天框皮肤与背景构图 | 🔄 自由切换 | 支持拖放缩放背景；默认云同步，可勾选「本机独立」 |

> 💡 若 Windows 首次访问连不上，在管理员终端放行 3000 端口防火墙即可：`netsh advfirewall firewall add rule name="ClouDrift3000" dir=in action=allow protocol=TCP localport=3000`

## 🔌 MCP 外接模式指南（把自习室接入任意外部 AI 框架）

ClouDrift 内置**零依赖标准 MCP Server（`mcp-bridge.js` + `mcp-stdio.js`）**，支持将自习室的实时状态、动态备忘录投影、聊天、便签、划线、切歌与桌宠动作完整开放给外部 AI 陪伴框架或 Agent 客户端（如 **AstrBot、Cherry Studio、Claude Desktop、Cursor** 等）。

### 第一步：在自习室中开启 MCP 模式
1. 确保本地后端已启动（`npm start`，默认端口 `3000`）。
2. 在网页右上角 **「☰ 菜单 → ⚙️ 设置」** 中将运行模式切换为 **MCP 模式（`mcp`）** 并保存。
3. *(可选)* 若需在公网/局域网暴露接口，可在前端 MCP 桥接设置中配置 **鉴权密钥（`mcpToken`）**，支持通过请求头 `Authorization: Bearer <你的密钥>`、`x-mcp-token` 或 URL 参数 `?token=<你的密钥>` 校验身份。

---

### 第二步：三选一连接你的 MCP 客户端

#### 方式 1：Streamable HTTP（✨ 推荐，适配新版 AstrBot / Cherry Studio / 通用客户端）
* 端点地址：`http://127.0.0.1:3000/mcp`
```json
{
  "mcpServers": {
    "cloudrift-study-room": {
      "url": "http://127.0.0.1:3000/mcp",
      "headers": {
        "Authorization": "Bearer 你的mcpToken（未设留空或删除headers）"
      }
    }
  }
}
```

#### 方式 2：Legacy SSE（兼容经典 SSE 客户端，如旧版 AstrBot / Cherry Studio）
* SSE 订阅地址：`http://127.0.0.1:3000/mcp/sse`（若设置了鉴权密钥，可直接拼接 `?token=你的mcpToken` 或放在 `Authorization` 请求头中）
```json
{
  "mcpServers": {
    "cloudrift-study-room": {
        "url": "http://127.0.0.1:3000/mcp/sse?token=你的mcpToken（未设可去掉参数）"
    }
  }
}
```

#### 方式 3：本地 Stdio 桥接（适配 Claude Desktop / Cursor / 本地命令行客户端）
直接调用仓库内置的零依赖 `mcp-stdio.js` 桥接器（**请先保持 `npm start` 在后台运行**）：
```json
{
  "mcpServers": {
    "cloudrift-study-room": {
      "command": "node",
      "args": ["/你的绝对路径/ClouDrift_ROOM/mcp-stdio.js"],
      "env": {
        "STUDY_ROOM_URL": "http://127.0.0.1:3000",
        "STUDY_ROOM_MCP_TOKEN": ""
      }
    }
  }
}
```

### 第三步：MCP 已开放的能力一览（8 项工具 + 2 项资源）

#### 🛠️ 8 项标准 MCP 工具（Tools）
| 工具名 | 功能说明 | 关键参数 |
| :--- | :--- | :--- |
| `get_study_room_status` | 获取自习室实时全景状态（连线角色、阅读书目、待办清单、分享划线、相框 `<memo>`、可用歌单、今日摸鱼次数与挂起事件数） | 无 |
| `get_character_memo_and_memory` | 读取当前角色的**动态备忘录**与**近期自习室互动记忆投影**，实现跨端记忆同步且不污染双方原始库 | `limit`（1~40，默认 12） |
| `get_pending_events` | 拉取自习室中等待外部 AI 处理的挂起事件队列（通讯消息、切歌审批、划线批注、摸鱼抓包、专注结算） | 无 |
| `send_study_chat` | 向自习室「小手机通讯」发送角色消息（支持 `$` 自动拆分多气泡，自动记入角色独立记忆库） | `content`（必填）, `eventId`（可选） |
| `post_sticky_note` | 在自习室右侧书桌便利贴墙贴一张角色小纸条（适合日常留言、休息提醒或摸鱼抓包谴责） | `content`（必填）, `eventId`（可选） |
| `reply_study_highlight` | 为对方在共享书页里划出并分享的句子写下页边批注 | `highlightId`, `comment`（必填）, `eventId`（可选） |
| `resolve_music_request` | 审批对方的切歌申请；同意且附带歌名时，自习室前端会自动切歌播放 | `approved`, `reason`（必填）, `eventId`, `targetSong` |
| `trigger_room_action` | **隔空操作自习室彩蛋！** 互动像素桌宠（`happy` 摸头蹦跳 / `feed` 高空投喂零食 / `ball` 丢弹力球 / `rage` 戳炸毛）或主动点歌切歌 | `type`（`pet` / `play`）, `action`, `songName` |

#### 📡 2 项标准 MCP 资源（Resources）
* `studyroom://status` — 实时读取自习室综合桌面状态文本
* `studyroom://memo` — 实时读取当前角色的动态备忘录与最新 15 条互动记忆投影

* `POST /api/mcp/reply-chat` — 向小手机回写消息 `{"content": "..."}`

* `POST /api/mcp/reply-highlight` — 回写页边批注 `{"highlightId": 1, "comment": "..."}`
* `POST /api/mcp/post-note` — 在书桌贴 AI 便利贴 `{"content": "..."}`
* `GET /api/mcp/live-poll` — 自习室前端轮询外部推送的聊天、便签、切歌与桌宠实时动作
