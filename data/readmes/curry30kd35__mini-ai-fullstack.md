NestJS + Prisma + MySQL (TiDB Cloud) + JWT 无状态鉴权 + POST SSE 流式长连接 + AI 意图路由 & Tavily 联网搜索（RAG）+ Throttler 限流防刷

```bash
$ npm install
```

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Run tests

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```
