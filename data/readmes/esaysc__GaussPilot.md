# openGauss 部署工具

一个基于Web的openGauss数据库部署和管理工具，支持不同业务场景的参数配置和实时监控。

## 功能特性

### 🚀 核心功能
- **一键部署** - 简化的openGauss数据库部署流程
- **参数验证** - 全面的输入参数验证和错误提示
- **实时状态** - 部署进度实时显示和日志输出
- **性能测试** - 内置数据库性能测试工具

### 🎯 业务场景配置
- **Web应用** - 高并发Web应用优化配置
- **数据仓库** - 大数据分析优化配置
- **OLTP系统** - 在线事务处理优化配置
- **开发测试** - 开发环境平衡配置

### 📊 实时监控
- **系统资源** - CPU、内存、磁盘使用率监控
- **数据库状态** - 连接数、活跃查询数监控
- **可视化图表** - 实时更新的监控图表
- **历史趋势** - 24小时监控数据趋势图

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动应用

```bash
python backend/app.py
```

### 3. 访问界面

打开浏览器访问：`http://localhost:5001`

## 使用指南

### 部署配置

1. **选择业务场景** - 根据您的应用类型选择对应的场景
2. **填写配置信息** - 输入数据库连接信息
3. **应用场景配置** - 系统自动应用优化的参数配置
4. **开始部署** - 点击部署按钮开始安装

### 监控功能

1. **启动监控** - 点击"启动监控"按钮
2. **查看指标** - 实时查看系统资源使用情况
3. **分析趋势** - 观察历史数据趋势图
4. **停止监控** - 点击"停止监控"按钮

### 性能测试

1. **选择场景** - 应用业务场景配置
2. **设置参数** - 配置测试参数
3. **执行测试** - 开始性能测试
4. **查看结果** - 分析测试结果

## 业务场景配置

### Web应用场景
适用于高并发Web应用，优化连接池和查询缓存：
- `max_connections`: 200
- `shared_buffers`: 256MB
- `effective_cache_size`: 1GB
- `work_mem`: 4MB

### 数据仓库场景
适用于大数据分析和报表查询，优化并行处理和内存使用：
- `max_connections`: 100
- `shared_buffers`: 2GB
- `effective_cache_size`: 8GB
- `work_mem`: 256MB

### OLTP系统场景
适用于在线事务处理，优化事务处理和并发性能：
- `max_connections`: 300
- `shared_buffers`: 512MB
- `work_mem`: 8MB
- `synchronous_commit`: on

### 开发测试场景
适用于开发和测试环境，平衡性能和资源使用：
- `max_connections`: 50
- `shared_buffers`: 128MB
- `work_mem`: 2MB
- `random_page_cost`: 4.0

## 监控指标

系统实时监控以下指标：
- **CPU使用率** - 系统CPU使用情况
- **内存使用率** - 系统内存使用情况
- **磁盘使用率** - 磁盘空间使用情况
- **数据库连接数** - 当前活跃的数据库连接数
- **活跃查询数** - 正在执行的查询数量
- **系统负载** - 系统负载平均值

## 技术栈

- **后端**: Flask, Python
- **前端**: HTML5, CSS3, JavaScript, Chart.js
- **监控**: psutil
- **数据库**: openGauss

## 注意事项

1. **系统要求** - 监控功能需要psutil库支持
2. **权限要求** - 系统监控需要适当的系统权限
3. **端口配置** - 默认使用端口5001，可修改
4. **数据存储** - 监控数据存储在内存中，重启后清空
