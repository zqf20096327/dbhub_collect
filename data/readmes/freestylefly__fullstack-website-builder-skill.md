# Fullstack Website Builder Skill —— 全栈网站快速生成助手

> 一句话描述你的需求，自动生成包含前端、后端、数据库和部署配置的完整网站项目。

## 这是什么？

`fullstack-website-builder-skill` 是一个 AI Agent Skill，它能根据你的一句话需求描述，自动生成一个结构清晰、可直接运行的全栈网站项目。

**你只管说"我想要什么"，剩下的代码、数据库、部署文件，它全帮你搞定。**

## 核心特性

- 🎯 **智能需求分析**：自动识别网站类型、提取功能需求、匹配最佳模板
- 📦 **5 种内置模板**：个人博客、企业官网、产品落地页、在线简历、小型电商
- ⚛️ **现代技术栈**：React 18 + Tailwind CSS + shadcn/ui + Node.js + Express + SQLite
- 🐳 **一键部署**：自动生成 Dockerfile 和 docker-compose.yml，`docker-compose up` 即可上线
- 📱 **响应式设计**：所有页面默认适配桌面端和移动端
- 🔒 **安全基线**：参数化查询、输入校验、基础认证

## 快速开始

### 安装

将本项目克隆到你的 Skill 目录：

```bash
git clone https://github.com/freestylefly/fullstack-website-builder-skill.git
```

或手动将 `SKILL.md` 文件复制到你的 Agent Skills 目录中。

### 前置要求

- Node.js >= 18
- Docker >= 20.0（如需容器化部署）

### 使用

只需用自然语言描述你的网站需求：

```
帮我做一个个人博客网站，要支持暗黑模式和文章搜索功能。
```

## 5 种模板一览

| 模板 | 适用场景 | 前端 | 后端 |
|------|----------|------|------|
| **个人博客** | 技术博客、知识分享 | 文章列表/详情、搜索、暗黑模式 | 文章 CRUD + SQLite |
| **企业官网** | 公司介绍、服务展示 | Hero 首屏、服务卡片、团队介绍 | 联系表单 API |
| **产品落地页** | 新品发布、活动推广 | 全屏首图、卖点展示、CTA 按钮 | 轻量表单 / 纯静态 |
| **在线简历** | 求职、作品集 | 个人信息、时间线、技能图 | 无（纯静态） |
| **小型电商** | 个人小店、预售 | 商品列表、购物车、结算 | 商品/订单 CRUD + SQLite |

## 三阶段工作流

```
用户需求 ──→ 【阶段一：需求分析】 ──→ 【阶段二：代码生成】 ──→ 【阶段三：部署配置】 ──→ 可运行的网站
              │                        │                        │
              ├─ 类型匹配              ├─ 前端组件               ├─ Dockerfile
              ├─ 功能提取              ├─ 后端 API               ├─ docker-compose.yml
              └─ 方案确认              ├─ 数据库脚本             └─ README.md
                                       └─ 联调适配
```

## 进阶用法

### 附加详细需求

```
帮我做一个小型电商网站，卖手工皮具的。
商品大概 20 个左右，需要分类筛选（钱包、皮带、包包）。
风格要偏复古，暖色调。
不需要在线支付，客户通过微信联系下单。
```

### 仅前端模式

```
帮我做一个纯静态的在线简历，不需要后端，可以直接部署到 GitHub Pages。
```

### 组合模板

```
帮我做一个带博客功能的企业官网，首页展示公司服务，同时有个技术博客频道。
```

## 设计理念

**工具负责从 0 到 80，你负责从 80 到 100。**

- 📌 **痛点即入口**：不从技术栈选型开始，而从"你想做什么网站"开始
- 📋 **模板即答案**：5 种模板覆盖最常见的建站场景，选中就能跑
- ✅ **标准即安全感**：自动生成的代码遵循行业规范，可直接用于生产环境
