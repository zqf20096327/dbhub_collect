PolarDB MySQL 版目前分两条主线：**标准版**和**企业版**。两者共用同一套内核，但在架构、功能和适用场景上有明显区别。

## 存储费用怎么算？

这里有一个细节很多人忽略了。

PolarDB 支持三种存储类型：**ESSD 云盘**（需预选容量，固定收费）、**PSL4** 和 **PSL5**（两种分布式存储，随数据增长自动扩容，只按实际数据量收费）。

对于大多数用户，PSL4/PSL5 更省心，不用担心提前规划容量，也不会因为买多了造成浪费。数据量较大（1000GB 以上）时，购买存储包能享受额外折扣，容量越大折扣越多。

多个集群可以共享同一个存储包。举个例子：你有三个存储容量各 40GB 的集群，共 120GB，可以用一个 100GB 存储包统一抵扣，多出的 20GB 按量计费——不需要为每个集群单独买。

## 常见问题（FAQ）

**Q：阿里云PolarDB MySQL版和RDS MySQL版区别是什么，该怎么选？**

A：两者都是阿里云托管的 MySQL 兼容数据库。RDS MySQL 更接近传统数据库托管，入门价格更低，适合预算有限的小型项目。PolarDB MySQL 是云原生架构，计算和存储分离，扩展性更强，性能更高，适合有一定规模或增长预期的业务。数据量在几十 GB 以内、并发不高的场景，RDS 够用；一旦涉及读写分离需求、大数据量或高并发，PolarDB 的架构优势就体现出来了。

**Q：阿里云PolarDB MySQL版存储费用怎么算，会不会越用越贵？**

A：PSL4/PSL5 存储类型按实际数据量计费，随用随扩，不用提前规划。ESSD 云盘需要预选容量。如果数据量增长可预期，可以购买存储包享受折扣价。备份存储有一定免费额度，超出才收费，日常使用通常不会产生大额备份费用。

**Q：PolarDB Serverless 适合什么场景？和固定规格比哪个更省钱？**

A：Serverless 适合有波峰波谷、流量不均匀的场景，比如定时任务、测试环境、低频 SaaS 应用等。可以在无请求时暂停计费（仅保留存储费用）。业务流量比较稳定的，固定规格 + 包年包月通常更省；流量波动大或需求不确定的，Serverless 反而更经济。

**Q：阿里云PolarDB MySQL版支持几个只读节点？扩容多少钱？**

A：标准版和企业版集群均支持扩展只读节点。因为采用共享存储架构，增加只读节点时不需要额外存储费用，只需支付新增节点的计算费用（与主节点规格价格相同）。弹性扩容分钟级生效，不影响主节点业务。

**Q：已有自建MySQL，迁移到PolarDB麻烦吗？**

A：PolarDB MySQL 版 100% 兼容 MySQL 语法和协议，大部分情况下应用代码不需要修改。迁移可以通过阿里云数据传输 DTS 工具完成，支持不停机迁移。建议迁移前通过免费 Serverless 实例先做兼容性验证，成本几乎为零。
