# backendskills

Agent skills that make Claude Code, Codex and Cursor write backend code like a senior engineer:
safe on auth, data, money and schema changes by default.

![Same prompt without and with backendskills: password guessing is blocked, a rename no longer breaks a rolling deploy, critical mistakes 25 → 2](docs/demo.gif)

## Results

We gave agents 15 backend tasks with and without the skills, then ran a hidden check the agent never
sees: 20 buyers at once for 5 items in stock, a user reading someone else's order, the old app version
running against the new schema mid-deploy.

**Critical mistakes: 25/150 runs without the skills, 2/150 with them.** (Sonnet 5.5 and Haiku 5.5, 5 runs per task.)

Runs with a critical mistake, without → with the skills. Most of the gap is two tasks: `login-rate-limit`
and `rename-column` account for 20 of the 25, and 10 of the 15 tasks had no critical mistake either way.
Not fixed yet: Haiku on out-of-order webhook events.

- **Team conventions** (down migrations, API docs): 30 misses → 4, with the sample app's conventions
  written into each skill's "Make it yours" section ([`bench/skills-overlay`](bench/skills-overlay)). The
  whole with-skills arm uses that version. As shipped, those lines say "not set".
- **Cost:** with the skills the agent does more: $0.11 vs $0.06 per run, 23 vs 14 turns
  (Sonnet $0.20 vs $0.12, Haiku $0.019 vs $0.012).
- **Left out:** 25 runs stopped because the bench account hit its usage limit (`usage_limit_reached`):
  20 Sonnet with-skills runs on `rename-column`, 1 on `orders-index`, 4 Opus. Each run's reason is its
  `error_reason` in `runs.jsonl`. The 21 Opus runs there are a partial run, not part of the results.
Every raw run, the tasks and how to rerun it are in [`bench/`](bench).

## Install

```sh
npx skills add globalmpc/backendskills
```

Codex and other `AGENTS.md` agents: append [`dist/AGENTS.md`](dist/AGENTS.md). Cursor: copy
[`dist/cursor/`](dist/cursor) into `.cursor/rules/`.

## Skills

| Skill | What the agent does by default |
| --- | --- |
| [`api-endpoint`](skills/api-endpoint/SKILL.md) | Scopes every query to the caller, turns bad input into a 4xx, rate-limits login and costly routes |
| [`data-integrity`](skills/data-integrity/SKILL.md) | Locks or conditional updates for read-then-write, UNIQUE constraints, idempotency keys on anything that charges or sends |
| [`db-migration`](skills/db-migration/SKILL.md) | Expand then contract, concurrent indexes, lock timeouts, batched backfills, down migrations |

Each skill ends with a **Make it yours** section for your team's choices (error format, API docs).
Left as "not set", the agent follows what your repo already does.
