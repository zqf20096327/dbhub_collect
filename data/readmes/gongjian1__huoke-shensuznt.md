# 获客系统

从抖音、小红书、快手、微信等平台的评论区里，把有购买意向的人找出来，整理成可以跟进的线索；再配上 AI 仿写、AI 视频和私信话术助手，帮本地商家把"找客户"这件事做完整。

Flask + SQLite，一台小服务器就能跑，支持多用户、按评论条数计费的额度和手动充值。

## 功能

- **评论区采集**：输入关键词，搜出相关作品，抓评论，按意向词自动分 A / B 两级；可按地区、时间筛选，导出 CSV。
- **对标账号**：盯住同行账号，定时刷新新作品，发现爆款。
- **AI 图文仿写**：拿爆款当参考，写出原创文案并配图（只借鉴选题和结构）。
- **AI 视频**：文字生成视频、图片生成视频（阿里云百炼 wan 系列）。
- **私信助手**：针对每条线索的评论，生成"公开回复 + 私信开场白"。**只生成文字，不会自动发送**，由使用者自己复制发送。
- **多用户与计费**：用户隔离，按评论条数扣额度（每抓 1 条新评论扣 1 条，微信类按倍数），管理员后台可审核注册、手动充值、查流水。
- **充值页**：套餐 + 收款码，用户付款后提交，管理员核对到账后确认入账。

AI 功能用的是**使用者自己的阿里云百炼 Key**（加密保存在数据库里），费用由阿里云结算，系统不扣评论额度。

## 本地运行

需要 Python 3.10+。

```bash
pip install -r requirements.txt
python manage.py set-admin-password   # 设置管理员密码，登录名 admin
python app.py                          # 打开 http://localhost:5000
```

Windows 下也可以直接双击 `启动系统.bat`。

## 部署到服务器

```bash
sudo bash deploy.sh 你的域名.com
```

脚本会装依赖、建虚拟环境、生成主密钥 `/etc/huoke.env`、注册 systemd 服务并配 nginx。详细说明见脚本开头的注释。

**请备份 `/etc/huoke.env` 里的 `HUOKE_SECRET`**：丢了它，数据库里用户保存的阿里云 Key 就解不开了。

数据库每天备份：

```
30 3 * * *  cd /opt/huoke && /opt/huoke/venv/bin/python backup_db.py
```

## 配置

见 [`.env.example`](.env.example)。常用的是 `DATA_API_BASE`、`DATA_API_KEY`、`HUOKE_SECRET`；放在 gunicorn + 反向代理 + HTTPS 后面时再加 `HUOKE_SCHEDULER=1`、`HUOKE_BEHIND_PROXY=1`、`HUOKE_HTTPS=1`（gunicorn 只能开 1 个 worker）。

意向词、价格、注册方式、AI 默认模型都在登录后的「管理后台 → 设置」里改。

## 使用须知

- 请遵守各平台的用户协议和当地法律，只处理公开可见的评论，不要滥用采集到的数据。
- 私信话术是辅助工具，发送由你自己完成；请控制频率，不要对同一批人反复发同样的内容。
- 话术和文案由 AI 生成，发布前请自己检查，改成你真实的情况，不要照搬。
