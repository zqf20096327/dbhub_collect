# bluDb

เครื่องมือจัดการฐานข้อมูลที่ทำงานบนเครื่องของคุณเอง — คล้าย phpMyAdmin แต่ออกแบบเป็น IDE
สำหรับนักพัฒนา รองรับ **MySQL / MariaDB, PostgreSQL, Microsoft SQL Server และ SQLite**

**ไม่ต้องใช้อินเตอร์เน็ต ไม่ต้องมี Composer ไม่ต้องมี Node.js ไม่มีขั้นตอน build** —
คัดลอกโฟลเดอร์ไปวางแล้วเปิดใช้ได้ทันที ทุกไฟล์ที่หน้าเว็บต้องใช้อยู่ในเครื่องทั้งหมด

ส่วนติดต่อผู้ใช้เป็นสองภาษา ไทย/อังกฤษ สลับได้ทันทีจากแถบบน

---

## ความสามารถ

### จัดการการเชื่อมต่อ
- โปรไฟล์การเชื่อมต่อพร้อมสี, ประเภทสภาพแวดล้อม (Dev / Staging / Production), โหมดอ่านอย่างเดียว
- ทดสอบการเชื่อมต่อ, ทำสำเนา, นำเข้า/ส่งออกโปรไฟล์ (ไม่มีรหัสผ่านติดไปด้วย)
- รหัสผ่านฐานข้อมูลเข้ารหัสด้วย libsodium และไม่เคยถูกส่งกลับมาที่หน้าเว็บ

### สำรวจและแก้ไขโครงสร้าง
- ต้นไม้ฐานข้อมูลแบบโหลดตามต้องการ ตั้งแต่ฐานข้อมูลลงไปถึงตาราง วิว โพรซีเยอร์ ฟังก์ชัน ทริกเกอร์ อีเวนต์
- ช่องกรองเดียวค้นได้ทั้งชื่อฐานข้อมูลและชื่อออบเจ็กต์ พร้อมไฮไลต์คำที่ตรง
- คลิกขวาเพื่อสร้าง / เปลี่ยนชื่อ / คัดลอก / ลบฐานข้อมูล, สร้าง / เปลี่ยนชื่อ / ทำสำเนา / ล้าง / ลบตาราง,
  OPTIMIZE / ANALYZE / CHECK / REPAIR, นับจำนวนแถวจริง, สร้างเทมเพลต INSERT, เรียกโพรซีเยอร์
- แก้ไขโครงสร้างตาราง: เพิ่ม/แก้/ลบคอลัมน์ ดัชนี และ foreign key
- คุณสมบัติของฐานข้อมูลและตาราง: ชุดอักขระ, collation, เอนจินจัดเก็บข้อมูล, เจ้าของ, ขนาด, จำนวนแถว
  — เปลี่ยนได้เฉพาะสิ่งที่เอนจินนั้นเปลี่ยนได้จริง และเลือกได้ว่าจะเปลี่ยนเฉพาะค่าเริ่มต้น
  หรือแปลงทุกคอลัมน์และทุกตารางตามไปด้วย

**ทุกคำสั่งที่เปลี่ยนโครงสร้างจะแสดง SQL ให้ตรวจก่อนเสมอ ไม่มีอะไรรันเองเงียบๆ**

### SQLite: ฐานข้อมูลที่เป็นไฟล์
- เชื่อมต่อด้วย *เส้นทางไฟล์* ไม่ใช่ host/user/password — ฟอร์มเปลี่ยนคำถามตามชนิดฐานข้อมูลเอง
- สร้างไฟล์ฐานข้อมูลใหม่ได้เมื่อสั่ง และปฏิเสธไฟล์ที่ไม่ใช่ฐานข้อมูล SQLite จริง (ตรวจจากไบต์แรกของไฟล์)
- จำกัดโฟลเดอร์ที่เปิดได้ด้วย `sqlite_directories` ใน config หากต้องการล็อกให้แน่นขึ้น
- **แก้ไขโครงสร้างได้จริง** ทั้งที่ SQLite เปลี่ยนชนิดคอลัมน์ไม่ได้ — bluDb สร้างสูตร "rebuild"
  ตามคู่มือของ SQLite ให้ครบทุกขั้น (สร้างตารางใหม่ → คัดลอกข้อมูล → ลบของเดิม → เปลี่ยนชื่อ →
  สร้าง index, trigger และ view กลับคืน → ตรวจ foreign key) แล้วแสดงให้ตรวจก่อนรัน
  ซึ่งเป็นขั้นตอนที่คนทำเองพลาดกันบ่อยที่สุด

### เขียนและรันคำสั่ง
- ตัวแก้ไข SQL ที่เขียนขึ้นเอง: ไฮไลต์ไวยากรณ์, เติมคำอัตโนมัติจากตารางและคอลัมน์จริง, จัดรูปแบบ
- รันคำสั่งที่เคอร์เซอร์อยู่ (Ctrl+Enter) หรือรันทั้งหมด (Ctrl+Shift+Enter)
- ห่อทั้งชุดคำสั่งไว้ในทรานแซกชันเดียวได้ ถ้ามีคำสั่งใดพลาด จะไม่มีอะไรถูกเขียนเลย
- ยกเลิกคำสั่งที่กำลังทำงานอยู่ได้จริง (`KILL QUERY` / `pg_cancel_backend`)
- ตารางผลลัพธ์แบบ virtualized เปิดผลหลายแสนแถวได้ สลับดูแบบ Table / JSON / Text และคัดลอกหรือดาวน์โหลด
- ประวัติคำสั่ง ค้นหาได้ ทำเครื่องหมายรายการโปรด และเรียกกลับมาใช้ซ้ำ

### ดูและแก้ไขข้อมูล
- แบ่งหน้าและเรียงลำดับที่ฝั่งเซิร์ฟเวอร์ ค้นหาภายในตาราง แก้ไขค่าในเซลล์ได้ทันที
- ตัวแก้ไขค่าแบบเต็มสำหรับข้อความยาวและ JSON (คลิกขวาที่เซลล์ หรือ Shift+Enter)
- กำหนดค่า NULL จริงจากเมนูคลิกขวา เพิ่มและลบแถว
- คำสั่งอันตราย (DROP / TRUNCATE / DELETE หรือ UPDATE ที่ไม่มี WHERE) ต้องยืนยันเสมอ
  พร้อมบอกจำนวนแถวโดยประมาณที่จะได้รับผล และการเชื่อมต่อแบบ Production ต้องพิมพ์ `CONFIRM`

### เครื่องมือสำหรับงานจริง
- **แผนภาพ ER** วาดด้วย SVG เอง ลากตารางได้ ซูมและเลื่อนได้ จัดวางอัตโนมัติ ส่งออกเป็น SVG หรือ PNG
  และจำตำแหน่งที่จัดไว้แยกตามฐานข้อมูล
- **เปรียบเทียบฐานข้อมูล** ระหว่างสองสคีมาใดก็ได้ ข้ามเครื่องหรือข้ามเอนจินก็ได้ พร้อมสร้าง SQL
  สำหรับปรับให้ตรงกันมาให้ตรวจ
- **สำรองและกู้คืน** ใช้เครื่องมือของเอนจินเองเมื่อมี (`mariadb-dump`, `pg_dump`) และมี
  `bin/backup.php` สำหรับฐานข้อมูลใหญ่ที่ไม่ควรทำผ่านเว็บ
- **นำเข้า/ส่งออก** ส่งออกเป็น CSV / TSV / JSON / NDJSON / SQL แบบ stream และนำเข้าไฟล์ SQL หรือ CSV
  ทีละ 1 MB พร้อม `bin/export.php` และ `bin/import.php` สำหรับไฟล์ที่ใหญ่เกินกว่าจะทำผ่านเว็บ
- **วิเคราะห์แผนการทำงาน** (Ctrl+E) — ไม่ใช่แค่ตาราง EXPLAIN ดิบ แต่บอกเป็นภาษาคนว่า
  *"อ่าน logs ทั้งตาราง — 97,618 แถว โดยไม่มีดัชนีช่วยจำกัดขอบเขต"* และวัดเวลาจริงได้เมื่อเอนจินรองรับ
- **เฝ้าดูเซิร์ฟเวอร์** — เวลาที่เปิดทำงาน, จำนวนการเชื่อมต่อ, คำสั่งต่อวินาที, อัตราการใช้แคช
  และรายการทุกการเชื่อมต่อพร้อมคำสั่งที่กำลังรัน คลิกขวาเพื่อหยุดคำสั่งที่ค้าง
- **ค้นหาทุกตาราง** (Ctrl+Shift+K) — ค้นค่าเดียวทั่วทั้งฐานข้อมูลโดยไม่ต้องรู้ว่าอยู่ตารางไหน
  เห็นความคืบหน้าและกดหยุดได้ คลิกผลลัพธ์เพื่อเปิดข้อมูลที่กรองไว้แล้ว
- **สร้างข้อมูลตัวอย่าง** — เดาชนิดข้อมูลให้จากชื่อและชนิดคอลัมน์ (คอลัมน์ชื่อ email ได้อีเมล,
  foreign key ได้คีย์ที่มีอยู่จริง, enum ได้ค่าของตัวเอง) ดูตัวอย่างก่อนเขียน และเขียนได้ครั้งละหลายหมื่นแถว

### ผู้ช่วย AI (ทางเลือก ปิดอยู่โดยค่าเริ่มต้น)
- ใช้ **โมเดลในเครื่อง** ผ่าน Ollama เป็นหลัก จึงยังทำงานได้โดยไม่ต้องมีอินเตอร์เน็ต
- รองรับ **OpenRouter** และบริการอื่นที่ใช้ API แบบ OpenAI โดยบอกชัดเจนว่าข้อมูลจะออกนอกเครื่อง
- ถามได้สี่อย่าง: เขียน SQL ให้ / อธิบาย SQL / ทำให้เร็วขึ้น / อธิบายตาราง — ตอบเป็นภาษาที่ใช้อยู่
- **ไม่รันคำสั่งใดเอง** SQL ที่ได้มาต้องผ่านหน้าตรวจเหมือนคำสั่งอื่นทุกครั้ง
- ส่งเฉพาะคำถาม ชนิดเอนจิน และชื่อตาราง/คอลัมน์เมื่ออนุญาตเท่านั้น — ไม่มีรหัสผ่าน ไม่มีข้อมูลในแถว
- คีย์ API เข้ารหัสด้วยกุญแจเดียวกับรหัสผ่านฐานข้อมูล และไม่เคยถูกส่งกลับมาที่หน้าเว็บ

### ติดตั้งเป็นแอปในเครื่อง (PWA)
เปิดจากเบราว์เซอร์แล้วกดปุ่มติดตั้งที่แถบบน bluDb จะกลายเป็นแอปที่มีหน้าต่างของตัวเอง
มีไอคอนของตัวเอง และหน้าจอยังเปิดได้แม้เซิร์ฟเวอร์จะไม่ทำงาน (จะบอกให้รู้ว่าส่วนไหนที่ล่ม)

### อื่นๆ
- Command palette (Ctrl+P) และคีย์ลัดที่ตั้งค่าเองได้
- ธีมสว่าง / มืด / ตามระบบ
- **พื้นที่ทำงานไม่หายเมื่อรีเฟรช** — การเชื่อมต่อ ฐานข้อมูลที่เลือก ทุกแท็บคำสั่งพร้อมข้อความ
  แท็บข้อมูลที่เปิดไว้ และรูปทรงของ tree กลับมาเหมือนเดิม

## ความต้องการของระบบ

- **PHP 8.2 ขึ้นไป** พร้อมส่วนขยาย: `pdo_sqlite`, `sodium`, `mbstring`, `intl` และไดรเวอร์ของ
  เอนจินที่จะใช้ — `pdo_mysql`, `pdo_pgsql`, `pdo_sqlsrv`
  (SQLite ใช้ `pdo_sqlite` ซึ่งเป็นข้อบังคับของ bluDb อยู่แล้ว จึงใช้ได้ทันทีโดยไม่ต้องติดตั้งอะไรเพิ่ม)
  > ตรวจสอบที่ SAPI ของเว็บ ไม่ใช่แค่ CLI — ส่วนขยายที่เปิดไว้เฉพาะ `php-cli` จะไม่มีผลกับ bluDb
- **Apache** (แนะนำให้เปิด mod_rewrite) หรือเว็บเซิร์ฟเวอร์อื่นที่เสิร์ฟ `public/` ได้
- ไม่ต้องมี Composer, Node.js หรืออินเตอร์เน็ต

## การติดตั้ง

คัดลอกโฟลเดอร์นี้ไปไว้ใต้ document root เช่น `htdocs/tools/bluDb` ไฟล์ `.htaccess` ที่ให้มา
จะจับคู่ `/api/*` ไปที่ front controller และ `/` ไปที่ `public/index.html`

```bash
php bin/install.php     # สร้าง config/secret.key และ data/app.sqlite พร้อมตรวจสภาพแวดล้อม
```

จากนั้นเปิด `http://your-server/tools/bluDb/` แล้ว:

1. เข้าสู่ระบบด้วยรหัสผ่านของแอป (ค่าเริ่มต้นคือ `admin` — **ควรเปลี่ยนทันที**)
2. สร้างการเชื่อมต่อจากแถบบน → *สร้างการเชื่อมต่อ*
3. เลือกการเชื่อมต่อ เลือกฐานข้อมูล แล้วเริ่มใช้งาน

หากต้องการเปลี่ยนค่าตั้งต้น ให้คัดลอก `config/config.example.php` เป็น `config/config.php`
แล้วแก้เฉพาะค่าที่ต้องการ (ทุกค่ามีค่าเริ่มต้นในตัวอยู่แล้ว)

### วิธีที่แนะนำสำหรับการใช้งานจริง

ชี้ `DocumentRoot` ของ vHost มาที่ `public/` แล้วทำ alias `/api/` ไปที่ `api/index.php`
เพื่อไม่ให้ซอร์สโค้ดอยู่ใต้ document root เลย

### เซิร์ฟเวอร์สำหรับพัฒนา

```bash
php -S 127.0.0.1:8088 -t . bin/router.php
```

## ความปลอดภัย

- **เปลี่ยน `auth_password`** ใน `config/config.php` ก่อนเปิดให้เข้าถึงจากนอกเครื่อง
- รหัสผ่านฐานข้อมูลเข้ารหัสด้วย libsodium กุญแจอยู่ใน `config/secret.key` ซึ่งไม่เคยออกจากเซิร์ฟเวอร์
  ไม่เคยถูกส่งกลับมาที่หน้าเว็บ และไม่เคยถูกเขียนลง log
- `config/`, `data/`, `locales/`, `bin/` และซอร์สของ API ถูกปิดกั้นด้วย `.htaccess`
  โดย `api/` ปิดกั้นเป็นรายไฟล์ เพราะ Apache ตรวจสิทธิ์จากเส้นทางก่อน rewrite
  การปิดทั้งไดเรกทอรีจะทำให้ API ใช้งานไม่ได้ — ถ้าใช้ nginx ต้องปิดกั้นเส้นทางเหล่านี้เอง
- ทุกคำสั่งที่เปลี่ยนแปลงข้อมูลต้องมี session cookie, header `X-BluDb-Token` และ `Origin` ที่ตรงกัน
- ค่าเริ่มต้น `bind_localhost_only` เปิดอยู่ จึงรับคำขอเฉพาะจาก loopback เท่านั้น
- โฟลเดอร์ `data/` ต้องเขียนได้โดยผู้ใช้ของเว็บเซิร์ฟเวอร์ (เก็บ SQLite และ log)

## การตรวจสอบคุณภาพ

```bash
php bin/test.php           # ชุดทดสอบหน่วย ไม่ต้องใช้ PHPUnit หรือ Composer
php bin/check-i18n.php     # ทุกข้อความในหน้าจอต้องมีคำแปลภาษาไทย (--write เติมคีย์ที่ขาด)
php bin/check-offline.php  # ต้องไม่มี URL ภายนอกใน public/ เลย
php bin/make-icons.php     # วาดไอคอนของแอปใหม่
php -l $(find api bin -name '*.php')
```

เปิดแอปด้วย `?debug=i18n` จะมีแผงแสดงข้อความที่ยังไม่มีคำแปล พร้อมปุ่มคัดลอกเป็น JSON

```
locales/  th.json — พจนานุกรม อังกฤษ → ไทย
config/   config.php (ของคุณเอง), secret.key — ทั้งคู่ไม่อยู่ใน git
data/     app.sqlite (โปรไฟล์ งาน ประวัติ แคชสคีมา), log, ไฟล์ชั่วคราว — ไม่อยู่ใน git
bin/      install.php, router.php, test.php, check-i18n.php, check-offline.php,
          make-icons.php, backup.php, export.php, import.php
```

การแยก PHP ออกจาก HTML ไม่ได้เป็นแค่ข้อตกลง แต่ถูกบังคับด้วยเครื่องมือตรวจ:
`public/` ต้องไม่มี PHP และ API ต้องตอบ JSON เท่านั้น
