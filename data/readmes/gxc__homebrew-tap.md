# gxc/homebrew-tap

Homebrew tap for [gxc](https://github.com/gxc)'s tools.

## gaussdb-ro-mcp

Read-only MCP server for Huawei GaussDB (centralized & distributed), built for coding agents — see the [project README](https://github.com/gxc/gaussdb-ro-mcp).

```bash
brew install gxc/tap/gaussdb-ro-mcp
gaussdb-ro-mcp --version
```

Prebuilt binaries for macOS (Apple Silicon) and Linux (amd64 / arm64); Windows users should download from the project's [Releases](https://github.com/gxc/gaussdb-ro-mcp/releases) page.
