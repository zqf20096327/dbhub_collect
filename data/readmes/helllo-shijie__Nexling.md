# NexLing 技术翻译工作台

一个**纯本地、离线可用的纯文本翻译客户端**（内核即 Language-Accessible Agent）。Python 核心 +
React 前端 + HTTP 桥接，全部落在本工作区 `D:\deepseek_world\ww26\v11`，**无在线仓库、无外部改动**。
当前版本 **1.11.0（候选，待独立检查）**。
Python 包名仍为 `laa_core`；数据目录默认 `%LOCALAPPDATA%\NexLing`，旧版便携目录 `.laa` 首次启动自动迁移（旧目录只读，不删）。

## 桌面程序（推荐）

双击 `NexLing.cmd`（相对路径调用 `dist\NexLing\NexLing.exe`）直接弹出 Windows 窗口，无需浏览器：

- 目录式（onedir）打包、免安装、便携式；数据默认写入 `%LOCALAPPDATA%\NexLing`（SQLite + DPAPI 密钥），旧版 exe 同级 `.laa` 首次启动复制迁移，不再写安装目录。
- 先出启动窗、后端在窗口出现后并行初始化，WebView2 就绪后再显示主窗。
- 窗口内核为系统 WebView2（Win10/11 自带，无需额外安装）。
- `dist\NexLing\skins\` 随交付目录提供三套示例皮肤包（毛玻璃 / 深色 / 暖色高对比），
  需在「设置 → 界面 → 皮肤」导入后使用，不内置进默认列表。
- 依赖：`pywebview` + `pyinstaller`（仅打包时）；重新打包（先 `cd webui && npm run build`）：

```powershell
python -m pip install pywebview pyinstaller
python tools\build_release.py
```

`build_release.py` 会编译原生启动器、清理运行时残留并跑 `tests/test_release_guard.py`，守卫失败即打包失败。

## 接入真实翻译 API

默认走内置离线引擎（FakeProvider）。要接 DeepSeek/OpenAI 等 **OpenAI 兼容接口**：

- **界面方式**：启动服务后进入「设置 → 模型」，选预设（DeepSeek/OpenAI/Claude/自定义），填 base_url、
  模型名与 API Key，「测试连接」通过后保存并「设为默认」，之后的翻译即走真实模型。
- **命令方式**（同一套接口，无 UI 也可用）：

```powershell
# 测试连通（不落盘）
curl -X POST http://127.0.0.1:8787/api/invoke -H "Content-Type: application/json" -d "{\"cmd\":\"provider.test\",\"payload\":{\"provider_id\":\"deepseek\",\"base_url\":\"https://api.deepseek.com/v1\",\"model\":\"deepseek-chat\",\"api_key\":\"sk-xxx\"}}"

# 保存并设为默认
curl -X POST http://127.0.0.1:8787/api/invoke -H "Content-Type: application/json" -d "{\"cmd\":\"provider.upsert\",\"payload\":{\"profile\":{\"id\":\"deepseek\",\"kind\":\"deepseek\",\"base_url\":\"https://api.deepseek.com/v1\",\"model\":\"deepseek-chat\",\"is_default\":true},\"api_key\":\"sk-xxx\"}}"
```

API Key 经 Windows DPAPI 加密后写入 `%LOCALAPPDATA%\NexLing\secrets.json`，不以明文落盘。`provider.list` 可查看已配置供应商与默认项。

## 术语库

页面顶部「术语库」标签页提供完整的本地术语管理：

- **查看/搜索**：按词库浏览与关键词过滤词条；顶部已有「内置基础术语（只读）」与「个人术语库」。
- **新建词库**：「新增术语库」创建个人自定义词库（名称必填 + 可选源语言/目标语言/领域），创建后自动选中，
  可继续在其中新增 / 导入词条；词库名称重复会被拒绝（`LAA-4011`）。
- **编辑**：个人词库内可新增、编辑（`glossary.update`，term version+1）、删除词条；内置词库只读，
  增删改一律被拒绝（`LAA-4004`）。
- **导入/导出术语包**：术语库界面「导入术语包」支持选择 JSON 文件、粘贴 JSON 或直接拖入 `.json` 文件，
  覆盖模式 `merge`（冲突时更新译词）/ `append`（冲突跳过）；「导出」生成 `glossary-<bank_id>.json`——
  **桌面程序会弹出系统「另存为」对话框，可自由选择保存路径与文件名**（浏览器里走文件选择器；都不可用时退回浏览器下载）。
  术语包 JSON 形如 `{"entries":[{"source_term","target_term","domain","forced",...}]}`，
  可用 `docs\sample-glossary.json` 试导入。
- **接口**：`glossary.package.list` / `glossary.search` / `glossary.manage`(add·remove) / `glossary.update` /
  `glossary.bank.create` / `glossary.import` / `glossary.export` / `glossary.discover`（候选发现）。
- **按场景区分译词**：词条可携带 `scene_variants`（`scene_id → 该场景译词`）。术语库列表显示默认译词
  `target_term`；点击词条查看详情时展示各场景的覆盖译词。翻译时按当前场景匹配：有覆盖用覆盖译词，
  无覆盖回退默认译词。

## 翻译场景

「设置 → 翻译场景」提供完整的自定义场景管理（内置 4 个 + 用户自建）：

- **内置**：学术技术·中性（默认）/ 商务·正式 / 产品文案·营销 / 日常·随性。
- **自定义**：新增场景（名称 / 描述 / 语域 register / 默认模式 fluent·literal / 风格 descriptors / 应做 do / 避免 dont）、
  编辑、删除（内置或默认场景不可删）、「设为默认」。
- **选用**：在工作台按当前选中场景翻译（`scene_profile_id` 参与术语匹配与 Prompt 组装）。
- **接口**：`scene.list`（返回完整 profile）/ `scene.manage`(create·save·set_default·delete)。
- **AI 对话填充**：新增/编辑场景弹窗内置「AI 对话填充」面板。一句话描述即可自动补全整张表单，
  之后可继续对话微调（如「语气再正式点」「加一条避免口语化」）。该助手被系统提示词严格限定为
  **只能创建/修改翻译场景档案**，与场景无关的请求会被拒绝。接口：`scene.ai`
  （入参 `message` / `scene_profile` / `history`，返回 `reply` + 归一化后的 `scene_profile`）。

## 账单与用量

「设置 → 用量」展示模型调用的 token 用量与预估费用（USD），每次调用由成本账本记录：

- **总览**：总花费 / 输入 token / 输出 token / 调用次数。
- **分组**：按供应商、按天聚合。
- **明细**：按时间倒序列出每次调用（供应商 / 模型 / 用途 / token / 金额），支持按供应商过滤与分页加载。
- **计价**：`laa_core/domain/cost/service.py` 的价格表（元/百万 token，按 1 USD ≈ 7.2 CNY 折算），
  价格表带版本号，属占位/参考值，实际以供应商账单为准。
- **接口**：`usage.summary`（totals + by_provider + by_day）/ `usage.list`（limit·offset·provider 分页明细）。

## 翻译历史（工作台工具栏 → 历史）

工作台工具栏的「历史」打开**右侧抽屉**，随时回看、回载以前的翻译：

- **列表**：按时间倒序显示最近 30 条任务，每条给出原文摘要（2 行截断）、模式（直译/流畅）、目标语言、状态与时间。
- **回载**：点某条历史即调用 `translation.snapshot`，把该任务的原文、译文、逐词义项与语气标注整体载入工作台，
  可继续看、继续选词/重译，不会覆盖历史数据。
- **关闭**：抽屉右上角关闭，或按 Esc。
- **刷新**：新翻译完成后自动刷新列表，也可点「刷新」手动拉取。
- **接口**：`history.list`（`limit` / `offset` 分页，返回 `items` + `total`）。

## 用量与调用历史（设置 → 用量）

「设置 → 用量」上半部分是**用量与花费**总览（总花费 / 输入 token / 输出 token / 调用次数，按供应商、按天聚合），
下半部分是**调用历史**，逐条记录每次模型调用的提示词、回复与花费：

- **总览**：数据来自成本账本（`usage.summary`），每次模型调用自动记账。
- **明细**：时间、供应商 / 模型、用途、输入 / 输出 token、花费（USD）与预览；支持刷新与分页加载。
- **详情**：点某一行展开，显示供应商、模型、用途、耗时、token、花费；
  **提示词默认只显示你原本输入的原文**，点「展开完整提示词」后才展开实际发给模型的完整 messages
  （system 约束 + user 分段/术语/语气要求等），回复区原样展示模型返回内容。
- **落库**：每次调用写入 `calls` 表（提示词 messages、回复、token、金额、耗时、任务 id），本地保存，重启仍在。
- **接口**：`usage.summary` / `usage.list` / `calls.list` / `calls.get`。

## 直译模式

复原初版计划中的直译模式语义（`mode=literal`）：**按词直译 + 可点选义项**。

- **按词翻译**：模型按原文词序逐词/逐词组对译，不合并、不省略、不意译，保持原句结构与语序；
  每个词给一个**推荐义项**（该词在当前语境与搭配下最贴切、能让整句读懂的义项），外加 1~3 个备选义项。
- **选词改句**：工作台译文区把直译结果渲染成**可点击的词**，点击弹出气泡展示原文词、推荐义项与备选义项
  （气泡里明确标注「推荐 / 备选」）；选中一个义项后，后端用新义项重建整句并保存为新版本，刷新后仍是你的选择。
- **标识**：段末保留 `[AI TRANSLATED]`，提示这是机器直译而非人工润色。
- **接口**：`segment.word.pick`（入参 `task_id` / `segment_id` / `word_index` / `choice`），
  返回更新后的 SegmentView（含 `words` 与重建后的 `target_text`）。
- **兼容**：流畅模式不产生逐词数据；模型未返回逐词结果时自动退化为整句直译 + 标识。

## 语气自动识别

计划 L49 的「输入侧自动识别原文语气（如 `[angry]`、`[sarcastic]`），输出侧保持语气保留」已落地，
且**与翻译共用同一次模型调用**（不额外加钱）：

- **识别**：模型在返回译文的同时，返回原文的 `tones`：`[{start,end,label}]`，区间是该语气片段在本段原文中的字符下标，
  `label` 是 2~4 个汉字（讽刺 / 愤怒 / 警告 / 催促 / 亲昵 / 正式 / 客套 / 犹豫 / 命令 / 调侃等）。
- **不标注**：中性陈述不产生任何标注；`tones` 为 `[]` 时界面与普通翻译完全一致。
- **展示**：工作台原文行在该片段前插入方括号标签并给片段加虚线，例如 `You really [讽刺]did a great job`。
- **迁移**：提示词同时要求译文保留原文语气，不得抹平成中性。
- **容错**：模型给 `span` / `start+end` / 原文片段字符串三种写法都能归一化；越界裁剪、空标签、重叠片段自动丢弃。
- **落盘**：语气随版本保存（`versions.tones`），刷新/重开应用仍在。

## 核心特性（M0–M3）

- **确定性离线翻译**：无网络/无模型时由 `FakeProvider` 产出可复现的伪译文；接入真实 API Key 后走
  OpenAI 兼容网关（重试/指数退避）。
- **术语体系**：最长匹配优先 + 七级作用域阶梯 `session>document>personal>team>official>community>builtin`，
  冲突在 L2/L3 绝不自动仲裁。
- **风险路由**：11 条规则包（法律/财务/数字单位/否定/免责/PII…）评分 → L0/L1 自动定稿、L2/L3 不自动导出
  （`manual_export`，由用户自行确认后处理）、out_of_scope 阻断。
- **质检与自信度**：长度比/数字单位/术语落实/漏译/结构/跨段一致性 6 项确定性检查 + ConfidenceEstimator。
- **翻译记忆（手动）**：翻译完成后点结果区的圆形加号按钮写入，已加入时显示对勾、再点撤回；
  改写、重译与自动流水线都不自动入库。
- **能力注册表（12 条）**：5 条可用（术语库 CRUD/导入导出、内置基础术语包、术语发现闭环）；7 条在「设置 → 路线图」
  与社区术语池统一标记为 `roadmap`，只在「设置 → 路线图」按阶段列出，主界面不再出现空壳入口。

## V10 新增

- **分层切分**：段落优先；单段超过 500 字符时把原文交给模型分句，校验分句拼接与原文逐字一致后
  按模型分句打包；模型不可用、返回不合法或离线时退回本地兜底分句（短碎片并入相邻句，
  并识别 `e.g.` / `i.e.` / `etc.` / `Mr.` / `Dr.` / `Fig.` 等缩写与小数点，不在缩写内部断开）。
  单句本身超长无法在边界切开时按字数强制切分（切点避开缩写、单词与小数点），并在片段与界面上标记「强制切分」。
- **分批请求**：`long_text` 设置可配每批字符预算（默认 2000）与每批片段数（默认 8），
  多批依次请求，批与批之间默认节流 120 ms（离线引擎不等待）。
- **术语全篇一致**：每批完成后把「术语 → 实际译法」写入 `task_terms`（可按任务查）；
  后续批次提示词带上已定译法作为硬约束，术语库命中优先，用户指定优先于两者。
  结果区「本文术语一致性」面板可查看并指定译法：旧译法可定位时直接替换、不调用模型；
  不可定位的片段才重译，不整篇重翻。命中与替换按 ASCII 词边界 / CJK 子串判断（与翻译记忆失效同一套规则），
  旧译法比新译法长时也不会被子串误判跳过；术语未在本文出现时如实返回 `matched=0`。
  模型返回的术语必须能在该段原文与译文中对上，对不上的一律丢弃。
- **真实进度**：片段状态与计划批次数落库，`task.progress` 事件携带
  总片段 / 已完成 / 失败 / 已取消 / 剩余 / 批次数；结果边翻边出现，工作台顶部进度条与实际完成数一致。
- **可取消**：批次之间检查取消，已完成片段保留可用，未完成片段标记为「已取消」。
  首批尚未开始就取消时，所有未开始片段也会落为「已取消」，前端可直接重试。
- **失败可续**：单批失败按设置有限重试；仍失败则记录该批并标片段为失败，
  结果区提供「重试失败片段」——只重跑 failed/pending/cancelled 片段，不重跑已完成部分。
  应用重启时把仍在运行的任务置为 `paused`（落库），可直接续传；若 `paused` 时片段其实已全部完成，
  重试会直接收尾为 `succeeded`，不发起新调用，不留永久暂停。
- **上限可处理**：20 万字符不再截断，提交前 `translation.estimate` 返回片段数、批次数与预计调用次数；
  超过可配置硬上限时明确报错（`LAA-3002`）并提示调高上限或拆分，而不是静默截断。
- **成本可见**：进度条展示预计调用次数，完成后由快照回填实际调用数、token 与花费（沿用账单能力）。
  离线假引擎的调用同样计入 `calls`，token 为 0、花费为 0，口径已写入 `VERSION.md`。
- **候选译法**：气泡中的推荐项与候选项各自保留译文；选中只标记当前采用项，反复切换不会串位或丢项。
  推荐标记始终留在最初的推荐译文上，候选顺序稳定，不随选中重排。
- **前端配套**：设置 → 翻译新增长文本五项参数；拖入文件不再在前端按长度截断；
  进度条、失败重试、待译/失败/已取消状态与强制切分标记均有前端用例覆盖；
  新增本文术语一致性面板与对应中英文案。
- **移除审校**：删除工作台审校按钮与抽屉、前端审校状态/文案/样式、后端 `domain/review`、
  `review.*` 命令与相关 DTO/错误码/测试；旧库 `reviews` / `decisions` 表保留建表但不读写，旧库可直接打开。
