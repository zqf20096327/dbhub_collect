## 一、产品定位

**我们一家** 是为 2–6 人小家庭设计的「自托管」生活协作中心。它把家庭日常最容易被遗忘、最容易各说各的四件事——**要做什么、发生了什么、要记住什么、花了多少钱**——收敛到一个私有部署的网页应用里，全家实时同步、各端自适应。

| 维度 | 说明 |
| --- | --- |
| 目标用户 | 小家庭 / 合住亲友（家庭共担事务的场景） |
| 核心场景 | 家庭待办提醒、家庭相册式动态、重要信息存档、共同记账 |
| 部署方式 | 私有部署（Docker 或 Node 直跑），数据完全自持 |
| 技术基调 | 零外部依赖、SQLite 单文件、原生前端，轻量可长期运行 |

## 二、核心功能

### 1. 万年历待办

农历、二十四节气与传统节日一目了然；待办默认只看「未完成」，进入即见今天还要做什么。支持**一句话快捷添加**、按日期建单、按参与人提醒，并内置「每周 / 每月 / 每年」周期提醒。

- 公历 + 农历 + 二十四节气 + 传统节日
- 周期提醒（每周 / 每月 / 每年公历或农历），不参与完成态
- 邮件提醒 + 提前 N 天提醒，按家庭时区精准计算
- 多人协同：任一成员增改，其他人自动同步

### 2. 图文动态 · 家庭朋友圈

一条朋友圈式的时间流，文字 + 多图（或视频），家人可评论、可「一起写」共创。支持标签筛选、关键词搜索、按日历回看。

- 文字 + 最多 9 图 / 3 段视频，视频自动取首帧封面
- 视频用内置播放器（ArtPlayer，MIT）播放：可拖进度、倍速、画中画、全屏手势；脚本未加载时自动回落到浏览器原生播放器
- 服务端支持 HTTP Range 分段请求，手机上边下边播、拖动进度不再回到 0
- 家人共创「一起写」、评论全部展示
- 图片支持双指缩放、左右滑动切换

### 3. 重点事项记录本

长期保存家庭重要信息：证件存放、账号备忘、病史、支出约定……可上锁、可归档、可带附件与勾选清单。

- 自定义分类（证件 / 账号 / 医疗 / 财务…），长按归档不丢失
- 访问密码（登录密码可作备用钥匙）
- 附件上传（单文件 20MB，可执行文件按文件头拦截）

### 4. 家庭记账

聊天式「一句话记账」：`今天买菜 30 元` 即入账，完全本地解析、断网可用。也能拍小票截图，由视觉模型识别后**确认再入库**。

- 一句话本地解析（金额 / 收支 / 日期 / 分类 / 备注）
- 千问截图记账：识别结果确认后才入库，密钥仅存服务端
- 个人 / 全家 × 日 / 月 四种统计、分类排行、预算预警
- CSV 导出（UTF-8 BOM，Excel 直接打开不乱码）

### 5. 家庭成员与管理

管理员在「家庭设置」里统一配置站点名称、注册开关、时区、待办提醒、内容通知、发件邮箱等；每位成员可自定义自己的收件邮箱与通知偏好。

- 自助注册开关、免登录有效期、站点名称自定义
- 待办邮件提醒与内容变更通知独立配置
- 一键导出 / 恢复备份，成员密码可重置
- 忘记密码可自助找回：登录页「忘记密码？」用账号绑定的邮箱收 6 位验证码重置（15 分钟有效、单次使用、10 分钟最多 3 次）；没有绑邮箱时由管理员在「家庭成员」里重置

### 6. 个性化主题

内置青野、米白、澄蓝三套配色主题，移动端与桌面端一致呈现，照顾不同家庭成员的视觉偏好。

## 四、主要优势

**全家实时协同**
任一成员新增或修改，其他人的列表与日历自动同步；版块红点提示「别人更新过」。

**数据自持 · 隐私优先**
私有部署，SQLite 单文件存储，备份一键导出 / 恢复；记录本可单独上锁，仅自己可见的内容绝不外发。

**零依赖 · 轻量易部署**
无需 `npm install`，Node ≥ 22.5 自带 SQLite；Docker Compose 一条命令即可上线，长期运行资源占用低。

**多端自适应**
同一套界面在手机与桌面自动重排，输入框始终在键盘上方，移动场景不打断输入。

**提醒与通知可靠**
待办邮件提醒 + 内容变更通知双轨独立；支持提前提醒、汇总发送、免打扰时段，并有「运行状态」页可核查是否生效。

**记账省心**
一句话本地记账零延迟、零额度消耗；截图记账识别确认后入库，密钥不出服务端；月度 AI 额度可设上限熔断。

**模板可配置**
待办提醒、内容通知、记账推送的邮件模板均可自定义并一键恢复默认，文案随家庭习惯调整。

## 五、部署与获取

- **Docker（推荐）**：`docker compose up -d`，挂载 `./data` 持久化
- **Node 直跑**：环境要求 Node.js ≥ 22.5，启动即服务，无需安装依赖
- **离线镜像包**：提供飞牛应用中心 `.fpk` 离线安装包，适用于无外网环境

## 七、已知限制与后续计划

**视频播放（P2 未做）**
服务端已支持 HTTP Range 分段请求，普通 H.264 MP4 可在手机上边下边播、自由拖动。但本项目**不做转封装 / 转码**：

- `moov` 原子位于文件尾部的 MP4（部分手机直接录制的）必须整段下载后才能开始播放 —— 需要 `ffmpeg -movflags +faststart` 重排；
- HEVC / H.265、部分 MOV 变体依赖设备自身解码能力，浏览器不支持时只能下载后用系统播放器看。

转码需引入 FFmpeg（镜像体积从 ~50MB 涨到 ~200MB），与「零依赖、轻量长期运行」的基调冲突，故列为后续计划，暂不实现。

**忘记密码依赖两个前提**
账号已绑定邮箱 + 家庭已配置发件邮箱（SMTP）。任一缺失时邮件发不出去，界面会提示改由管理员重置；未配置 SMTP 时接口返回 `503 MAIL_NOT_READY`，而不是静默假装已发送。

**PWA：现在能「装得像样」，还不能「断网打开」**
iOS Safari「添加到主屏幕」、Android Chrome「安装应用」、桌面 Chrome/Edge「安装」均可用，独立窗口打开、无地址栏。

- **图标**：4 张 PNG（192 / 512 / maskable-512 / apple-touch-180）。iOS 不认 SVG，旧版本装到主屏是空白方块，本版已修。改设计或换主题色后执行 `node scripts/make-icons.js` 重新生成（纯 Node，不引 sharp / canvas，与零依赖基调一致）。
- **清单**：`public/manifest.webmanifest` 全程用相对路径（`start_url` / `scope` / `id` 都是 `./`），网关带前缀（如 `/app/familyhub/`）时自动正确；响应头 `Cache-Control: no-cache`，换图标不必让用户清缓存。
- **未做**：Service Worker 与离线缓存（P1）。它只在 **https / localhost** 下生效，而本项目默认是 `http://内网IP:3455` —— 没有证书时做了也不会被激活。等有了 HTTPS 入口（反向代理挂证书）再上，届时断网也能打开界面壳。
