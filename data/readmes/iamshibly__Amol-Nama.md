# AmolNama

A student reflection journal for recording lessons, tracking promises, and reviewing progress.

[Live website](https://amol-nama.vercel.app)

## Features

- Private reflections with search, filters, and a timeline
- Promises linked to reflections
- Semester dashboard and reports
- Moderated anonymous sharing and reactions
- Editable profile, profile photos, and account data export

## Built with

Java 26, Spring Boot, Thymeleaf, and MySQL-compatible TiDB.

## Deployment

Hosted on Vercel from this repository. The application root is `app`.

See [DEPLOYMENT.md](DEPLOYMENT.md) for setup and environment variables.
