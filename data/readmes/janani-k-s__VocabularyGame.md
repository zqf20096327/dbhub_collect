# Vocabulary Game

A gamified web application for learning Gen-Z vocabulary.

## Tech Stack

- Python
- Django
- Django REST Framework
- PostgreSQL
- HTML
- CSS
- Bootstrap

## Features

- User registration/login
- Vocabulary quiz
- XP system
- Leaderboard
- REST APIs

## Installation

```bash
git clone <repository-url>
cd backend

python -m venv venv

# Windows
venv\Scripts\activate

pip install -r requirements.txt

Create a .env file using .env.example

python manage.py migrate

python manage.py runserver
```
