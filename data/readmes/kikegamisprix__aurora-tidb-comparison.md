# Amazon Aurora MySQL vs TiDB 比較資料

このプロジェクトは、Amazon Aurora MySQLとTiDBの技術比較、および移行時のメリット・デメリットをまとめたSlidevプレゼンテーション資料です。

## 概要

エンジニア向けに、以下の内容をカバーしています:

- アーキテクチャの比較
- スケーラビリティと性能特性
- レプリケーションと可用性
- コスト構造
- 運用管理の違い
- **マイグレーションメリット（詳細）**
- **マイグレーションデメリット（詳細）**
- 意思決定マトリックス

## セットアップ

### 前提条件

- Node.js (v16以上推奨)
- npm または yarn

### インストール

```bash
npm install
```

## 使い方

### 開発モード（プレゼンテーションモード）

ローカルでスライドを表示し、編集しながらリアルタイムプレビューできます:

```bash
npm run dev
```

ブラウザで `http://localhost:3030` を開きます。

### ビルド（静的HTMLとして出力）

プレゼンテーションを静的HTMLファイルとしてビルドします:

```bash
npm run build
```

ビルドされたファイルは `dist/` ディレクトリに出力されます。

### PDFエクスポート

スライドをPDFファイルとしてエクスポートします:

```bash
npm run export
```

## スライドの構成

1. **イントロダクション** - 資料の目的と目次
2. **アーキテクチャ比較** - Aurora MySQL と TiDB の基本構造
3. **スケーラビリティ** - 垂直 vs 水平スケーリング
4. **ストレージと永続化** - データの保存方法とレプリケーション
5. **パフォーマンス特性** - ワークロード別のベンチマーク比較
6. **レプリケーションと可用性** - HA構成とフェイルオーバー
7. **コスト構造** - 価格モデルとコスト最適化
8. **運用管理** - 管理ツールと監視
9. **マイグレーションメリット** - TiDB移行の利点
   - スケーラビリティ向上
   - HTAP機能
   - マルチクラウド対応
   - 強一貫性と高可用性
10. **マイグレーションデメリット** - TiDB移行の課題
    - 運用の複雑性
    - MySQL互換性の制約
    - 初期コストと移行リスク
11. **意思決定マトリックス** - シナリオ別の推奨
12. **まとめ** - 各データベースの強みと推奨アプローチ

## カスタマイズ

### スライドの編集

`slides.md` ファイルを編集してスライドをカスタマイズできます。

### テーマの変更

`slides.md` の先頭にあるfrontmatterセクションで、テーマや背景を変更できます:

```yaml
---
theme: default  # 他のテーマ: seriph, apple-basic, etc.
background: https://your-image-url.jpg
---
```

### 追加スライド

`---` で区切って新しいスライドを追加できます:

```markdown
---
layout: center
---

# 新しいスライド

コンテンツをここに記述
```

## キーボードショートカット（プレゼンモード）

- **Space / ↓ / →** - 次のスライド
- **↑ / ←** - 前のスライド
- **F** - フルスクリーン
- **O** - スライド一覧
- **D** - ダークモード切り替え
