## 📖 项目介绍

智能协同云图库（`yu-picture`）是一套基于 Vue 3、Spring Boot、腾讯云 COS 对象存储与 WebSocket 构建的企业级智能协同云图库全栈平台，由 [程序员鱼皮](http://dogyupi.com/) 在 [编程导航](https://www.codefather.cn/vip) 推出的企业级实战教学项目。完整课程配套视频教程、文字教程、分节源码、简历写法、面试题解与答疑服务，帮助你从零到一掌握商业级系统的架构演进与工程落地，大幅提升简历竞争力。如果你想先快速直观地了解整体界面效果和上线流程，可以先观看 [一分钟项目介绍与上线教程视频](https://www.bilibili.com/video/BV1akwGeSERK)。

这个平台的业务延展性非常强，既可以作为公开的表情包网站、设计素材网站或壁纸网站对外服务，也能扩展为个人云盘、个人相册、设计师作品集以及企业级活动相册和内部素材库。从功能视角来看，整套系统围绕四大真实业务场景层层展开。

在公共图库场景中，所有用户都可以在平台公开上传、分类浏览并多维度检索图片素材，迅速找到符合需求的图片资源。

![智能协同云图库公共图片素材上传与多维检索首页界面](./doc/images/img-01.png)

在平台管理场景中，管理员可以统一上传、审核、管理全站图片，并对系统内的图库容量与分布情况进行统计分析，保障内容合规与资源健康。

![智能协同云图库管理员审核图片与数据分析后台界面](./doc/images/img-02.png)

在个人 C 端场景中，每位用户都可以开通专属私有空间，将图片上传至个人空间内进行批量管理、颜色与标签检索、在线裁切编辑以及空间用量分析，轻松将其打造为个人网盘或作品集。

![智能协同云图库个人私有空间批量管理、检索与在线编辑界面](./doc/images/img-03.png)

在企业 B 端协作场景中，企业与组织可以开通团队共享空间并灵活邀请与管理成员，通过细粒度权限控制在团队内部共享图片，并支持多人实时协同编辑图片，显著提升商业团队的素材协作效率。

![智能协同云图库企业团队空间成员权限管理与多人实时协同编辑界面](./doc/images/img-04.png)

纵观全站，项目覆盖了文件存管、多维检索、复杂权限控制、实时协同通信以及 AI 图像扩展等企业高频业务场景，同时综合运用了多种架构思想与性能优化策略，是一套有真实业务深度、也有扎实技术含量的企业级全栈实践。

## 📐 项目三大阶段与架构设计

为了让不同基础的开发者都能循序渐进地消化整套系统，鱼皮将整个开发过程拆分为三个清晰递进的阶段，你可以根据自己的时间安排与当前技术水平按需跟进学习。

第一阶段聚焦公共图库平台的从零搭建。这一阶段主要带你实战 Vue 3 与 Spring Boot 全栈开发流程，掌握图片上传、解析、压缩、存储优化与检索查询等文件存管核心技巧。学完这一阶段，你就能独立交付一套可直接上线的表情包网站、壁纸库或设计素材站。

![智能协同云图库第一阶段公共图库平台业务流程图](./doc/images/img-05.png)

第二阶段重点面向 C 端能力进行深度扩展。用户能够开通个人私有空间，体验以图搜图、按主色调检索、扫码分享、批量编辑、AI 扩图以及空间用量可视化分析等丰富能力。这一阶段沉淀了大量互联网产品的主流业务实现方式，非常有助于拓宽工程视野。

![智能协同云图库第二阶段个人私有空间与多维检索分析功能架构图](./doc/images/img-06.png)

第三阶段则全面升级至 B 端企业级团队协作架构。企业可以创建团队空间并基于 RBAC 与 Sa-Token 实现成员角色管理，结合 WebSocket 与 Disruptor 无锁队列完成高并发下的多人实时协同编辑，并进一步演进至动态分库分表与 DDD 领域驱动设计重构，真正触及中大型商业系统的架构核心。

![智能协同云图库第三阶段团队空间权限控制与实时协同编辑架构图](./doc/images/img-07.png)

下面这张整体系统架构设计图完整串联了前端交互、网关与权限、缓存与存储、分库分表、实时通信以及 AI 绘图大模型调用等各个层次，方便你从全局视角把握整个工程的设计脉络。

## 🎯 项目收获

区别于千篇一律的普通增删改查练习项目，智能协同云图库强调讲透通用的系统拆解方法与架构设计套路。通过完整跟学与动手实践，你将系统掌握复杂业务从需求分析、表结构与权限建模到部署上线的全流程能力。

在架构与中间件实战方面，你会亲手基于 RBAC 权限模型与 Sa-Token 实现私有空间与团队空间的细粒度鉴权，结合 Redis 分布式缓存与 Caffeine 本地缓存构建高性能多级缓存体系，并针对文件上传、图片压缩、流量防盗与异步清理实施十余种存储优化策略。面对高并发与海量数据挑战，你还将实战 Disruptor 无锁队列提升协同事件吞吐能力，通过 ShardingSphere 落地支持动态扩容的分库分表方案，并利用 WebSocket 双向通信打通多端实时协同编辑。此外，课程还会带你接入 AI 绘图大模型扩展智能修图与扩图能力，并完整演示如何把传统三层架构的后端工程重构为清晰解耦的 DDD 领域驱动设计架构。

在代码实现之外，你还能学会如何绘制清晰的业务架构图与时序图、如何客观对比不同技术方案的取舍，并借助课程提供的大量差异化扩展思路，把项目真正打磨成简历上极具说服力的亮点经历。

## 🔧 技术选型

整套项目围绕主流企业级 Java 后端与现代化 Vue 3 前端技术栈构建，兼顾工程规范与高阶架构实践，同时贴合大厂招聘的核心技术考察点。

| 技术端 | 核心技术与框架 |
| --- | --- |
| 后端核心框架与持久层 | Java、Spring Boot、MySQL、MyBatis-Plus、MyBatis X |
| 缓存与数据存储 | Redis 分布式缓存、Caffeine 本地缓存、腾讯云 COS 对象存储、ShardingSphere 动态分库分表 |
| 架构、并发与权限 | DDD 领域驱动设计、Sa-Token 细粒度权限控制、WebSocket 双向通信、Disruptor 高性能无锁队列、JUC 并发与异步编程 |
| 智能扩展与工程优化 | AI 绘图大模型接入、Jsoup 数据抓取、多种经典设计模式实战，以及围绕性能、成本与安全的多角度系统优化 |
| 前端核心框架与工具 | Vue 3、Vite 构建工具、Ant Design Vue 组件库、Axios 请求库、Pinia 全局状态管理 |
| 前端工程化与生态组件 | TypeScript、ESLint、Prettier、OpenAPI 前端接口代码自动生成、数据可视化图表与在线图片编辑组件 |

## 📂 仓库目录结构

为了方便开发者直观对比传统分层架构与领域驱动设计架构的代码组织方式，本仓库同时保留了三个独立子工程目录。

| 目录名称 | 模块说明 |
| --- | --- |
| `yu-picture-backend/` | 基于 Spring Boot 的传统三层架构后端源码，适合前期快速理解核心业务逻辑与各项中间件落地 |
| `yu-picture-backend-ddd/` | 基于 DDD（领域驱动设计）重构升级后的企业级后端源码，清晰展示领域层、应用层、接口层与基础设施层的解耦实践 |
| `yu-picture-frontend/` | 基于 Vue 3、TypeScript 与 Ant Design Vue 的前端工程源码，集成实时协同编辑、数据可视化与 OpenAPI 接口生成 |

<details>
<summary><b>Q2：智能协同云图库适合作为计算机专业本科或研究生的毕业设计吗？</b></summary>

<details>
<summary><b>Q3：仓库里的 <code>yu-picture-backend</code> 和 <code>yu-picture-backend-ddd</code> 两个后端目录有什么区别？应该先看哪一个？</b></summary>
<p><code>yu-picture-backend</code> 采用经典的 Controller-Service-Mapper 三层架构实现，逻辑直观、上手门槛低，建议先通过这个版本理解完整业务流程、缓存优化和实时协同机制；待业务熟悉后，再对照阅读 <code>yu-picture-backend-ddd</code>，能够非常清晰地体会如何把真实业务项目平滑重构为高内聚、低耦合的 DDD 领域驱动设计架构。</p>
</details>

<details>
<summary><b>Q4：在图库类项目中，如何避免多人同时编辑同一张图片产生冲突并提升并发吞吐能力？</b></summary>
<p>在智能协同云图库的团队空间协同编辑模块中，系统使用 WebSocket 建立双向实时通信通道，通过状态锁机制控制同一时刻仅允许一位成员进入编辑状态并实时广播操作指令；同时引入高性能无锁队列 Disruptor 异步解耦消息分发，避免高并发场景下广播阻塞业务线程，这套设计思路在面试高并发与实时协作问题时非常加分。</p>
</details>

<details>
<summary><b>Q5：学完这个全栈项目后，如何快速准备项目相关的技术面试以及进一步用 AI 扩展功能？</b></summary>
