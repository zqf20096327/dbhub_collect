# wxlocal

微信聊天记录本地归档与浏览。把手机/电脑微信里的消息、图片、文件、视频收进一个你自己持有的
SQLite 库，然后用一个像微信一样的界面随时翻对话、看文件、搜索、导出。

存在的理由只有两条：**手机存储不够**，以及**聊天记录不该只活在一台手机上**。

---

> ⚠️ **环境与前置要求**
> - **操作系统**：Windows 10 / Windows 11（64位）
> - **微信版本**：**电脑版微信 4.0 及以上版本**（暂不支持微信 3.x 及更早旧版本）
> - **运行状态**：首次取密钥时，微信必须处于**已登录**状态。若微信是以管理员身份运行的，请同样以管理员身份运行本程序。

---

## 它做什么

- **对话式浏览**：左侧会话列表、右侧气泡流，图片/视频/文件/表情/引用回复按微信的排版还原。
- **搜索**：全会话搜、单个会话内搜。
- **导出**：任意会话导出成 HTML/ZIP，脱离本程序也能看。
- **自持归档**：图片、语音封面、视频、收到的文件拷进你自己的 `library\`，不再依赖微信目录。
- **回收空间**：确认已归档之后，可以把微信原目录里的媒体文件删掉（**只能手动触发**）。
- **增量同步**：重新打开就自动读新增消息，读到多少算多少，不阻塞浏览。

它**不**做的事：不发消息、不改微信数据、不联网上传任何东西。全程只读微信目录，写的只有它自己的库。

## 三分钟跑起来

### 用打包好的 exe（推荐给不想装 Python 的人）

1. 双击 `wxlocal.exe`。第一次会自己开一个独立窗口。
2. 窗口里跟着引导走两步：
   - **① 取密钥** —— 需要电脑上的微信**正在登录**。程序只在内存里读密钥，不注入、不调试、不改微信。
   - **② 读取记录** —— 建索引、扫媒体、归位图片。首次几分钟到十几分钟，看记录多少。
3. 完事之后每次双击就是直接看记录，不再要求你做任何迁移。

数据默认落在 exe 旁边的 `wxlocal-data\`。想放别的盘：

```
wxlocal.exe --data D:\wxlocal-data
```

### 从源码跑（想改代码的人）

```bat
pip install -r requirements.txt
python -m wxlocal
```

或者双击 `启动.bat`（固定 8770 端口，Edge 独立窗口打开）。停服务用 `停止.bat`。

打包成单文件 exe：

```bat
python tools\build.py --onefile
```

## 目录结构

仓库根是项目根，包本体在 `wxlocal/`，打包脚手架在 `tools/`。

PyInstaller 的入口是 `tools/entry.py`，**不是** `wxlocal/__main__.py`：
PyInstaller 把入口当顶层脚本执行，没有父包，`__main__.py` 里的
`from .cli import ...` 会以 `attempted relative import with no known parent
package` 崩掉。`tools/entry.py` 用绝对包名导入绕开这点。

```
wxlocal/
├─ __main__.py        python -m wxlocal 的入口
├─ cli.py             命令行：定数据目录、挑空闲端口、起服务、开窗口
├─ runtime.py         冻结/源码两种状态下的路径解析（RES_DIR / BASE_DIR / DATA_DIR）
├─ config.py          全应用唯一的路径来源 + config.json 读写
├─ server.py          FastAPI 后端 + 静态页面挂载（所有 /api/*）
├─ sync.py            同步流水线：解密 → 索引 → 扫盘 → 图片 → 视频 → 文件 → wxgf → 表情 → 归档
│
├─ core/              与微信无关的底层能力
│  ├─ keyfind.py      从微信进程内存里取数据库密钥（只读）
│  ├─ mediacrypt.py   .dat 图片/视频解密，全应用唯一实现
│  └─ wxdecrypt.py    SQLCipher 4 单库解密 + WAL 合并
│
├─ wechat/            微信专有的格式解析
│  ├─ indexer.py      分片库增量抽取进 wxvault.db
│  ├─ wxgf.py         微信自有 HEIF 变体 → jpg
│  └─ stickers.py     表情包 CDN 拉取
│
├─ store/             你自己的数据怎么存、怎么搬、怎么删
│  ├─ library.py      媒体收进自持库
│  ├─ importdir.py    合并另一份聊天记录（跨目录/跨机器）
│  ├─ migrate.py      整个归档搬到另一个盘
│  ├─ release.py      删掉已归档的微信源文件，回收空间
│  └─ exporter.py     会话导出
│
└─ static/            前端页面（单文件 index.html）
```

`tools/build.py` 是打包脚本，不属于运行时代码。

## 数据放在哪

| 东西 | 默认位置 | 说明 |
|---|---|---|
| `config.json` | 数据目录 | 微信数据根、账号、库路径 |
| `wxvault.db` | 数据目录 | 你的库：消息、会话、联系人、媒体索引 |
| `library\` | 数据目录 | 归档的明文媒体 |
| `decrypted\` | 数据目录 | 解密出来的微信原始库（可重建，删了不心疼） |
| `cache\` `exports\` `logs\` `profile\` | 数据目录 | 临时/导出/日志/窗口配置 |

数据目录的判定顺序：

1. 命令行 `--data <目录>`
2. 环境变量 `WXLOCAL_HOME`
3. exe 旁边的 `wxlocal-data\`
4. 源码运行时就是仓库根

同一个 exe 想开两份互不干扰的归档，复制一份 exe 或加 `--data` 就行。

## 常见问题

**取不到密钥。**
1. 微信必须处于**已登录**状态。
2. 版本必须是**微信 4.x**（微信 3.x 数据库加密和内存结构完全不同，暂不支持）。
3. 如果微信是以管理员身份运行的，操作系统会拒绝普通权限读取进程内存，请尝试**右键以管理员身份运行本程序**。
4. 从源码运行的用户，请务必执行 `pip install -r requirements.txt` 确保 `pefile` 等依赖已安装。

**视频/语音打不开。**
按设计取舍：语音文件微信本地根本不落盘（只在 CDN），所以语音只有记录没有声音；视频只归档
微信自己缓存下来的那部分，没缓存过的就是没有。这两条是物理上限，不是 bug。

**某个文件显示「未缓存」。**
对方发来的文件你没下载过，微信目录里就从来不存在这个文件，程序不会去猜一个同名文件塞给你——
配错比配不上更糟。

**归档能撤回吗。**
`store/release.py` 只删微信原目录里**确认已归档进 library** 的那份，并且只删媒体，
不碰 `db_storage`。但它仍然是删除操作，所以永远只能你手动点，程序不会自己干。
