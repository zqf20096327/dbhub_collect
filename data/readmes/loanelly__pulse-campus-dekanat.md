## Гибридная архитектура и безопасность

Приложение поддерживает два режима:

- **Серверный режим:** Python 3.11+ и SQLite локально или в Docker. API обрабатывает вход, заявки и проверку доступа.
- **Автономный режим GitHub Pages:** `LocalCampusEngine` работает на стороне браузера и хранит демонстрационные данные в `localStorage` под версионированным ключом `pulse_campus_v1`. Изменения заявок доступны ролям в том же браузере.

Сервер хранит пароли как PBKDF2-HMAC-SHA256-хеш с индивидуальной солью, а не открытым текстом. Доступ к заявкам ограничивается текущим пользователем; попытка студента открыть чужую заявку получает `403 Forbidden`. В автономном режиме проверяются демо-пароли и выполняется фильтрация по текущему аккаунту. **GitHub Pages предназначен только для демонстрации на вымышленных данных:** клиентское хранилище не является безопасным местом для реальной персональной информации.

| Переменная | Назначение | Значение по умолчанию |
|---|---|---|
| `HOST` | Адрес сервера | `0.0.0.0` |
| `PORT` | Порт сервера | `8000` |
| `APP_SECRET` | Секрет подписи сессионных токенов | Генерируется случайно при запуске |

## Быстрый старт

Запустить сервер:

```bash
python app.py
```

Откройте [http://localhost:8000](http://localhost:8000).

Собрать и запустить Docker-контейнер:

```bash
docker build -t pulse-campus .
docker run --rm -p 8000:8000 -e APP_SECRET="замените-на-секрет-хостинга" pulse-campus
```

Запустить автотесты безопасности и сценариев:

```bash
python -m unittest discover tests
```

Тесты поднимают сервер на свободном порту и проверяют вход всех трёх ролей, отказ неверному паролю, защиту от IDOR, хранение PBKDF2-хешей и сквозной сценарий «заявка → деканат → готовая справка».
