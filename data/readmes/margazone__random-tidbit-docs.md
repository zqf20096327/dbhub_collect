# Random Tidbit documentation

Documentation website for
[random-tidbit](https://github.com/margazone/random-tidbit), a small browser
renderer that displays shuffled pieces of text without immediate repeats.

- [Read the documentation](https://random-tidbit.marga.zone/)
- [Package source code](https://github.com/margazone/random-tidbit)
- [npm package](https://www.npmjs.com/package/random-tidbit)

## Development

This website is built with [Astro](https://astro.build/) and
[Starlight](https://starlight.astro.build/).

```sh
pnpm install
pnpm dev
```

The development server runs at http://localhost:4328.

## 🧞 Commands

All commands are run from the root of the project, from a terminal:

| Command                | Action                                           |
| :--------------------- | :----------------------------------------------- |
| `pnpm install`         | Installs dependencies                            |
| `pnpm dev`             | Starts local dev server at `localhost:4328`      |
| `pnpm check`           | Runs Astro and TypeScript diagnostics            |
| `pnpm build`           | Build your production site to `./dist/`          |
| `pnpm preview`         | Preview your build locally, before deploying     |
| `pnpm astro ...`       | Run CLI commands like `astro add`, `astro check` |
| `pnpm astro -- --help` | Get help using the Astro CLI                     |
| `pnpm format`          | Format project files                             |
| `pnpm format:check`    | Check project formatting                         |
