# 🛒 Loja-Consulta.php

> Sistema de loja web com funcionalidade de consulta de dados, desenvolvido utilizando PHP, CSS e SQLite.

## 🚀 Sobre o Projeto

O **Loja-Consulta.php** é uma aplicação web simples e leve que integra um sistema de vitrine/loja com recursos de consulta a banco de dados. O projeto foi estruturado para fins de estudo e prática de desenvolvimento web backend com PHP e manipulação de dados leves com SQLite.

## 🛠️ Tecnologias Utilizadas

As seguintes tecnologias foram usadas no desenvolvimento do projeto:

* **PHP** (Lógica do backend e conexão com o banco de dados)
* **SQLite**[cite: 1] (Banco de dados leve e embarcado)
* **CSS**[cite: 1] (Estilização e design da interface)

## 📁 Estrutura do Repositório
