# Apache Flink Tools, Libraries, and Frameworks
[Back to the Top](https://github.com/mikeroyal/Apache-Flink-Guide#table-of-contents)

[FlinkX](https://github.com/DTStack/flinkx) is a data synchronization tool based on [Apache Flink®](https://flink.apache.org/) that supports data synchronization/integration and streaming SQL computation.

[Flink Siddhi](https://github.com/haoch/flink-siddhi) is a light-weight library to run [Siddhi CEP](https://github.com/wso2/siddhi) within [Apache Flink®](https://flink.apache.org/) streaming application. Siddhi CEP is a lightweight and easy-to-use Open Source Complex Event Processing Engine (CEP) released as a Java Library under Apache Software License v2.0.

[Apache Beam](https://beam.apache.org/) is an open source, unified model and set of language-specific SDKs for defining and executing data processing workflows, and also data ingestion and integration flows, supporting Enterprise Integration Patterns (EIPs) and Domain Specific Languages (DSLs).

[Apache Bahir](https://bahir.apache.org) is a tool that provides extensions to distributed analytics platforms such as Apache Spark™ and Apache Flink®.
