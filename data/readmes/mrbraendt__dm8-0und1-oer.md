# 0 und 1: Grundlagen der Informatik (Digitale Medien, Jahrgang 8)

Eine interaktive Lernwebsite im Cyberpunk-Stil für etwa ein bis zwei Unterrichtsstunden. In acht Stationen geht es um Bits und Bytes, die Turingmaschine, Hardware und Software, Pixel, Grenzen der Berechenbarkeit, KI, Verschlüsselung und sichere Passwörter. Jede Station öffnet sich erst, wenn das Rätsel davor gelöst ist.

Dazu gibt es zwei Spiele:
- **CYBER::ADVENTURES** (`cyber-adventure/`): ein Point-and-Click-Abenteuer
- **CYBER::TOWER** (`cyber-3d/`): ein 3D-Browserspiel

## Nutzen
Alles läuft im Browser, ohne Server und ohne Anmeldung. Du kannst die Seite über GitHub Pages aufrufen oder den Ordner herunterladen und `index.html` öffnen. Für die Spiele ist ein kleiner lokaler Webserver nötig, zum Beispiel `python3 -m http.server`.

Die Schriften liegen im Ordner `fonts/`, es werden keine externen Dienste geladen. Nur `cyber-3d/` lädt die Bibliothek three.js von jsDelivr.
