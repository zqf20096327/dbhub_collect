# MySQL Community

Welcome to the MySQL Community repository.

This repository supports the MySQL Community engagement initiative. It is a central place for community-facing updates, public discussion materials, meeting notes, slides, summaries, and supporting resources from the MySQL Community team.

Most of the active content lives in the repository wiki:

👉 [Visit the MySQL Community Wiki](https://github.com/mysql/mysql-community/wiki)

## Community discussions

We use GitHub Discussions to make it easier for the MySQL community to follow, join, and continue conversations around MySQL community priorities.

Visit [GitHub Discussions](https://github.com/mysql/mysql-community/discussions) to:

- Follow announcements from the MySQL Community team
- Participate in roadmap-related conversations
- Share feedback on MySQL community initiatives
- Join discussions around developer, DBA, ecosystem, cloud, AI, performance, and observability topics
- Respond to polls and other community engagement requests

GitHub Discussions are intended for open community conversation. For bugs or product defects, please use the appropriate MySQL bug reporting channels.

## What you can find here

This repository helps community members stay informed about MySQL community initiatives, roadmap discussions, contributor events, and public meeting materials.

Current resources include:

- MySQL Community Roadmap Public Discussion materials
- Webinar slides and recap links
- MySQL Contributor Summit 2026 information
- Public meeting notes and supporting documents
- Links to related MySQL community resources
