# TikTok History Viewer

A lightweight web application for viewing and managing exported TikTok watch history.

## Features

- 📂 Import TikTok history from a JSON file
- 🔍 Search videos by title
- 📅 Filter videos by date range
- ↕️ Sort history entries
- 📄 Pagination with customizable page size
- ▶️ Built-in TikTok video player
- 🔗 Quick access and copy video links

## Usage

1. Export your TikTok watch history.
2. Open the application.
3. Click **Load Data** and select the exported JSON file.
4. Browse, search, filter, and watch videos directly in the app.
