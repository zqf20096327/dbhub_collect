<h1 align="center">Tidbit</h1>
<p align="center"><strong>Bite-sized facts, shared with friends.</strong></p>

Tidbit is a small social web app for sharing interesting facts. Post a fact with a source and a category, browse what others have shared, and vote on each one as 👍 interesting, 🤯 mind-blowing or ⛔ false. When more people vote a fact false than interesting, it's flagged as **disputed**, so the community fact-checks itself.

## Features

- **Share a tidbit** with a source link and category. The form validates as you type and has a 200-character counter that warns as you get close.
- **Browse and filter** by category, **sort** by most interesting, most mind-blowing or newest, and **search** the facts you've loaded.
- **Vote once per fact.** Votes update instantly (optimistic UI) and roll back with an error message if the server rejects them.
- **Disputed badge** for facts the community voted false.
- **Share with friends** through the native share sheet on mobile, or copy to the clipboard on desktop.
- **Light and dark themes** that follow your system setting. Responsive from 320px up, keyboard accessible, and respects reduced-motion settings.

## Running locally

**Prerequisites:** Node.js 20.19+ (see `.nvmrc`) and a free [Supabase](https://supabase.com) project.

1. Install dependencies:

   ```bash
   git clone https://github.com/purnimakumarr/today-i-learnt.git tidbit
   cd tidbit
   npm install
   ```

2. Create the `facts` table in the Supabase SQL editor:

   ```sql
   create table facts (
     id bigint generated by default as identity primary key,
     created_at timestamptz not null default now(),
     text text not null check (char_length(text) <= 200),
     source text not null,
     category text not null,
     "votesInteresting" integer not null default 0,
     "votesMindblowing" integer not null default 0,
     "votesFalse" integer not null default 0
   );

   alter table facts enable row level security;
   create policy "Anyone can read facts" on facts for select using (true);
   create policy "Anyone can add facts" on facts for insert with check (true);
   create policy "Anyone can vote" on facts for update using (true);
   ```

3. Copy `.env.example` to `.env` and fill in your project URL and **anon** key. You can find both under Project Settings → API.

   ```bash
   cp .env.example .env
   ```

4. Start the dev server:

   ```bash
   npm run dev
   ```

| Script              | What it does                          |
| ------------------- | ------------------------------------- |
| `npm run dev`       | Start Vite dev server with hot reload |
| `npm run build`     | Type-check and build to `dist/`       |
| `npm run preview`   | Serve the production build locally    |
| `npm run lint`      | Run ESLint                            |
| `npm run typecheck` | Run the TypeScript compiler only      |

## Design notes

- **Logo.** A speech bubble (sharing) with a bite taken out of the corner (a _tidbit_) and a spark for the "did you know?" moment. It's a hand-written SVG that takes its color from the theme.
- **Theme.** Warm cream and tangerine in light mode, warm charcoal in dark mode. Fonts are Bricolage Grotesque for headings and DM Sans for body text. Category colors are mixed into tinted chips with `color-mix()`, so they stay readable in both themes.
- **One vote per fact** is enforced in the browser, which stops casual repeat voting. A production version would enforce it on the server, for example with Supabase Auth and a `votes` table keyed by user. Increments would also move into a Postgres function so concurrent votes can't overwrite each other.
