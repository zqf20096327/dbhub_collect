# StandardRe 规范查新工具

StandardRe 从 Word 或当前打开的 CAD 文档中提取规范引用，查询规范状态，并按用户选择生成替换后的文本。

## 下载 Windows 版

无需安装 Python，可从 [GitHub Releases](https://github.com/ranwenmin/standardre/releases) 下载最新的 Windows x64 压缩包，解压后运行 `main_in.exe`。运行时数据库会在软件目录的 `data` 文件夹中自动创建。

> 软件查询公开标准信息。公开代理可用性会随时间变化；查询结论应结合结果中显示的权威来源复核。

## 运行

### v1.0.1 启动兼容性修复

修复部分电脑启动时提示 `pyi_rth_win32comgenpy` / `DLL load failed` 的问题。
旧包的 COM 组件依赖 `VCRUNTIME140_1.dll`，但运行库只放在 Qt 子目录，
没有系统级 VC 运行库的电脑可能无法加载。新包将 VC 运行库放到程序根目录，
并在 COM 启动钩子前加载包内运行库。

请完整解压新版 ZIP 到新文件夹，不要单独复制 `main_in.exe`。
需要保留查询记录时，关闭软件后把旧版 `data` 文件夹复制到新版目录。

发布包支持离线自检：`main_in.exe --self-test C:\path\report.json`。
自检验证主窗口创建、COM 初始化、Word 文档读写、SQLite 及关键 DLL 的实际加载路径。

项目当前使用 Python 3.7 和 PySide2，以兼容既有 Windows COM/CAD 环境：

```powershell
.\venv\Scripts\python.exe .\main_in.py
```

应用无需注册。运行日志位于 `%LOCALAPPDATA%\StandardRe\logs\standardre.log`。

## 主要模块

- `main_in.py`：窗口、任务调度和结果展示。
- `crawler_requests.py`：缓存、官方来源与工标网兜底的统一查询入口。
- `official_sources.py`：全国标准信息公共服务平台、国家标准全文公开系统、国家数字标准馆适配器。
- `proxy_pool.py`：代理格式校验、工标网真实查询预检和测速选择。
- `standard_cache.py`：项目内 SQLite 规范库、复核有效期和历史记录。
- `standard_utils.py`：规范名称、编号和年版的纯解析逻辑。
- `word_cad_find_func.py`：Word/CAD 查找替换。
- `app_paths.py`：源码和 PyInstaller 环境下的资源路径。
- `EIO.py` / `mymakepy.py`：Windows Office/CAD COM 支持。

覆盖保存 Word 时会先验证临时文档，并在原文件旁生成 `.docx.bak` 备份。

## 查询来源与本地规范库

查询顺序保持原接口兼容：

1. 优先读取复核有效期内的本地 SQLite 规范记录；
2. 未命中或需要复核时，优先使用原工标网快速查询；
3. 工标网无结果、返回错误页或连接不可用时，立即切换官方来源；
4. 工标网仍无可用结果时，自动查询“全国标准信息公共服务平台”“国家标准全文公开系统”和“国家数字标准馆”；工程建设、城建、交通、地方等规范优先使用覆盖范围更广的国家数字标准馆。

批量查询会按规范编号去重，同一编号在文档中出现多次只查询一次，结果同步显示到全部对应行。最多同时查询 5 个唯一编号。所有任务始终先读本地规范库，有效记录不会发起网络请求；需要联网时先使用当前线路，线路在查询途中被工标网限制后，由整批任务共享的线路管理器在后台筛选并切换到下一条可用代理。工标网的无权访问页、国家数字标准馆的访问验证页、超时和解析失败都只表示当前线路或来源不可用，统一保持为可重试状态，不再据此生成或保存“未收录”。

当工程建设标准在修订时只改变 `GB`/`GB/T` 属性，或名称由“规范”改为“标准”时，查询会自动尝试对应的编号和名称变体。即使文档省略了年号，也会通过名称检索最新版；例如旧引用 `《混凝土结构设计规范》（GB 50010-2010）（2015年版）` 和 `混凝土结构设计规范 GB50010` 均会返回现行的 `《混凝土结构设计标准》（GB/T 50010-2010）（2024年版）`，不会误判为“查无规范”。

“查无规范”采用单独的阴性确认流程：工标网返回空结果后，并行查询两个适用于该标准类别的权威目录，只有两者都成功访问且都没有精确记录时才显示“查无规范”。任一来源限流、需要验证码、超时或页面结构异常时显示“查询未完成”，不保存假阴性结果。并行复核只针对疑似查无的行，已查到的结果和本地缓存命中不增加等待时间；其他行仍由原线程池继续查询。

省略分部分号的系列标准不会再作为普通空结果处理。程序会从官方搜索结果提取当前有效的各组成部分，界面显示“编号不完整”并列出候选编号；例如 `DB50/T 548` 会返回 `DB50/T 548.1-2024` 至 `DB50/T 548.4-2024`。如果确因官方来源限流或验证页面而无法完成复核，查询结果会明确写出不可用的来源，不再笼统提示“当前线路未取得有效结果”。

数据库位于项目内的 `data\standards.sqlite3`；打包运行时位于 `main_in.exe` 同级目录下的 `data\standards.sqlite3`。旧版本 `%LOCALAPPDATA%\StandardRe\cache\standards.sqlite3` 中的数据会在首次启动时自动导入，原数据库不会被删除。

每次联网查询成功都会更新当前规范记录，同时向 `standard_query_history` 表追加一份复核快照，因此旧信息不会因更新而丢失。有效期到达只表示需要联网复核，不会删除数据库记录：现行标准默认 3 天复核一次，即将实施标准 1 天，废止标准 14 天，待人工确认及未知状态 6 小时。联网复核成功后覆盖当前记录并保留历史；所有来源暂时不可用时继续返回旧记录，并在结果提示中明确标记。

如需验证纯网络查询，可点击结果处理区的“清除本地规范库”。确认后会清空当前规范记录和全部复核历史，并把界面结果重置为“未查询”；下一次点击“查询规范”将全部通过网络重新查询。

“查询规范”和“更换IP查询”都只跳过界面中已经明确为“现行、过期、名称错误”的行；废止、待确认、查无规范、未收录、查询中、请更换IP及其他任何状态都会重新查询。两种查询仍然先读本地规范库，只有没有可用记录或记录需要复核时才联网。应用每次启动时默认使用本机 IP；成功切换代理后，普通“查询规范”继续使用当前代理，不会自动恢复本机 IP，直至再次更换代理或重启程序。普通查询会在后台验证当前线路；一旦发现工标网限流、无权访问、超时或返回内容异常，会自动筛选下一条可用代理并继续原查询，不需要用户再次点击。同一批任务只由一个工作线程执行切换，其他线程直接复用新线路；已失败的线路在本批查询中不会再次使用。点击“更换IP查询”则会主动换到另一条经过真实工标网查询验证的线路。预检会自动跳过不可用节点，并从当前批次选择实测最快的 IP。程序会继续筛选剩余代理，只有整份 IP 池逐一验证后仍没有可用线路，结果区才显示“IP池已用尽”；在此之前不会显示“请更换IP”。若要强制验证全部网络查询，应先点击“清除本地规范库”。鼠标停留在查询结果上，可以看到来源、查询时间、是否来自缓存以及是否经过两个官方来源交叉确认。

内置代理列表位于 `Support\IP_set\IP_set.txt`，按最近一次工标网真实查询测速结果排列。公开代理的可用性随时可能变化，因此文件顺序只用于缩短筛选时间，运行时预检结果才是最终依据。公开代理仅用于查询公开规范信息，不应承载账号、口令或其他敏感数据。

只有唯一候选且官方明确标注“全部代替/整体代替”时才自动沿替代链更新。部分代替、多个候选或来源冲突统一显示“待确认”，不会自动给出错误替代结论。

## 测试

```powershell
.\venv\Scripts\python.exe -m unittest discover -s tests -v
```

## 打包

```powershell
.\venv\Scripts\python.exe -m PyInstaller --noconfirm .\main_in.spec
```

`main_in.spec` 会携带图标和 `Support` 运行资源。

## 后续运行时升级

升级 Python/PySide 前应在独立分支或新虚拟环境中验证 Word、AutoCAD COM 和 PyInstaller。当前源码已减少框架耦合，便于后续迁移到受支持的新版本 Python 和 PySide6。
