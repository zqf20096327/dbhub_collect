# SaaSy Land

Source code for the SaaSy Land website, customer workspace, and admin console. The application combines a multilingual marketing site, documentation and blog, authentication, newsletter subscriptions, video streaming and courses, and Polar checkout and licence management in one TanStack Start application deployed to Cloudflare Workers.

This repository contains the website application. The SaaSy Land CLI and private generator templates are maintained separately and are not included here. The website source is MIT licensed, so you can start from it for free; the paid CLI writes a new project in the stack you choose, today React with TanStack Start on Cloudflare Workers and the other stacks on the [roadmap](content/docs/project/roadmap.en-US.mdx), with its own tests, coverage gate, CI workflow and `AGENTS.md`. See [licensing](#licensing) for the distinction between the website source and the commercial product.

## Features and implementation status

Every admin screen reads real data through permission-checked server functions: from D1, and from Polar for the product catalogue and an order's live payment. A screen whose data has no source yet is not built, and the `admin-data/no-literal-data` lint rule fails `bun run check` when admin code declares demo data.
