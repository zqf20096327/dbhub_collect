# CTG Vape Shop

A modern e-commerce website for CTG Vape Shop, providing customers with a seamless online shopping experience for vaping products and accessories.

## Features

- **Product Catalog**: Browse through a wide selection of vaping products including devices, e-liquids, and accessories
- **Shopping Cart**: Easy-to-use cart system for managing purchases
- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices
- **Product Search & Filter**: Quickly find products by category, brand, or price range
- **Contact Form**: Easy way for customers to reach out with questions or concerns

## Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: node.js
- **Database**: firebase


## Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/ctgvapeshop.git
```

2. Navigate to the project directory
```bash
cd ctgvapeshop
```

3. Install dependencies
```bash
npm install
```

4. Set up environment variables
```bash
cp .env.example .env
# Edit .env with your configuration
```

5. Run the application
```bash
npm start
```
