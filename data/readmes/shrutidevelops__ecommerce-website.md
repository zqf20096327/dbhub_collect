# 🛒 ShruShop

A full-stack e-commerce web application built using **Python Flask**, **HTML**, **CSS**, **TiDB Cloud (MySQL)**, and deployed on **Render**.

🌐 **Live Demo:** https://ecommerce-website-yqy9.onrender.com

## ✨ Features

- User Registration & Login
- Product Categories
- Product Search
- Shopping Cart
- Wishlist
- Address Management
- Checkout & Order Placement
- Order History
- Admin Dashboard
- Contact Form
- Newsletter Subscription
- Responsive Design

## 🛠️ Tech Stack

- Python
- Flask
- HTML5
- CSS3
- MySQL / TiDB Cloud
- Git & GitHub
- Render

## 🚀 Run Locally

```bash
git clone https://github.com/shrutidevelops/ecommerce-website.git
cd ecommerce-website
pip install -r requirements.txt
python app.py
```
