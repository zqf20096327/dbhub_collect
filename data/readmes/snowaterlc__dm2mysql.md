# 达梦数据库到MySQL8迁移工具

一个专业的数据迁移工具，用于将达梦(DaMeng)数据库迁移到MySQL 8.0。

## 编写初衷

在企业级应用开发中，数据库迁移是一个常见但复杂的需求。随着国产化进程的推进，越来越多的企业需要将原有的达梦(DM)数据库迁移到MySQL等开源数据库。然而，这两个数据库之间存在诸多差异，传统的手工迁移方式效率低下且容易出错。

本工具旨在解决**达梦数据库到MySQL数据迁移**这一特定场景下的核心痛点，提供一个**开箱即用、稳定可靠**的迁移解决方案。

## 解决的问题

### 1. 数据类型差异问题
- 达梦数据库特有的数据类型（如 CLOB、NCLOB、BLOB、DATE、DATETIME 等）需要正确映射到 MySQL 对应类型
- 自动处理 VARCHAR2、NVARCHAR2 等 Oracle 兼容类型
- 处理达梦与 MySQL 之间数值类型的精度差异（如 DECIMAL 映射）

### 2. MySQL 行大小限制
- MySQL 单行数据有 **65535 字节**的限制
- 自动检测并处理可能超出限制的大字段（VARCHAR超大、CHAR超大等）
- 智能将超长字段转换为 TEXT/LONGTEXT 类型

### 3. MySQL 8 索引限制
- MySQL 8 在 utf8mb4 编码下，**索引字段最大 768 字符**
- 自动检测超长索引字段并转换为 TEXT 类型，确保字段可被正常创建和使用

### 4. 默认值兼容性问题
- 达梦数据库的默认日期值（如 `0000-00-00`）在 MySQL 中是非法的
- 自动清理无效的默认值，转换为 MySQL 可接受的格式
- 处理达梦特有的日期时间函数（如 GETDATE()、SYSDATE）转换为 MySQL 标准函数

### 5. 大字段数据迁移
- 支持 CLOB/NCLOB 转换为 LONGTEXT
- 支持 BLOB 转换为 LONGBLOB
- 正确处理二进制数据的编码和传输

### 6. 迁移效率问题
- 支持批量多表迁移，可选择全选或部分表
- 支持**断点续传**：迁移过程中可暂停和继续
- 实时显示迁移进度、速度、耗时等详细信息
- 批量提交机制提高大规模数据迁移效率

### 7. 配置与使用复杂性
- 提供图形化界面，无需命令行操作
- 配置信息自动保存，下次使用无需重复输入
- 连接测试功能，提前发现配置问题
- 完整的日志记录，便于问题排查和审计

## 功能特点

- **数据类型智能转换**：自动将达梦数据类型映射到MySQL数据类型
- **大字段处理**：处理MySQL单行容量限制，支持TEXT、LONGTEXT、BLOB等大字段
- **批量迁移**：支持多表批量迁移，可选择全选或部分表
- **断点续传**：支持暂停和继续迁移
- **实时进度**：显示迁移进度、速度、耗时等详细信息
- **日志记录**：完整的迁移日志，便于问题排查
- **配置保存**：保存数据库连接配置，下次使用无需重新输入

## 系统要求

- Python 3.7+
- 达梦数据库 ODBC 驱动 或 dmdpy 驱动
- MySQL 8.0+

## 安装步骤

1. 安装Python依赖：

```bash
pip install -r requirements.txt
```

2. 安装达梦数据库驱动（选择以下任一方式）：

### 方式一：使用dmdpy（推荐）

```bash
pip install dmdpy
```

### 方式二：使用ODBC驱动

1. 下载并安装达梦数据库ODBC驱动
2. 配置ODBC数据源

## 使用方法

1. 运行程序：

```bash
python main.py
```

2. 在界面中配置达梦数据库连接信息
3. 点击"连接达梦数据库"按钮测试连接
4. 在界面中配置MySQL数据库连接信息
5. 点击"连接MySQL数据库"按钮测试连接
6. 选择要迁移的表
7. 设置迁移选项
8. 点击"开始迁移"按钮

## 配置说明

### 达梦数据库配置

- **主机**：达梦数据库服务器地址
- **端口**：达梦数据库端口（默认5236）
- **用户名**：数据库用户名
- **密码**：数据库密码
- **数据库**：要连接的数据库名

### MySQL数据库配置

- **主机**：MySQL服务器地址
- **端口**：MySQL端口（默认3306）
- **用户名**：MySQL用户名
- **密码**：MySQL密码
- **数据库**：目标数据库名

## 数据类型映射

| 达梦类型 | MySQL类型 |
|---------|----------|
| INT | BIGINT |
| VARCHAR | VARCHAR |
| CHAR | VARCHAR |
| CLOB | LONGTEXT |
| NCLOB | LONGTEXT |
| BLOB | LONGBLOB |
| DATE | DATE |
| DATETIME | DATETIME |
| TIMESTAMP | TIMESTAMP |
| DECIMAL | DECIMAL |
| BOOLEAN | TINYINT(1) |

## 迁移选项

- **创建新表**：如果目标表已存在，跳过该表
- **清空现有数据**：如果目标表已存在，先清空数据再导入

## 常见问题

### 1. 达梦数据库连接失败

- 检查达梦数据库服务是否启动
- 确认主机地址和端口是否正确
- 检查用户名和密码是否正确
- 确保网络连接正常

### 2. MySQL数据库连接失败

- 检查MySQL服务是否启动
- 确认目标数据库是否已创建
- 检查用户权限是否足够

### 3. 迁移速度慢

- 建议分批次迁移大量数据
- 检查网络连接速度
- 考虑在MySQL端禁用索引，迁移完成后再重建
