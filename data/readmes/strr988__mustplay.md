# mustplay

Десктопный плеер для локальной музыки на Windows. Он собирает локальные аудиофайлы в библиотеку, импортирует плейлисты из Deezer, Spotify и SoundCloud и подбирает треки из неё в персональном радио «Моя волна». Версия исходного кода — **0.12.1** (подготовка следующего выпуска; опубликованный релиз пока v0.11.0). [Импорт плейлистов с проверкой отпечатком](docs/MUSIC_PIPELINE.md) · [Поиск в Яндекс Музыке](docs/YANDEX_SEARCH.md) · [История версий](CHANGELOG.md).

*English summary · mustplay is a Windows desktop player for local audio files, with playlists, a playback queue and explainable recommendations. It imports Deezer, Spotify and SoundCloud playlists by link, verifies every track by ISRC and Chromaprint fingerprint, and searches Yandex Music with a personal token.*

## Возможности 0.12.1

- Импорт по ссылке: плейлист Deezer, плейлист Spotify и сет SoundCloud. Одно поле само определяет сервис и тип ссылки; трек ищется через yt-dlp, подтверждается ISRC и отпечатком Chromaprint/AcoustID. Готовые треки становятся плейлистом библиотеки с метаданными и жанрами источника. [Как это работает](docs/MUSIC_PIPELINE.md).
- Короткие ссылки разворачиваются автоматически: `link.deezer.com`, `spoti.fi`, `on.soundcloud.com` и аналоги, включая адреса из мобильного «Поделиться». Резолвер ходит только по HTTPS и белому списку хостов.
- Импорт с минимальной настройкой: исходная папка загрузок — системная «Музыка» (можно изменить), yt-dlp и fpcalc устанавливаются из закреплённых версий с проверкой SHA-256. Встроенный ключ AcoustID работает без регистрации. Выбор `m4a` или исходного формата, история заданий и повтор неудачных треков.
- YT Music открывается плиткой входа: приложение показывает настоящую страницу сервиса и читает плейлист из живой вкладки. Ссылку YouTube напрямую импортировать нельзя — подсказка объясняет, что делать.
- Кнопка импорта включается только для ссылок, которые приложение действительно доводит до конца. ВК, Яндекс и YouTube по ссылке не запускают импорт; для них есть отдельные подсказки и входы.
- Отдельная вкладка «Поиск» для Яндекс Музыки: личный OAuth-токен хранится зашифрованным в профиле (при недоступности системного шифрования сохранить новый токен нельзя), доступны качество, тексты LRC, обложка и папка загрузок. [Настройка поиска](docs/YANDEX_SEARCH.md).
- Метаданные и жанры: при импорте сохраняются доступные поля и список жанров в библиотеке; отсутствие отдельного поля не бракует трек, а неподтверждённый отпечаток — бракует. Расширенное хранение сырых полей и каноническая нормализация жанров остаются направлением развития.
- Рекурсивный импорт и исключение папок, чтение тегов и встроенных JPEG/PNG-обложек, поиск и сортировка по библиотеке.
- Плейлисты и редактируемая очередь с перемешиванием и повтором.
- Локальное сохранение библиотеки, лайков, истории, громкости, очереди и позиции воспроизведения.
- Радио «Моя волна» с режимами **Знакомое**, **Баланс** и **Открытия**. Панель **Почему этот трек?** объясняет автоматический выбор.
- Инструменты исследования для сравнения алгоритмов, проведения слепого пилота и экспорта оценок. [Методика](docs/RECOMMENDATION_EXPERIMENT.md).
- Полноэкранный плеер с синхронизированной «Текстомузыкой» и отдельная панель чтения текста песни из локальных файлов и тегов.
- Мини-плеер с закреплением поверх окон, настраиваемые глобальные сочетания и таймер сна. [Руководство по функциям плеера](docs/PLAYER_EXPERIENCE.md).
- Светлая и тёмная темы. Кнопка внизу боковой панели переключает тему с плавным переходом. Выбор сохраняется для основного окна и мини-плеера.
- Масштаб интерфейса от 80% до 150%, анимация лайка, выбор системного, встроенного или импортированного курсора.
- Пресеты Speed Up и Slowed с изменением темпа и высоты тона. Reverb включается отдельно для каждого пресета. Меню доступно во всех режимах плеера.
- Выдвижной регулятор громкости в основном и полноэкранном плеере. В диско-режиме цветное свечение реагирует на музыку.

## Разработка

На Windows x64 установите Node.js **24.22.x** и pnpm **11.25.0**. Выполните команды в корне клонированного репозитория.

```powershell
npm install --global pnpm@11.25.0
pnpm install --frozen-lockfile --store-dir .pnpm-store
pnpm exec install-electron
pnpm build
pnpm start
```

Если pnpm нужной версии уже установлен, начните со второй команды. Для разработки с обновлением интерфейса запустите `pnpm dev`. Папка `tests/fixtures` содержит синтетические MP3 и FLAC для первого импорта.

```powershell
pnpm typecheck
pnpm test
pnpm test:desktop
```

`pnpm build` также проверяет типы. `pnpm test:desktop` запускает собранное приложение в интерактивном Windows-сеансе. Для упаковки и проверки ZIP используйте `pnpm package:windows` и `pnpm test:release`. Подготовка архива и сценарии обновления описаны отдельно. [Windows-сборка](docs/WINDOWS_RELEASE.md).

## Технологии и архитектура

Electron, React, TypeScript, Tailwind CSS, SQLite через `node:sqlite`, music-metadata, electron-vite и Vitest.

- **Main** управляет диалогами, импортом, SQLite и доступом к аудио по ID источника.
- **Preload** предоставляет именованные операции через типизированный IPC. **Renderer** отображает интерфейс и управляет одним `HTMLAudioElement`.
- Контракты находятся в `src/shared`. Алгоритм в `src/recommendations` работает с обычными данными независимо от Electron, React и SQLite.

## Ограничения

- Поддерживаются локальные MP3, AAC, M4A/MP4 с AAC или FLAC, FLAC, WAV PCM, Ogg Vorbis, Opus и WebM с Opus/Vorbis. ALAC, AIFF и WMA не поддерживаются.
- По ссылке импортируются плейлисты Deezer и Spotify и сеты SoundCloud. ВК, Яндекс и YouTube по ссылке не импортируются: для Яндекса есть отдельный поиск с токеном, для YT Music — вход через плитку, для ВК прямого резолвера аудио нет.
- Публичная страница Spotify отдаёт не больше 100 треков и не отдаёт ISRC — недостающие коды ищутся по метаданным.
- Скачивание с YouTube и медиа-серверов SoundCloud зависит от провайдера: если маршрут закрыт, нужен системный VPN в режиме TUN. Чтение списков при этом работает.
- Поиск в Яндекс Музыке требует личный токен и активную подписку сервиса; файлы скачиваются для личного использования.
- Выпуск 0.12.1 готовится для Windows x64. Публикация ZIP требует успешных проверок в GitHub Actions; сборки для macOS и Linux не подготовлены.
- SQLite хранится в профиле Windows, а библиотека ссылается на файлы на диске. После изменений повторите импорт. [Хранение и миграции](docs/PERSISTENT_LIBRARY.md).
- Объяснения доступны для автоматических рекомендаций текущего сеанса. Результаты технического сравнения получены на синтетическом каталоге. [Результаты исследования](docs/EXPERIMENT_RESULTS.md).
