# Anger Management Game

## Overview
The **Anger Management Game** is a web‑based interactive experience that helps users explore and regulate emotions through tactical combat. Players face off in fast‑paced rounds, using a blend of classic Rock‑Paper‑Scissors and strategic attacks to influence three emotional meters—**Anger**, **Satisfaction**, and **Confidence**—and ultimately achieve victory.

## Play the Game
You can access the live version of the game here:

[Anger Management Game](https://anger-management.onrender.com)

## How to Play
### 🔄 Phase 1: The Clash
Every turn begins with a synchronized **Rock‑Paper‑Scissors** selection. Win the clash phase to gain offensive initiative.

### 💥 Phase 2: The Strike
The clash winner selects an aggressive follow‑up strike: **Punch, Kick, or Slap** to inflict immediate scoring hits and warp player emotional states.

### 🧠 The Psychorithm
Manage three shifting neurological attribute meters during combat:
- **Anger** – Spikes when taking hits. High anger scales up your attack thresholds.
- **Satisfaction** – Expands upon landing clean tactical choices. Max out this bar to secure a victory.
- **Confidence** – Generated through balanced defensive responses, mitigating damage velocities.

### 🏆 Win Conditions
A match instantly concludes when a fighter meets any of these criteria:
- Accumulates **100 combat points** via strikes.
- Achieves **100 % Satisfaction** (Instant Strategic Synergy Win).
- The opponent chooses to **Give Up**.

## Installation
1. Clone the repository
   ```bash
   git clone https://github.com/yourusername/anger-management.git
   ```
2. Install dependencies
   ```bash
   cd anger-management/frontend
   npm install
   ```
3. Run the development server
   ```bash
   npm start
   ```
