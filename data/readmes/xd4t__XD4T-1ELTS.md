## Hệ sinh thái 4 kỹ năng khép kín (`v1.7.0`)

- **Luyện Lỗi Sai Thực Chiến (`error_drills`) & Mastery Loop `0/3 → ✅ Đã trị dứt điểm`:** Không còn gõ chép máy móc tiếng Việt. Sửa lỗi thông qua **Chọn đáp án ngữ cảnh (MCQ)**, **Tìm & sửa bẫy Reading T/F/NG & Paraphrase (Mini-Case)** và **Điền từ bẫy Listening (Typing)**. Đúng **3 ngữ cảnh khác nhau liên tiếp** mới đánh dấu **`✅ Đã trị dứt điểm`**, và tự mở lại ôn (*Relapse Trigger*) nếu bạn tái phạm khi viết Writing hoặc nói Speaking.
- **Biểu đồ & Sơ đồ SVG chuẩn Cambridge cho mọi đề Writing Task 1:** Phủ đủ **Line Graph · Bar Chart · Pie Charts (2 năm) · Table · Process · Map (Before/After) · Mixed Chart**, kèm nút **`🔍 Phóng to biểu đồ`**, **`🖼 Tải ảnh đề ngoài`** (luyện đề tự do), và tự tóm tắt số liệu vào prompt chấm AI (*Task Achievement*). Thanh **`⚠️ Top 3 lỗi Writing`** lọc chuẩn kỹ năng Writing; **2 nút nộp bài luôn nằm gọn trong màn hình 1280×800**.
- **Kho Nội Dung Sống 12 chủ đề + Tự động nạp gói mới (Gemini Refill):** Sẵn **120 thẻ Collocations (60 thẻ/track)**, **48 câu Dictation**, **48 Cue Card Speaking**, **60 bài Error Drill**, **24 cặp Paraphrase Reading** và **24 đề Writing** trong SQLite. Bấm **`✨ Nạp thêm bài (AI)`** (hoặc bật tự động nạp ngầm vào **Chủ Nhật hàng tuần / khi học đủ tiến độ**) để sinh **25 bài liên kết theo 1 trong 12 chủ đề IELTS** chỉ với 1 request, gắn nhãn `✨ Mới nạp`.
- **Dual-Track 24 Tuần (`Aim 6.5 · Vùng đệm 7.0` & `Aim 8.0`):** Chuyển đổi qua lại tức thì trong Cài đặt, tự động đồng bộ toàn bộ Bộ từ vựng, Lộ trình tuần, Đề Writing, Dictation, Bảng Paraphrase và Sổ lỗi giữa hai cấp độ.
- **Lịch `CORE ≤ 30 phút` đan xen Study4 vs `BONUS`:** Auto-tick khép kín khi ôn SRS, hoàn thành Quiz / Luyện lỗi sai, hoàn thành Speaking / Dictation, và có nút **`✓ Đánh dấu đã viết (Copy Prompt)`** cho Writing khi không dùng API key.
- **Phòng Luyện Nói (Speaking Studio — 48 Cue Card + Đề của tôi):** Hỗ trợ **Thi thật (Part 2 2:00 + Part 3)**, **Phản xạ 4-3-2**, chọn nghe lại từng chặng, **`📜 Lịch sử (N phiên)`**, **Chấm AI (Gemini Audio)** hoặc quy trình miễn phí **`✓ Tự chấm 5 mục`**.
- **Nghe chép câu (Listening Dictation — 100% Offline):** Tốc độ `0.85x | 1.0x | 1.15x`, chấm **Word-by-word Diff** xanh/đỏ, trích tối đa **3 cặp từ sai cốt lõi** đẩy vào `Listening · Chính tả` và tự sinh bài drill `TYPING`.
- **Flashcard SM-2 thông minh:** 3 mặt thẻ (**Mặt từ**, **Câu đục lỗ** nhận diện cả động từ chia thì, **🎧 Nghe trước `en-GB`/`en-US`**), chữa **`🔥 Từ cứng đầu`** (kiểm tra chứa từ gốc), **`🙈 Ẩn` kèm Hoàn tác 5 giây** và **`🗑 Xóa` xác nhận 2 nhịp**.
- **Flow Phím Tắt Liên Tục (`?`):** Chuyển tab `Alt+1..4`, lật/chấm Flashcard `Space` / `1..4`, cày Quiz / Micro-Check / Luyện lỗi bằng `1..4` / `A..D` và `Enter → Enter` không cần chạm chuột.

## 3 việc hay dùng nhất

> Xem hướng dẫn đầy đủ từng bước cho người mới tại: **[📖 Hướng dẫn sử dụng chi tiết từ A–Z](docs/HUONG-DAN-SU-DUNG.md)**

### 1. Bật AI tự chấm bài (Writing, Speaking Audio & Tự nạp bài mới)
1. Mở **Cài đặt** → bấm **Lấy key miễn phí tại Google AI Studio**.
2. Đăng nhập Google → bấm **Create API key** → copy chuỗi key và dán vào ô **Gemini API Key** (hoặc nạp từ file `.txt`/`.env`).
3. Bấm **Kiểm tra kết nối API** → **Lưu cài đặt**.
   *(Không muốn dùng API key? App vẫn chạy 100% chức năng học + **Copy Prompt** miễn phí gửi ChatGPT/Gemini web + **Tự chấm Speaking 5 mục** + **✓ Đánh dấu đã viết Writing**!)*

### 2. Đổi sang lộ trình học riêng bằng file `.md`
1. Mở tab **`[4] LỘ TRÌNH & SỔ LỖI`** → bấm **`+ NẠP LỘ TRÌNH .MD`**.
2. Bấm **`COPY PROMPT TẠO LỘ TRÌNH CHO AI`**, dán vào ChatGPT/Gemini để tạo file theo ngày thi của bạn.
3. Chọn file `.md` (hoặc dán thẳng) → **`PHÂN TÍCH & XEM TRƯỚC`** → **`ÁP DỤNG LỘ TRÌNH NGAY`** (bảo toàn các tuần đã hoàn thành).

### 3. Lưu bài học trước khi đổi máy / cài lại Windows
1. Mở **Cài đặt** → bấm **`💾 Xuất file sao lưu (.db)`** để cất toàn bộ tiến độ, từ vựng, sổ lỗi, điểm số và biểu đồ.
2. Sang máy mới, cài app xong vào **Cài đặt** → **`📂 Khôi phục từ file (.db)`** và chọn lại file vừa lưu.

## Hỏi đáp nhanh

- **Có cần mạng Internet để học không?**
  Không. Toàn bộ Flashcard SRS, 60 bài Error Drill, 48 câu Dictation, 48 Speaking Cue Card, 24 đề Writing + biểu đồ SVG, Bảng Paraphrase và Lộ trình đều chạy **100% offline**. Chỉ cần mạng khi bấm chấm AI hoặc nạp thêm gói chủ đề từ Gemini.

- **Desktop App:** Rust + Tauri v2 + TypeScript + Vite + SQLite (`rusqlite` bundled, WAL mode).

### Build từ mã nguồn (Windows)
```powershell
# 1. Cài dependencies frontend
npm install

# 2. Build Taskbar Widget
powershell -ExecutionPolicy Bypass -File .\taskbar-widget\build.ps1

# 3. Chạy test Frontend Diff + Backend Rust
node --test tests/error_fix_diff.test.mjs
cargo test --manifest-path src-tauri/Cargo.toml

# 4. Build bộ cài 1-file NSIS (remap path tránh nhúng đường dẫn cá nhân)
$env:RUSTFLAGS = "--remap-path-prefix=$env:USERPROFILE=/build"
npx tauri build --bundles nsis
```
