# openGauss-test-toolset

本项目用于介绍外部的测试工具集，会介绍每个工具的用处、使用说明、测试结果、调优方式、最佳实践、案例等内容，每个目录就是一个工具。



# 目录说明

| 目录         | 类型 | 说明                                   |
| ------------ | ---- | -------------------------------------- |
| 01_benchmark | 压测 | tpcc模型工具                           |
| 02_sysbench  | 压测 | sysbench模型工具                       |
| 03_hybench   | 压测 | hybench模型工具                        |
| 04_datakit   | 综合 | 安装、部署、迁移、开发、运维、调试工具 |
| 05_yat       | 测试 | openGauss自动化测试工具                |



# 其他说明

新增或者更新工具，请联系Tools sig组：[tools@opengauss.org](https://mailweb.opengauss.org/postorius/lists/tools.opengauss.org)

新增案例、工具使用，请联系QA sig组：[qa@opengauss.org](https://mailweb.opengauss.org/postorius/lists/qa.opengauss.org)
