# IT-AMS · IT 资产管理系统

> **关键词：** IT 资产管理 · 本地优先 · 局域网 H5 盘点 · Electron · Vue3 · SQLite

把公司「家底」管成一本看得见的明白账：桌面主机 + 手机 H5 共享同一份本地数据，台账、变更留痕、现场盘点，全部自己掌控。

## 适用场景

- 中小团队 IT 设备台账（在用 / 闲置 / 故障 / 报废）
- 办公室局域网现场盘点，无需公网与云账号
- 需要变更留痕、本地备份、绿色版免安装的场景

## 部署

### GitHub Pages

`https://zybkpro.github.io/ITAMS/`

推送到 `main` 后 Actions 自动部署静态站（`site/`）；Settings → Pages → Source = GitHub Actions。

### 安装包

体积较大的 `.zip` / `.dmg` 托管在 [GitHub Releases](https://github.com/zybkpro/ITAMS/releases)，不进入 git 历史。
