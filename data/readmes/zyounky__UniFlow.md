# UniFlow

UniFlow — Android-приложение для просмотра учебного расписания и работы с заданиями. У задания есть предмет, название, срок и отметка выполнения. Задания можно добавлять из приложения или через Telegram. Сервер хранит их в SQLite, а приложение сохраняет последнюю загруженную копию в Room, чтобы список можно было открыть без подключения.

- **Android** — Kotlin, Jetpack Compose, Room и Ktor Client.
- **Сервер** — Kotlin, Ktor, Exposed и SQLite.
- **Telegram-бот** — отдельный процесс на Kotlin/JVM, который добавляет задания в ту же базу через API.
- **Расписание** — демонстрационные занятия на четверг. Данные для него находятся в `LessonData.kt`.

[Дерево каталогов и схема обмена данными](PROJECT_STRUCTURE.md)

## Запуск

Понадобятся Git, JDK 21, Android Studio и Android SDK Platform 36. Приложение поддерживает Android 8.0 (API 26) и выше. Укажите JDK 21 как Gradle JDK в Android Studio или задайте `JAVA_HOME` перед запуском Gradle из терминала.

```powershell
git clone https://github.com/zyounky/UniFlow.git
cd UniFlow
```

### 1. Сервер

В корне репозитория запустите сервер в отдельном терминале.

```powershell
cd backend
.\gradlew.bat run
```

API доступен на `http://127.0.0.1:8080`. При первом запуске сервер создаст `backend/uniflow.db` с пустым списком заданий. Чтобы использовать другой файл SQLite, задайте переменную окружения `UNIFLOW_DB_PATH` перед запуском.

```powershell
Invoke-RestMethod http://127.0.0.1:8080/tasks
```

### 2. Приложение

Откройте папку `android/` в Android Studio, дождитесь синхронизации Gradle и запустите конфигурацию `app` на эмуляторе. Эмулятор обращается к серверу на компьютере по адресу `http://10.0.2.2:8080`.

Для физического устройства с USB-отладкой выполните `adb reverse tcp:8080 tcp:8080` (ADB входит в Android SDK Platform-Tools). Установите приложение с адресом сервера на телефоне.

```powershell
cd android
.\gradlew.bat :app:installDebug "-PuniflowApiBaseUrl=http://127.0.0.1:8080"
```

Для сборки из Android Studio задайте `uniflowApiBaseUrl=http://127.0.0.1:8080` в пользовательском `gradle.properties` в каталоге Gradle User Home. После смены адреса пересоберите и установите приложение.

Во вкладке «Задания» можно создать задание, отметить его выполненным или удалить. Для этих действий требуется работающий сервер. Если соединение пропало, приложение показывает сохранённый список и позволяет повторить загрузку.

### 3. Telegram-бот

Создайте бота через BotFather и отправьте ему сообщение в личном чате. В ответе Telegram `getUpdates` возьмите идентификатор из `message.chat.id`. [Документация Telegram Bot API](https://core.telegram.org/bots/api#getupdates)

Перед запуском сервера задайте секрет в его терминале. Используйте своё случайное значение.

```powershell
$env:UNIFLOW_BOT_SECRET = [Net.NetworkCredential]::new('', (Read-Host "Секрет для сервера и бота" -AsSecureString)).Password
.\gradlew.bat run
```

В другом терминале из папки `backend/` задайте токен, ID чата и тот же секрет.

```powershell
$env:TELEGRAM_BOT_TOKEN = [Net.NetworkCredential]::new('', (Read-Host "Токен Telegram-бота" -AsSecureString)).Password
$env:ALLOWED_CHAT_ID = Read-Host "ID разрешённого личного чата"
$env:UNIFLOW_BOT_SECRET = [Net.NetworkCredential]::new('', (Read-Host "Тот же секрет" -AsSecureString)).Password
.\gradlew.bat runBot
```

В личном чате отправьте `/start`, затем, например, `/task Физика | Сдать отчёт | 20 ноября`. В Android откройте «Задания» и нажмите «Обновить список». Бот принимает команды только из указанного личного чата. Сервер узнаёт повторную доставку по идентификатору обновления и возвращает ранее созданное задание.

Если сервер работает на другом порту, укажите для бота `UNIFLOW_API_BASE_URL`. Бот сохраняет позицию чтения в `.telegram-offset` в рабочем каталоге. Путь можно переопределить через `TELEGRAM_OFFSET_PATH`. Запускайте один процесс на токен.

На macOS и Linux используйте `./gradlew` вместо `.\gradlew.bat`.

## API заданий

| Запрос | Результат |
| --- | --- |
| `GET /tasks` | `200 OK`, список заданий |
| `POST /tasks` | `201 Created`, созданное задание с идентификатором сервера |
| `PUT /tasks/{id}` | `200 OK`, обновлённое задание |
| `DELETE /tasks/{id}` | `200 OK`, подтверждение удаления |

Запросы `POST` и `PUT` принимают JSON с заголовком `Content-Type: application/json`. Для `PUT` идентификатор в теле должен совпадать с идентификатором в URL. Ошибка в запросе возвращает `400 Bad Request`, а попытка изменить или удалить отсутствующее задание — `404 Not Found`.

Предмет и название обязательны, до 100 и 200 символов соответственно. Срок можно оставить пустым, максимальная длина — 100 символов. [Настройки сервера и запуск на другом порту](backend/README.md)

Пример тела для `POST /tasks`.

```json
{
  "subject": "Физика",
  "title": "Сдать отчёт по лабораторной",
  "deadline": "20 ноября",
  "isCompleted": false
}
```

API Android рассчитан на локальный запуск по HTTP. Внутренний маршрут `POST /telegram/tasks` требует секрет в заголовке `X-Bot-Secret`.

## Личные данные

При публикации исходников оставляйте сервер привязанным к `127.0.0.1`. Маршруты `/tasks` доступны без входа в аккаунт, поэтому порт сервера предназначен для локального подключения.

Храните токен бота, ID чата и секрет в переменных окружения. Для локальных настроек и выгрузок в рабочей папке можно использовать каталог `local-data/`, который игнорирует Git. Для коммитов используйте адрес `noreply` из настроек GitHub, задав его локально для этого репозитория.

Для резервной копии остановите сервер и скопируйте рабочий файл SQLite за пределы репозитория. Серверная база хранит оригиналы заданий. Кэш заданий исключён из резервных копий Android и переноса между устройствами. После переустановки приложение заново загружает список с сервера.

## Сборка и тесты

Команды выполняются из каталогов соответствующих компонентов.

| Каталог | Команда в PowerShell |
| --- | --- |
| `backend/` | `.\gradlew.bat build` |
| `android/` | `.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest` |
| `android/` | `.\gradlew.bat :app:connectedDebugAndroidTest` с эмулятором или подключённым устройством и работающим сервером |

Для тестов Android запустите сервер с отдельным файлом SQLite через `UNIFLOW_DB_PATH`. Тест создаёт задание, отмечает его выполненным и удаляет через интерфейс.
