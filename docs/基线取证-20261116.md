# 基线取证（2026-11-16 · P0 · 改造前现状）

> 结论先行：**当前 dbhub_page 对搜索引擎是一张白纸**——正文不在 HTML 里（蜘蛛只看到"正在加载"），无线上部署，Lighthouse 性能 61 分、LCP 47.4 秒。本文件为改造前基线，改造后复测对比用。

## 1. 正文不在 HTML（P0.1 铁证）

本地 `python -m http.server` 起站，`curl` 拉原始 HTML（= 不执行 JS 的蜘蛛视角）：

| 检查项 | 结果 |
|---|---|
| projects.html 原始大小 | 46,184 B（45KB 壳） |
| 已知项目名命中（supabase/grafana/netdata/clickhouse/oceanbase/postgresql） | **全部 0 次** |
| "tidb" 命中 1 次 | 出现在内联 JS 代码 `DBS.indexOf("TiDB")`，非正文 |
| 剥掉 `<script>/<style>/标签` 后纯正文 | **211 字符**——只有导航文字和"正在加载生态数据…" |
| 对照：data/pool.js 中同名命中 | supabase 1 / grafana 1 / tidb 2（数据全锁在 JS 文件里） |

**含义**：百度（不执行 JS）抓到的页面 = 无任何项目内容；Google 二级渲染队列，收录慢且不稳。
